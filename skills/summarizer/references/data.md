# Data, Metrics, and Tables

Scope: earnings figures, dashboards, metric dumps, tables, quantitative appendices.

## Hard fidelity

- Copy the figure **and its unit/currency** exactly as stated.
- Do not derive, annualize, margin-calculate, or round unless the user asked — and then say you did.
- "About 30%" from 26.4% is a fabricated number.
- Preserve baseline, period, and segment labels with the number.

## Reading strategy

- Headline KPIs are often the issuer's own summary; check footnotes, guidance language, and changed wording.
- Call out what the table does **not** show when that absence changes a decision.

## Shape

- Tables beat prose for repeated fields.
- One line per metric: `Name — value — period — vs prior (if stated)`.
