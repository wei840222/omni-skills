# Recurring Editions

Scope: the same stream summarized again on a cadence.

## Product is the delta

1. Load the prior edition via Boxes / stored index.
2. Deduplicate unchanged material; keep continuity one-liners only when needed for a new reader.
3. Lead with what changed since last cut-off.
4. Keep slot order stable when a template exists (`formats.md`) so editions compare.

## State writes

- Accepted cadences become `## Due` rows.
- Approved shapes become `<state_root>/templates/<name>.md` with a Boxes line.
