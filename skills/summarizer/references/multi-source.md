# Multi-Source Synthesis (Compression, Not New Insight)

Scope: several sources on one topic into one shorter account. New conclusions belong to `synthesize`; this file only compresses and attributes.

## Procedure

1. Build a **coverage matrix**: row = claim axis, columns = sources, cells = support/dissent/absent.
2. Write one account that **preserves disagreement** — range + who holds which end.
3. Attribute contested, projected, and vendor-supplied claims.
4. State coverage gaps: what no source addressed.

## Forbidden

- Averaging two conflicting figures into a bland midpoint neither source stated
- Dropping the lone dissent because consensus compresses easier
- Adding a recommendation unless labelled as judgment outside the summary
