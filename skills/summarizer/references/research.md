# Research Papers and Studies

Scope: papers, preprints, systematic reviews, technical studies.

## Payload locations

- **Do not treat the abstract as the source.** It is the authors' favorable compression and often omits limitations.
- Primary payload: **Results numbers** + **Discussion/Limitations**.
- Methods detail is usually cut for non-method audiences; population, N, and design caveats are not optional color.

## Must retain

For each material finding:

- Claim
- Population / setting
- N (or "not stated")
- Effect size / direction with units
- Limitation or uncertainty the authors stated
- Preprint/draft/unaudited status when present

## Shape

Prefer structured slots over free prose when the reader will compare papers:

```
Question → Finding (with N/effect) → Limitation → Relevance to reader
```

## Traps

- Summarizing only the abstract
- Upgrading "associated with" / "may" to causal claims
- Dropping the lone dissenting result or underpowered caveat
