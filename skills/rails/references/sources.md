# Official Sources & Framework Guides

This document records the primary official documentation and guides for Ruby on Rails web application development.

## Official Rails Guides

- **Ruby on Rails Guides Home**: [https://guides.rubyonrails.org/](https://guides.rubyonrails.org/)
  - Comprehensive architectural guides, conventions, and configuration options.
- **Active Record Basics & Querying**: [https://guides.rubyonrails.org/active_record_basics.html](https://guides.rubyonrails.org/active_record_basics.html)
  - Association patterns (`has_many :through`), validations, lifecycle callbacks (`throw :abort`), and query optimization (`includes`, `find_each`).
- **Action Controller Overview**: [https://guides.rubyonrails.org/action_controller_overview.html](https://guides.rubyonrails.org/action_controller_overview.html)
  - Strong Parameters, filter chains (`before_action`), rendering constraints, and redirect execution rules.
- **Securing Rails Applications**: [https://guides.rubyonrails.org/security.html](https://guides.rubyonrails.org/security.html)
  - CSRF token validation, SQL injection prevention, mass-assignment safety, and XSS sanitization.
