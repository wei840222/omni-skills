## Product and gallery

- Generated Photos Faces gallery — browse/filter pre-generated faces via
  https://generated.photos/faces
- Default avatar shortlist path verified live:
  https://generated.photos/faces/beautified/female/young-adult
  and https://generated.photos/faces/beautified/male/young-adult
- Image CDN host used by gallery cards:
  https://images.generated.photos/
- Face Generator (real-time generation, adjacent product):
  https://generated.photos/face-generator
- API marketing / commercial integration page:
  https://generated.photos/api
  Notes verified on-page: API pricing cards ($250/mo for 1,000 photos and
  $300/mo for 10,000 photos billed monthly), commercial-use link, and explicit
  API restrictions against caching/stockpiling stand-alone files, redistributing
  Generated Photos, machine-learning use, and dataset compilation.
