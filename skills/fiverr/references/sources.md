# Official Sources Map — Fiverr

Use these primary or high-authority sources when verifying seller-level rules, Terms of Service, AI disclosure, and marketplace risk. Prefer the full URL in PR notes and user-facing citations. Fiverr HTML endpoints frequently bot-challenge automated fetches (HTTP 403); when a live page is unreachable, still cite the canonical URL and re-check in a human browser before asserting a numeric threshold.

## Platform overview

- **Wikipedia — Fiverr** — company/marketplace framing (Israeli-founded freelance services marketplace; name originates from early $5 gigs) via https://en.wikipedia.org/wiki/Fiverr
- **Fiverr Community** — seller discussions and program change chatter (secondary; verify against Help Center before treating as policy) via https://community.fiverr.com/

## AI transparency and consumer protection (cross-jurisdiction)

- **EU Artificial Intelligence Act — Regulation (EU) 2024/1689** — primary legal text via https://eur-lex.europa.eu/eli/reg/2024/1689/oj
- **EU AI Act explainer hub** — implementation context and article navigation via https://artificialintelligenceact.eu/
- **European Commission — AI Act overview** — policy framing via https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai
- **EU AI Act Article 50 (transparency)** — disclosure-oriented obligations context via https://artificialintelligenceact.eu/article/50/

## How to use these sources in-session

- When stating **seller-level day/order/rating floors**, open the live Seller Levels or Help Center page first; do not treat skill prose as the system of record.
- When advising **AI disclosure**, separate (a) Fiverr marketplace expectations, (b) AI tool ToS commercial-use rights, and (c) EU/US consumer/AI transparency rules.
- Prefer on-platform message logs as the dispute record; external chat weakens chargeback and ToS posture.
- Never paste secrets, government IDs, or client credentials into examples.
