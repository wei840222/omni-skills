# Gratitude Data Templates

## Daily Entry Template
Use this template for logging daily gratitude:

```markdown
# <state_root>/log/YYYY/MM/DD.md
## Morning
- [Entry 1]
- [Entry 2]

## Evening
- [Entry 1]
- [Entry 2]
```

## Patterns Template
Use this to summarize frequent themes:

```markdown
# <state_root>/patterns.md
## Frequent Themes
- [Theme 1] (appears [X]% of entries)
- [Theme 2]

## People Mentioned Most
- [Person 1]: [X] times
- [Person 2]: [Y] times

## Insights
- [Insight 1]
- [Insight 2]
```

## Favorites Template
Save standout entries here for hard days:

```markdown
# <state_root>/favorites.md
Entries to revisit on hard days:

- "[Entry description]" — [Date]
- "[Entry description]" — [Date]
```

## Practice Preferences Template
Store how the user wants to engage:

```markdown
# <state_root>/practice.md
## Frequency
- Daily: morning, evening, or both
- Prompt me: yes/no

## Style
- Quick: 1-3 items
- Reflective: with context/why
```
