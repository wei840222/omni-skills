# Official Sources & Runtime References

This document records the official documentation and technical specifications for the Deno 2 runtime and package ecosystem.

## Official Runtime Documentation

- **Deno Runtime Documentation**: [https://docs.deno.com/runtime/](https://docs.deno.com/runtime/)
  - Core runtime APIs, granular permission model (`--allow-net`, `--allow-read`, `--allow-write`), and configuration via `deno.json`.
- **Deno 2 Release & Modern Architecture**: [https://deno.com/blog/v2.0](https://deno.com/blog/v2.0)
  - Full backwards compatibility with Node.js and npm packages, standard `package.json` support, and workspace configurations.
- **JSR Package Registry**: [https://jsr.io/docs/introduction](https://jsr.io/docs/introduction)
  - The open-source package registry for modern TypeScript and JavaScript with native documentation generation.
