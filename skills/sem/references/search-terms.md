# Search Terms Hygiene

- Review search-term reports on a defined cadence and use them to identify useful query themes and irrelevant traffic.
- Apply negative keywords at campaign scope for broad exclusions and at ad-group scope for narrower refinement.
- Verify negative-keyword match behavior before adding a term so that legitimate query coverage remains eligible.
- Maintain shared negative lists only when the excluded intent is consistently irrelevant across the campaigns that use them.
