## Stable product facts verified 2026-10-15

- Beszel is a lightweight server monitoring platform with Docker/Podman stats, historical data, and alerts.
- Architecture is hub + agent: the hub is a PocketBase-based web app; agents report system metrics to the hub.
- Supported capabilities called out by official docs include configurable alerts, Docker stats, network monitors, S.M.A.R.T., multi-user management, OAuth/OIDC, and automatic backups to disk or S3-compatible storage.
- Docs version menu observed at fetch time showed `0.21.0`; treat exact version claims as mutable and re-check releases before stating them as current.
