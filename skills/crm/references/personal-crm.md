# Personal and Solo CRM

The 20-minute version for job search, networking, freelance clients, and one-person shops.

## Minimum viable loop

1. Shared contacts box for people (`<state_root>/contacts/contacts.md`)
2. `## Pipeline` for anything with value + a date (applications, retainers, intros)
3. `interactions/<year>.md` for one-line substance
4. Weekly 20-minute review on `review_day`

## Weekly 20 minutes

| Minute | Action |
|---|---|
| 0–5 | Scan open deals/applications; close or set next step |
| 5–12 | Overdue tier A/B list; send or schedule the next touch |
| 12–18 | Log anything still only in your head |
| 18–20 | Export or copy a backup if you changed many rows |

## What to skip

- Multi-stage enterprise schemas on day one
- Enrichment vendors for a few dozen contacts
- Two tools "just for analytics"
- Fields you will not filter on this month

Graduate to hosted CRM or SQLite only when queries stop being greppable or a second person must write concurrently (`references/tools.md`).
