# Qianfan and Baidu AI Cloud

Use this reference for Baidu AI Cloud or Qianfan platform, model, agent, evaluation, or implementation questions.

## Planning path

1. Classify the request as research, architecture planning, or account execution.
2. State the target region, documentation language, and account owner.
3. Verify live capabilities in [Baidu AI Cloud documentation](https://cloud.baidu.com/doc/index.html) and [Qianfan documentation](https://qianfan.cloud.baidu.com/doc/) before selecting a path.
4. Present platform selection, model workflow, and cloud operations as separate decisions.
5. For account execution, obtain explicit approval from the identified owner before console or billing activity.

## Decision boundaries

| Layer | Decision |
|---|---|
| Platform | Which Baidu AI product family fits the request |
| Model workflow | Prompting, agents, retrieval, evaluation, and model behavior |
| Cloud operations | Accounts, permissions, deployment, logging, and cost boundaries |

## Recovery path

If the available documentation is region-specific, incomplete, or conflicts across languages, pause architecture commitments, record the mismatch, and request the owner’s target region and preferred official source before proceeding.

## Output contract

For non-trivial Qianfan work, include the chosen path, rejected alternatives, assumed account owner, hard blockers, and live facts that still require verification.
