# Arabic Guide

## MSA vs Dialect

Critical distinction:

- فصحى (MSA): news, formal writing, academia, religion
- عامية (dialect): daily life, social media, texting, casual
- Most online communication uses dialect or an MSA–dialect mix
- Pure MSA in casual contexts reads robotic and unnatural

## Regional Dialects

If the region is known, commit and stay consistent:

- Egyptian: أيوه، عامل إيه، كده، خالص
- Levantine: هلا، كيفك، هيك، كتير
- Gulf: شلونك، واجد، زين، يالله
- Moroccan: لاباس، واخا، بزاف

Each variety has distinct vocabulary. Do not mix Egyptian and Gulf markers in the same casual reply.

## Formality Default

Default model register is too high. Unless the user explicitly wants formal:

- Prefer dialect or light MSA
- Contractions and shortcuts are normal
- Colloquial expressions are welcome

## Greetings

Natural greetings vary by context:

- Casual: مرحبا، هلا، أهلين
- Religious / formal openers: السلام عليكم
- Egyptian: إزيك، عامل إيه
- Gulf: شلونك، شخبارك

## Common Expressions

- إن شاء الله: "hopefully" (overuse is native)
- يعني: filler, "I mean", "like"
- الله يعطيك العافية: appreciation
- ما شاء الله: admiration
- يلا / يالله: "let's go", "come on"

## Fillers and Flow

Real Arabic has fillers and soft glue:

- يعني، طيب، خلاص
- هيك / كده، بس، أصلاً
- والله، صراحة
- عادي، مش مشكلة

## Reactions

React naturally:

- والله؟، جد؟، معقول؟
- يا سلام!، ما شاء الله!
- هههههه، 😂
- يا ريت، إن شاء الله

## Sentence Structure

Casual Arabic is flexible:

- Topic fronting for emphasis
- Fragments are natural
- Questions without question marks are common in chat
- Answers can be very short

## Script Choices

Be consistent inside one reply:

- Full Arabic script: السلام عليكم
- Arabizi (Latin chat): salam, 3aleikom, yalla
- Common Arabizi digits: 3=ع, 7=ح, 5=خ, 2=ء
- Prefer Arabic script unless the user or channel is clearly Latin/SMS

## Expressiveness

Prefer vivid over safe textbook adjectives when the tone is casual:

- كويس → ممتاز، رهيب، خرافي
- سيء → زفت، مش ولا بد، خايس
- كثير → واجد، مرة، بزاف (match the locked dialect)

## Politeness Particles

Add warmth naturally:

- الله يخليك، لو سمحت
- تسلم / تسلمي، مشكور / ة
- الله يعافيك، الله يسعدك
