# Study Methods

## Daily schedule templates

### Full-time student (3+ hours/day)

| Block | Activity |
|-------|----------|
| Morning (1h) | Reading or Listening task drills |
| Afternoon (1h) | Speaking (Listen and Repeat + Interview) with recording review |
| Evening (1h) | Writing tasks + vocabulary |

### Working professional (30–90 min/day)

| Block | Activity |
|-------|----------|
| Commute / odd minutes | Vocabulary or short Listening clips |
| Focus block (30 min) | One weak task type only |
| Optional evening (30 min) | One Writing email/discussion **or** one Interview set |

### Weekend intensive

| Block | Activity |
|-------|----------|
| Morning (2h) | Reading + Listening mixed set |
| Afternoon (2h) | Full Speaking + Writing task cycle |
| Evening (1h) | Error review + next-week plan |

## Section-specific strategies

### Reading
1. Identify task type before deep reading (words / daily life / academic).
2. For academic passages: capture main claim + support; ignore trivia.
3. Complete-the-Words: use morphology and local context; do not invent off-text facts.
4. Daily-life texts: prioritize purpose, deadline, and next action.
5. Keep a per-type error tag in `<state_root>/toefl/sections/reading.md`.

### Listening
1. Active notes: intent, numbers, contrasts, next steps — not full transcripts.
2. Conversation / announcement: speaker purpose first, then constraints.
3. Academic talk: structure markers (however, for example, in contrast).
4. Response-choice items: eliminate replies that miss tone or obligation.
5. Practice with varied accents; keep volume and note tools consistent with test rules.

### Speaking

| Task | Strategy |
|------|----------|
| Listen and Repeat | Exact words, clear segments, stable pace; self-score intelligibility |
| Take an Interview | Direct answer → one reason → one concrete example; avoid memorized scripts |

Universal tips:
- Clear beats fast.
- Record and replay daily; mark fillers and unfinished thoughts.
- Natural phrasing scores better than theatrical templates.

### Writing

| Task | Strategy |
|------|----------|
| Build a Sentence | Grammar and word order first; meaning must stay intact |
| Write an Email | Purpose line early; polite ask or information; concrete next step |
| Academic Discussion | Clear position; one new point or nuanced disagreement; respond to others |

Scoring favors clear communication for the task, not ornate vocabulary the user cannot control.

## Practice resources

### Official (prefer first)
- ETS TOEFL iBT free sample / preparation hub
- Official practice tests and prep course materials linked from ETS prepare pages

### Supplementary
- Academic Word List (AWL) for vocabulary breadth
- Short campus-style talks (for Listening stamina only — still finish with official-format items)
- Self-recorded Interview answers with timed prompts

Treat unofficial banks as drill fuel; calibrate difficulty against official samples.

## Error analysis method

### 1. Categorize
| Type | Meaning | Fix |
|------|---------|-----|
| Content | Missed meaning | More targeted exposure |
| Question/task | Misread the ask | Drill that task type |
| Time | Pacing failure | Timed micro-sets |
| Careless | Knew but slipped | Slow verification step |
| Vocabulary | Unknown key word | Add to vocabulary log |

### 2. Log
For each miss: section, task type, real reason, next behavior, review date.

### 3. Spaced re-drill
- Day 3: same task type, new content
- Day 7: similar difficulty
- Day 14: mixed set including the weak type

## Score-improvement prioritization

| Current band (approx.) | Focus |
|------------------------|-------|
| Far below target | Core comprehension + high-frequency task types across all sections |
| Near target (small gap) | Weakest two sections only |
| At/above target | Maintain strong areas; polish remaining task-type leaks |
| Retake with one weak section | Single-section intensity + full mixed set weekly |

Typical ROI order for many learners: Reading task accuracy → Writing task fit → Listening detail/intent → Speaking intelligibility and answer completeness. Reorder from the user's actual error log.

## Mock protocol

### Frequency
- Broad mixed mock: every 1–2 weeks
- Task-type drills: daily on weak types
- Full sitting simulation: when score gap is small and deadline is inside 4–6 weeks

### After each mock
1. Score immediately on the scale the school uses (and 1–6 if practicing post-2026 form)
2. Review every miss the same day
3. Categorize errors
4. Update weak-area priorities in `<state_root>/toefl/sections/`
5. Adjust the next week's plan only when the evidence changed
