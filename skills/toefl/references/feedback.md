# Feedback & Self-Improvement System

Store the live log at `<state_root>/toefl/feedback.md` after state-root resolution.

## Feedback loop

### Track what works

```markdown
## Effective Strategies
- Speaking: daily Listen and Repeat + interview recording improved intelligibility
- Writing: purpose-first emails beat ornate vocabulary
- Reading: task-type tagging before deep reading
- Listening: symbol notes for contrasts and next actions
```

### Track what does not work

```markdown
## Ineffective Approaches
- Speaking: memorized interview monologues sounded robotic
- Writing: forcing rare words the user cannot control
- Listening: trying to transcribe every word and missing the question
```

### Evolving insights

```markdown
## Evolving Insights
- Academic Discussion: shorter, clearer posts beat long rambling
- Interview answers: one concrete example outperforms three vague claims
- Reading Complete-the-Words: morphology + local context beats global topic guesses
```


## Progress stalls

If scores are flat for 2+ weeks:
1. Confirm practice is task-targeted, not random volume
2. Confirm error analysis is written the same day
3. Check for an unlogged weak task type
4. Change technique before adding hours

### Plateau interventions (examples)

```markdown
## Plateau Interventions
- Speaking stuck: dropped scripts → structured interview answers with one example
- Writing stuck: cut rare vocabulary → clearer email purpose and discussion stance
- Listening stuck: practiced intent/next-action questions before detail hunts
```
