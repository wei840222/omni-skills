## University score requirements (planning defaults)

| Program type | Typical published range (often still 0–120) |
|--------------|-----------------------------------------------|
| Top US MBA / highly selective grad | High overall (commonly 100+ on 0–120 while schools migrate) |
| Broad US graduate | Often 90–100 on 0–120, or equivalent 1–6 once updated |
| Many US undergraduate | Often 80–90 on 0–120 |
| UK / Canadian universities | School-specific; some prefer IELTS |

When a school only lists 0–120 numbers after Jan 2026, help the user map practice 1–6 results with the ETS comparison table and note the transition overall on the official report.

### MyBest acceptance patterns

| Pattern | What to do |
|---------|------------|
| Accepts MyBest / superscores | Track best sections across valid tests; still prepare for a strong single sitting |
| Single-sitting only | Optimize one test date; MyBest is informational only |
| Unknown | Open the program English-requirements page; do not guess |

Examples change yearly (MBA vs PhD policies differ). Never hard-code a school as permanent MyBest-yes/no without a fresh URL.

## Immigration and status notes

| Destination / path | TOEFL role |
|--------------------|------------|
| US F-1 / university study | University sets the English bar; visa does not replace school requirements |
| US H-1B / employment | Not a universal TOEFL mandate; employer or licensing body may ask for proof of English |
| Canada Express Entry | IELTS/CELPIP (and other IRCC-accepted tests) dominate; do not treat TOEFL as interchangeable without checking the current IRCC list |
| UK student / skilled routes | University or Home Office/UKVI lists control acceptance; IELTS/PTE often preferred for some routes |
| Australia student / skilled | TOEFL may be accepted for some student routes; skilled points frameworks often feature IELTS/PTE — verify the current instrument |

If the user's goal is immigration points rather than a US-campus classroom, evaluate whether `ielts` is the better primary skill.

## Score-sending strategy

### Timeline (work backwards)
1. Application or employer deadline
2. Recipient processing buffer (school portal lag)
3. ETS delivery window (electronic feeds often multi-business-day; postal much slower)
4. Score availability (~3 days after test per ETS understand-scores guidance)
5. Preferred test date ≥ **3–4 weeks** before hard deadlines when official reports are required; longer if postal or peak season

### Cost optimization
- Use the free score-recipient slots included with the test fee when destinations are known early
- Additional reports are per institution/agency at the current ETS fee
- Selecting recipients can interact with score-review eligibility — read the send-scores page before locking choices

### What to send

| Application type | Typical expectation |
|------------------|---------------------|
| US graduate | Official ETS send required for final review |
| US undergraduate | Sometimes self-report first, official later |
| UK / Canada / AU | Follow each school's or agency's current channel |

## Waivers and alternatives

### Common waiver themes
- Degree taught in English in an approved country/institution
- Citizenship or long-term study in an English-majority system
- Program-specific alternate evidence

Always check the **program** waiver text; national stereotypes are not waivers.

### Alternative tests (route, don't blur)

| Test | When to consider |
|------|------------------|
| IELTS Academic/GT | UK/AU/CA pathways; schools that list IELTS bands |
| Duolingo English Test | Cost/speed when the school explicitly accepts it |
| PTE Academic | Some UK/AU immigration and university lists |
| Cambridge C1/C2 | Less common for US admissions; check Europe-facing programs |

Approximate concordance tables are rough. Prefer the institution's own concordance or minimums.

## Decision framework

### Retake?
- Large gap vs target and time remains → plan a retake with task-type focus
- Tiny gap → weigh essays/GPA/experience vs another sitting cost
- Already above target → retake only for scholarships, section floors, or single-sitting rules that MyBest cannot satisfy

### Which test family?
- US universities primary → TOEFL iBT is usually the default
- Canada immigration points → start with IRCC-accepted options (often IELTS/CELPIP)
- Mixed multi-country plan → build a matrix of accepted tests before buying two prep systems
