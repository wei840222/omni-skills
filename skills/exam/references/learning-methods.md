# Learning methods and calibration

Use these principles when choosing question difficulty, review cadence, or a study plan. Adapt the plan to the learner's available time and actual performance rather than treating any interval as universal.

## Retrieval practice

Prefer questions that make the learner retrieve an answer before seeing it. Include an explanation after the answer and use missed concepts to select the next practice set. Recognition-only prompts can supplement review, but they are not a substitute for retrieval.

Source: The Learning Scientists, "Retrieval Practice" — https://www.learningscientists.org/blog/2016/6/23-1

## Spaced practice and interleaving

Spread revisits over time and mix related topics once the learner has basic familiarity. Start with a cadence the learner can sustain, then adapt it from observed accuracy, forgetting, and the exam date. A fixed `1/3/7/21` schedule is only an example, not a universal algorithm.

Source: The Learning Scientists, "Spaced Practice" — https://www.learningscientists.org/blog/2016/7/21-1

## Difficulty calibration

Use the cognitive demand of the target assessment and supplied material:

| Level | Primary demand | Example task |
|-------|----------------|--------------|
| Easy | Recall and define | Identify a term or fact |
| Medium | Apply and compare | Choose an approach for a described case |
| Hard | Analyze, evaluate, and create | Diagnose a trade-off or design a solution |

Raise difficulty only after performance on prerequisites supports it. For multiple-choice questions, write plausible distractors based on common misconceptions and explain why the selected answer is correct.

## Flashcard scheduling

If the user asks for SM-2-compatible scheduling, use the algorithm's documented quality response and interval mechanics. If the user is using another scheduler (for example, an application-specific algorithm), export cards in the requested format and let that scheduler own due dates rather than claiming SM-2 behavior.

Source: Piotr Woźniak, "Application of a computer to improve the results obtained in working with the SuperMemo method" — https://www.supermemo.com/en/archives1990-2015/english/ol/sm2

## Source and exam boundaries

- Treat supplied notes as the authority for questions about those notes.
- For a named live certification, retrieve the current official exam guide before asserting the question count, time limit, passing score, or domain weighting.
- State uncertainty when the source material is incomplete; ask for the missing blueprint or material instead of fabricating details.
