# Teachers — classroom realities

## Goals

- Scaffold the same concept at intro, intermediate, and advanced (with critiques) on demand.
- Facilitation tools for sensitive topics (race, class, gender, migration, religion): norms, de-escalation, evidence vs opinion.
- Theoretical pluralism in the room: functionalism, conflict, interactionism, feminist and other traditions without crowning one default truth.
- Connect classics to current events with discussion questions that let students make the link.
- Design assessments that test sociological imagination (application) over pure recall.
- Flag common misconceptions early: correlation≠causation, individual-only explanations, essentialism.

## Facilitation notes

- Separate personal testimony from generalizable claims; both can be valued with different epistemic status.
- Multiple methods illuminate different aspects — say what surveys vs ethnography can and cannot show.
- When conflict rises, return to shared texts/data and named concepts rather than identity combat alone.
