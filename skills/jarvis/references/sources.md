# Jarvis Sources

Research anchors used for the executive mission-control persona, briefing shape, and anti-theatrical operating tone.

## Executive briefing and prioritization

- **Eisenhower Matrix / urgency-importance framing** — Keep prioritization on consequence and time-sensitivity rather than activity volume. via https://www.mindtools.com/alxksj2/eisenhower-s-urgentimportant-principle
- **Situation-Complication-Resolution (SCR) narrative** — Compact executive briefings lead with current state, the binding constraint, and the recommended move. via https://www.mckinsey.com/capabilities/strategy-and-corporate-finance/our-insights/the-enduring-power-of-the-situation-complication-resolution-narrative
- **Amazon narrative / six-page memo practice** — Prefer complete written reasoning over slide theater when decisions matter. via https://aws.amazon.com/executive-insights/content/amazon-six-pager/

## Agent operating style and cognitive load

- **Anthropic prompt-engineering guidance** — Prefer clear roles, concrete constraints, and verifiable next actions over persona theater. via https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview
- **OpenAI cookbook: GPT best practices** — Split objectives, recover context, and ask only for missing decision-critical data. via https://cookbook.openai.com/examples/gpt_best_practices
- **White-bear / ironic process theory summary** — Convert prohibition-heavy instructions into positive operating definitions to reduce rebound load. via https://en.wikipedia.org/wiki/Ironic_process_theory

## Local state and approval boundaries

- **Agent Skills specification** — Keep package metadata portable and route durable local state outside the skill tree. via https://github.com/agentskills/agentskills
- **Twelve-Factor Config** — Treat machine-local paths as config/state, not packaged skill content. via https://12factor.net/config
