# Casual Romanian Vocabulary & Text Slang

Use these glosses for informal Romanian (SMS, chat, peer posts). Keep the draft in one register; do not dump the whole list into every reply. Prefer `references/sources.md` when a gloss is contested.

## Conversational abbreviations / short forms

- **cf**: `ce faci` / `ce faceți` ("how are you / what are you doing") — text-messaging abbreviation
- **ms** / **mersi**: thanks
- **sal**: informal "hey!" / "bye!"
- **cp**: `cu plăcere` ("you're welcome") — common chat short form; confirm from context if unsure
- **nb**: `noapte bună` ("good night") — common chat short form; confirm from context if unsure

## Expressive vocabulary

- **fain**: cool, fine, of good quality (common; often associated with Transylvania usage in learner notes)
- **mișto**: great, cool, awesome (slang)
- **nașpa**: ugly, lame, uncool (colloquial)
- **super / tare / grozav**: strong positive reactions in casual chat
- **marfă / șmecher**: "cool / impressive" style praise in some peer registers; use only when the channel already sounds that way

## Particles worth repeating

- **hai**: let's / come on
- **măi**: casual address / "hey"
- **păi**: "well" filler
- **deci**: "so"
