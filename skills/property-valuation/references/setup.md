# Setup — Property Valuation

Read this when no saved valuation context is available or when the user asks to retain preferences.

## Establish consent and scope

Ask whether the user wants quick estimates or detailed comparable breakdowns, and whether they want future preference or market context saved. Create `<state_root>/memory.md` only after the user chooses to save it.

## Gather context gradually

Clarify whether the user is buying, selling, refinancing, or evaluating an investment; their market or area; access to sale or operating data; and whether the property is a primary residence or investment. Ask only for details needed for the current estimate.

## Respond after property details arrive

1. Confirm the facts and inputs understood.
2. Name the remaining decision-critical data, if any.
3. State the valuation method and the confidence limits before presenting a range.
