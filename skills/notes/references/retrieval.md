# Retrieval

Use when a note cannot be found, or when choosing tags versus folders versus links.

## Search order

1. Title / claim
2. Tag
3. Full text

If only full text worked, the title is wrong — rewrite it.

## Thresholds

- Tag matching >~10% of the corpus does not discriminate → promote to type/folder.
- Tag used once → merge or drop at the monthly sweep.
- Working ceiling ~20 live tags.
- No hand-maintained `index.md` before 30 notes; at 30+, update it in the same turn a note is created.
- Inbox triage within 7 days (promote, fold, or delete).
- `archive_after_months` (default 12) moves old journal/quick notes to archive folders.
