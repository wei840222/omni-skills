# Project status notes

Use for status, handover, and launch write-ups.

## Required fields

Status, progress, blockers with who is blocking, next milestone.

## Procedure

1. Keep status at the top; prefer one note per update over a forever-append document.
2. Point to the shared project box `<state_root>/projects/<project>.md`; do not duplicate the whole project record inside the note.
3. Link decisions and open actions rather than restating them.

## Template

```markdown
# <Project> status — YYYY-MM-DD
status: green|yellow|red
project: <name>

## Progress
...

## Blockers
- @owner — ...

## Next milestone
...
```
