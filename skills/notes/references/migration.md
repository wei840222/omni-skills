# Migration

Use when leaving an app, importing a corpus, or exporting a vault.

## Before committing

1. Build a fidelity matrix: what survives (text, checkboxes, tags, links, attachments, databases).
2. Export a sample and **restore one note** into the target before migrating the corpus.
3. Expect Notion markdown exports to flatten nested databases/views; Evernote HTML often loses checkboxes.
4. Keep credentials and private third-party data out of intermediate export folders that sync broadly.

## During migration

- Move in batches; name how many notes each batch touches.
- Preserve claim titles and absolute action dates.
- Leave a pointer from old homes when dual-running briefly; do not edit both copies.
