# Research workflow

## Establish the claim

1. State the research question and identify whether it concerns an observation, an inferred physical quantity, or a theoretical model.
2. Select an authoritative catalog, mission archive, or literature index appropriate to the object and wavelength range.
3. Record the data release, query, selection criteria, coordinate frame, epoch, and units before interpreting results.
4. Preserve both statistical and systematic uncertainty. Name assumptions that can dominate the result, such as extinction correction, distance model, calibration, population selection, or background subtraction.

## Literature and data sources

- Use NASA ADS for astronomy literature discovery and citation identifiers.
- Use the archive for the relevant observatory or survey for primary data and instrument documentation.
- Use SIMBAD or NED for cross-identification only after checking object aliases and coordinate conventions.
- Use TAP/ADQL or archive APIs with bounded queries, then retain the exact query and result version for reproducibility.

## If a result conflicts

Compare object identity, coordinate epoch, units, sample selection, data release, calibration, and uncertainty treatment before treating sources as contradictory. Report unresolved differences as a limitation and identify the next verification step instead of combining incompatible values.

## Authoritative sources

- NASA Astrophysics Data System: https://ui.adsabs.harvard.edu/ — literature discovery, bibliographic identifiers, and citation metadata.
- NASA Science — The Universe: https://science.nasa.gov/universe/ — current, public-facing overview of NASA universe science.
- NASA Science — Black Holes: https://science.nasa.gov/universe/black-holes/ — primary-agency explainer for black-hole concepts and current mission context.
- NASA Exoplanets: https://science.nasa.gov/exoplanets/ — mission and discovery context for exoplanet questions.
