# Current Information and Source Checks

Use this reference when an answer depends on a fare, price, availability, visa rule, admission policy, safety condition, or other time-sensitive detail. Treat the package's dated figures as planning estimates, not live quotes.

## Check the Current Source Before Giving a Decisive Answer

| Topic | Authoritative source | What to verify |
|---|---|---|
| Public transport and fares | Île-de-France Mobilités — https://www.iledefrance-mobilites.fr/en/tickets-fares | Ticket products, zones, eligibility, prices, and validity. |
| Paris transit operations | RATP — https://www.ratp.fr/en | Service status, route changes, accessibility, and station information. |
| Visitor planning | Paris je t'aime — https://parisjetaime.com/eng/ | Official visitor information and destination guidance. |
| Museums and monuments | The venue's official website | Opening hours, timed-entry rules, access conditions, and admission prices. |
| Visas and residence | France-Visas — https://france-visas.gouv.fr/en/ | Nationality-specific visa requirements and application process. |
| Public administration | Service-Public.fr — https://www.service-public.fr/particuliers/vosdroits/N19808?lang=en | Current official immigration and residence guidance. |
| Higher education | Campus France — https://www.campusfrance.org/en | Study routes, application guidance, and official student information. |
| Paris rental reference rents | Paris.fr — https://www.paris.fr/pages/encadrement-des-loyers-a-paris-2712 | Current rent-control rules and official rent-reference resources. |

If an official site is inaccessible, say that the live value could not be verified, retain the package value only as a dated estimate, and direct the user to the listed source. Do not present an estimate as a current official price or rule.

## Freshness Classes

- **Time-sensitive:** fares, rent, salaries, food and hotel prices, tuition, tax, visa thresholds, venue admission, service schedules, and startup funding.
- **Stable-domain:** neighbourhood character, transit-system roles, common scam patterns, and general planning heuristics. Still qualify location-specific safety judgments and use current official advice when stakes are high.

## Practical Answer Pattern

1. Identify the user's travel dates, nationality or residence status when relevant, budget, and accessibility needs.
2. Load the matching topical reference from `SKILL.md`.
3. Verify time-sensitive facts at the official source above before making a booking, immigration, payment, or safety recommendation.
4. Separate verified facts from estimates and explain any live-information gap.
