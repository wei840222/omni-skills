# Drafting and operative language

Load when writing words, cleaning ambiguity, building signature blocks, or checking e-sign validity.

## Operative discipline

- Define every term used in money or exit clauses
- Prefer operative verbs ("shall pay", "may terminate") over narrative
- State precedence when documents stack: MSA → order form → SOW → policies
- Pin URL-incorporated terms to a dated version or attach the PDF
- Know the default rule of the governing law before deleting a clause — deletion fills the statutory/common-law default, which can be worse

## Contra proferentem

Ambiguity construes against the drafter only after meaning fails, and many commercial contracts disclaim it. It is a tiebreaker, not a shield. Draft clearly; when reviewing, list undefined money/exit terms and define them.

## Parties and authority (Rule 7)

- Exact registered legal name + entity form (not trade name)
- Signer authority from delegation matrix or board consent — not job title alone
- Method the jurisdiction accepts

## Electronic signatures

Generally valid for commercial contracts under:

- United States: ESIGN Act (2000) and state UETA adoptions
- European Union: eIDAS Regulation (EU) No 910/2014

Recurring carve-outs: wills and testamentary instruments, some real-property transfers, certain notarised or witnessed instruments. Verify local carve-outs before relying on e-sign for those categories. Source notes in `references/sources.md`.

## Execution block checklist

1. Party legal name and form
2. Signatory name + title + authority basis
3. Date and counterpart clause if needed
4. Witness/notary only when the instrument type requires it
