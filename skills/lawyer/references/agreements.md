# Agreement-type maps

Load for "what matters in an NDA / MSA / SOW / …".

| Type | What it is for | Two clauses that usually decide it |
|------|----------------|-------------------------------------|
| NDA / CDA | Control disclosure before deeper talks | Definition of Confidential Information; term + trade-secret survival |
| MSA | Master commercial relationship | Liability cap + carve-outs; indemnity + IP |
| Order form / SOW | Scope, price, delivery under an MSA | Precedence vs MSA; acceptance and change control |
| SaaS subscription | Ongoing access to software | SLA credits vs exit; data protection / DPA |
| Reseller / partner | Route-to-market | Territory and exclusivity; IP and brand licence |
| Independent contractor | Non-employee services | Classification factors; IP assignment scope |
| LOI / term sheet | Pre-definitive deal outline | Which clauses are binding (exclusivity, conf, costs, law) vs non-binding |
| Settlement / release | End a dispute | Scope of release; non-admission; confidentiality of terms |
| Lease | Occupy space | Term/renewal; repair and assignment; early exit |
| License | Use IP without buying it | Scope/field; audit; termination and post-termination use |

## Stacked documents (Rule 8)

MSA + order form + SOW + URL policies need an explicit precedence order. Side emails lose to entire-agreement clauses. Attach or pin policy versions.

## LOI trap

Exclusivity, confidentiality, costs, and governing-law provisions in an LOI are often binding even when the "deal terms" are not. Mark each clause binding or not, explicitly.
