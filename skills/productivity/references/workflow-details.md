# Productivity workflow details

## Diagnose before designing

Use the smallest matching intervention.

| Signal | Primary bottleneck | First intervention |
| --- | --- | --- |
| Everything is urgent | More committed work than capacity | Rank, cut, defer, or renegotiate one item. |
| Knows what matters but cannot start | Action is ambiguous or emotionally loaded | Define a visible two-minute physical action. |
| Busy day, nothing shipped | Meetings, messages, or context switching | Protect one block and batch the reactive work. |
| Replans repeatedly | Planning has become avoidance | Freeze the plan; execute the next physical action. |
| Misses estimates | Planning uses ideal time | Apply a local calibration ratio and add a buffer. |
| Starts habits then stops | Plan has no minimum version | Restart with the smallest version and review the friction. |

## Capacity and WIP

Compute available focused hours from the user's actual week, subtracting fixed commitments. Compare it with the sum of each due item's estimate multiplied by the local calibration ratio. A positive gap means scope, dates, or commitments must change before scheduling.

Use a default WIP limit of three active projects when the user has not chosen one. Starting another project requires parking, finishing, delegating, or declining an existing one.

## Planning sequence

1. List commitments due in the horizon.
2. Estimate only the work that must be decided now.
3. Reserve a buffer before allocating work.
4. Select one must-win outcome and the next physical action for each active project.
5. Put demanding work in the user's observed higher-energy window; reserve fragmented windows for coordination and administration.
6. At the next review, compare estimate and actual, then revise the plan rather than defending it.

## Weekly review

Keep the review small enough to repeat:

1. Capture loose commitments.
2. Close, delegate, defer, or delete stale items explicitly.
3. Check upcoming deadlines and waiting items.
4. Recompute capacity and select the next must-win outcome.
5. Write one sentence about a recurring friction and its countermeasure.

## Recovery-aware planning

Treat sleep, care obligations, health needs, and recovery as capacity constraints. A plan that relies on routine sleep loss or an uninterrupted eight-hour day is invalid. When work repeatedly exceeds capacity, change scope, support, staffing, or expectations rather than adding a more elaborate productivity ritual.
