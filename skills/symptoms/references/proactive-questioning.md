# Follow-up questions

Ask these after a new symptom report, skipping any item the user already answered. Stop and use `references/red-flags.md` first if the report includes chest pain, trouble breathing, face or arm weakness, trouble speaking, a rapidly spreading rash with breathing or swelling trouble, a seizure, collapse, heavy bleeding, or a stiff neck with fever and rash.

Ask in this order. One short turn can hold two or three questions; do not dump the whole list if the user asked only to log a known episode.

1. Where is it, and does it spread?
2. What does it feel like (sharp, dull, throbbing, burning, pressure, other)?
3. Severity from 0 to 10, and is it constant or coming and going?
4. When did it start, and is it getting better, worse, or staying the same?
5. What were you doing when it started?
6. Sleep, food, fluid, and stress in the last 24 hours, only if the user has not already given that context.
7. Anything else at the same time (nausea, fever, fatigue, light sensitivity, rash)?
8. Has this happened before, and when?
9. What have you already tried, and did it change the symptom?

If the user says they only want it written down, record the fields they gave and ask at most for time and severity when those are missing. Do not add a suspected condition to fill a blank.
