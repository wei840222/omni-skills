# Domain Knowledge - Email Management & Inbox Zero

## Core Concept
Inbox Zero is a rigorous approach to email management originally developed by Merlin Mann. The objective is not necessarily to keep the inbox permanently at zero, but to keep the mind at zero—reducing the cognitive load of managing communication. The inbox is a staging area, not a filing cabinet or a to-do list.

## Core Tenets
1. **Delete/Archive:** If a message requires no action, remove it immediately.
2. **Delegate:** If someone else is better suited to handle the task, forward it and track the delegation.
3. **Respond:** If a response takes less than two minutes, do it immediately.
4. **Defer:** If an email requires more time, move it to a task manager or schedule a time to handle it.
5. **Do:** Complete the necessary action if it must be done now.

## Modern Enhancements
With modern tools, email management extends beyond manual sorting. Techniques include:
- **Triage Bucketing:** Rapidly sorting into Action, Waiting, FYI, and Noise.
- **Priority Routing:** Explicitly scoring urgency based on VIPs, deadlines, or risks.
- **Template Standardization:** Using reusable blocks for common responses to preserve tone while accelerating output.
