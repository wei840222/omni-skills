# Domain Knowledge: Quizlet

## Overview
Quizlet is an American education technology company that provides digital study tools. Founded in 2005 by Andrew Sutherland, it has become one of the most widely used platforms for flashcards, practice quizzes, and collaborative learning games (like Quizlet Live). 

## Core Study Modes
- **Flashcards:** Passive review mode useful for fast recall warmups.
- **Learn Mode:** An adaptive study mode utilizing spaced repetition concepts. It dynamically adjusts question frequency based on whether the user answers correctly, moving cards from "Unseen" to "Familiar" to "Mastered".
- **Test Mode:** Simulates exam conditions. Users can configure question types (multiple choice, written, matching, true/false) and set time limits.
- **Match:** A time-based game where users match terms to definitions as quickly as possible.

## Recent Features
- **Quizlet Plus:** A premium tier that offers advanced features like offline access, ad-free studying, and enhanced content creation tools.
- **Q-Chat:** An AI tutor powered by OpenAI's ChatGPT API, introduced in 2023, which helps students study through conversational interaction.
- **Magic Notes / AI Features:** Features allowing users to turn their notes into flashcards and study guides automatically.
- **Course-Powered Quizlet:** A feature organizing study materials by institution and course for collaborative studying.

## Best Practices for Set Design
- **Atomic Cards:** Each card should test a single concept, fact, or decision. Multi-answer prompts lead to false confidence.
- **Strategic Mode Selection:** Use Learn mode for early acquisition and spaced repetition. Use Test mode to verify recall under simulated exam conditions. Rely on Learn and Test modes for true recall, as Flashcards primarily build recognition.
- **Diagnostics & Weak Cards:** Users should identify recurring misses and rewrite those cards to reduce ambiguity and improve retention.
