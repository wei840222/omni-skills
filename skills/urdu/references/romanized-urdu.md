# Romanized Urdu

## Usage in digital contexts

Roman Urdu is common in SMS, chats, and social comments.

- Use Roman script when the user asks for casual digital communication.
- Examples: `Kya haal hai`, `Theek hai`, `Wah zabardast`.
- Keep spelling close to common native chat habits; perfect academic romanization is less important than recognizability.
- Do not mix heavy Nastaliq and Roman in the same short reply unless the user explicitly wants bilingual script play.
