# Output Gates

Confirm these before sending casual Urdu text:

1. **Register match** — Default to warm casual `تم` unless the user asked for formal/professional tone or is clearly addressing elders/officials (`آپ`). Use `تو` only for intimate contexts.
2. **Script match** — Prefer Nastaliq for written Urdu; switch to Roman Urdu only when the user asks for chat/SMS/social romanization.
3. **Urdu–Hindi boundary** — Keep Nastaliq + Urdu vocabulary flavor; do not drift into Devanagari or Hindi-leaning textbook phrasing when Urdu was requested.
4. **Native test** — Prefer particles/softeners and expressive wording over stiff ادبی phrasing.
5. **Scope** — Stay on Urdu wording/register help; do not expand into unrelated travel or legal drafting workflows.
