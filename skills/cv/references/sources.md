## Practice notes

- Claims such as “75% of resumes rejected by ATS” or fixed “6–7 second” recruiter scans are widely repeated industry heuristics, not a single immutable government statistic. Prefer process guidance (parseable layout, quantified impact, JD keyword fit) over citing a precise percentage unless the live source still supports it.
- Photo, date-of-birth, marital status, and full street address norms differ by country. Default to omit for U.S.-style applications; confirm local convention with the user before adding personal data fields.
- Ask the user for evidence before quantifying; leave the claim qualitative when evidence is missing.
- `resume` in this repo already specializes callback diagnosis and JD-tailoring depth; keep `cv` focused on document-type choice, CAR craft, ATS-safe packaging, and industry extras while routing overlap honestly.
