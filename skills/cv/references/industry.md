# Industry Packaging — Tech and Design

Load when the target role is software/engineering/IT or design/UX product design.

## Tech / engineering

Include when available and truthful:

- GitHub (or equivalent) profile URL
- Skills grouped by category (Languages, Frameworks, Cloud, Tools)
- Projects with live links or repo links
- Scale metrics (users, RPS, data volume, latency, reliability)

Example skills block:

```text
Languages: Python, TypeScript, Go
Frameworks: React, FastAPI, Django
Cloud: AWS (EC2, Lambda, S3), GCP
Tools: Docker, Kubernetes, Terraform, GitHub Actions
```

Prefer current, role-relevant stack language. Drop obsolete tech and filler phrases such as "Proficient in Microsoft Office" unless the posting explicitly values them. Use precise titles rather than novelty titles ("Code Ninja").

## Design / UX

Include when available and truthful:

- Portfolio link near the top (often immediately under the name)
- Tools actually used (for example Figma, Sketch, Adobe CC)
- Process language: user research, wireframing, prototyping, usability testing
- Impact metrics: conversion, task success, satisfaction, time-on-task

Pair tools with methodology and outcomes. A tool list without process or impact is a weak signal for design hiring.

## Cross-cutting

- Match vocabulary to the posting before inventing a personal taxonomy.
- Keep links HTTPS and human-testable.
- If a portfolio or GitHub is private, say so and offer a share path rather than a dead link.
