# Length Bands and Pre-Submit Checklist

Load before finalizing length or running a last-pass checklist.

## Length guidelines (industry resume)

| Experience | Typical length |
|------------|----------------|
| Student / entry-level | 1 page |
| 1–5 years | 1 page |
| 5–10 years | 1–2 pages |
| 10+ years / executive | up to 2 pages for most industry targets |
| Academic CV | content-driven; may exceed 2 pages |

For senior industry resumes, condense early-career roles to 1–2 lines when space is tight. Academic and some EU/UK CVs follow completeness over hard page caps—confirm the user's market.

## Pre-submit checklist

```text
□ Professional email address
□ Summary tailored to target role
□ Majority of bullets include evidence/metrics (or marked unknown)
□ Skills and keywords align with the job description where truthful
□ Acronyms + full forms for critical terms when both are used in-market
□ Consistent formatting and date style
□ Length matches experience band / document type
□ Text-selectable PDF or DOCX
□ Filename: FirstName_LastName_Resume.pdf (or CV)
□ LinkedIn / portfolio / GitHub links match the document
□ Single-column layout without table/text-box structure
□ Spell-check completed
□ U.S.-style applications omit photo / DOB / marital status / religion / full street address unless user confirmed another market norm
```
