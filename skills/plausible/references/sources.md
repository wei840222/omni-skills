# Official Sources & API References

This document records the official documentation and API references for the Plausible Analytics platform.

## Official Documentation & API Endpoints

- **Plausible Stats API**:
  - Documentation: [https://plausible.io/docs/stats-api](https://plausible.io/docs/stats-api)
  - Endpoints: Realtime visitors (`/api/v1/stats/realtime/visitors`), aggregate metrics (`/api/v1/stats/aggregate`), time-series breakdowns (`/api/v1/stats/timeseries`), and breakdown dimensions (`/api/v1/stats/breakdown`).
- **Plausible Events API**:
  - Documentation: [https://plausible.io/docs/events-api](https://plausible.io/docs/events-api)
  - Custom event transmission, automated referrer tracking, and server-side tracking via POST to `/api/event`.
- **Custom Event Goals & Properties**:
  - Documentation: [https://plausible.io/docs/custom-event-goals](https://plausible.io/docs/custom-event-goals)
  - Setting up goal conversions, funnel analysis, and custom dimension property filtering.
