# First-run setup — Tenerife

Use when `<state_root>/memory.md` is missing or empty and the user wants continuity.

## Intake (natural conversation, not a form dump)

1. **Role** — visitor, digital nomad, retiree, family relocating, or business?
2. **Month / duration** — which season and how many days or months?
3. **Must-haves** — beach daily, culture, hiking, nightlife, schools, coworking?
4. **Car comfort** — happy to drive mountain roads, or prefer transit-heavy bases?
5. **Budget band** — rough monthly housing + lifestyle target.
6. **Admin path** — EU citizen, short-stay visitor, or exploring a residence visa?

## After intake

- Copy `assets/memory-template.md` into `<state_root>/memory.md` only if the user
  wants memory kept.
- Recommend **one primary base** and one backup using `references/zones-choosing.md`.
- For visitors, offer a 1/3/7-day frame from `references/visitor-itineraries.md`.
- For nomads, pair base + coworking via `references/nomad.md` and
  `references/coworking.md`.
- Before any visa or tax number, open `references/sources.md` live pages.

## Do not store

- Passport images, full NIE/ID numbers, bank credentials, or private keys.
- Irreversible bookings without the user confirming live availability.
