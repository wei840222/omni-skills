# Briefing — Stock Market

Create `<state_root>/briefing-log.md` using the Briefing Template in `assets/templates.md` (a path rooted at this skill package) only when persistent state is enabled and the user approves creation.

## Operating Guidance

1. Include source, as-of time, and timezone for each current market or event claim.
2. In the post-market response, include both trade and no-trade outcomes.
3. Update persistent watchlist priorities only when state is enabled and the user approves that update.
4. If rule breaks occurred, propose a corrective rule; retain it only when state is enabled and the user approves that update.
