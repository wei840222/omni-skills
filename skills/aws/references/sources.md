# Official Sources & Architecture Frameworks

This document records the official Amazon Web Services (AWS) documentation and architectural pillars.

## Official AWS Documentation

- **AWS Documentation Home**: [https://docs.aws.amazon.com/](https://docs.aws.amazon.com/)
  - Comprehensive service guides, API references, and SDK manuals across all AWS cloud products.
- **AWS Identity and Access Management (IAM)**: [https://docs.aws.amazon.com/iam/](https://docs.aws.amazon.com/iam/)
  - Policy evaluation logic, Service Control Policies (SCPs), permissions boundaries, and IAM role trust relationships.
- **Amazon VPC Networking**: [https://docs.aws.amazon.com/vpc/](https://docs.aws.amazon.com/vpc/)
  - VPC CIDR sizing, route tables, internet/NAT gateways, security groups vs network ACLs, and VPC endpoints (PrivateLink).
- **AWS Well-Architected Framework**: [https://docs.aws.amazon.com/wellarchitected/latest/framework/the-pillars-of-the-framework.html](https://docs.aws.amazon.com/wellarchitected/latest/framework/the-pillars-of-the-framework.html)
  - Six operational pillars: Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, and Sustainability.
