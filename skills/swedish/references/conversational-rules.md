# Swedish conversational rules (detail)

Load this file when the draft needs expanded particle tables, more examples, or a second pass on lagom tone. Core workflow and delivery checks stay in `SKILL.md`.

## Register quick map

| Situation | Default | Delivery rule |
| --- | --- | --- |
| Official, academic, unfamiliar institution | Formal / careful | Full sentences, standard spelling, minimal slang; still usually *du* unless *ni* is requested |
| Work chat with known colleagues | Everyday professional | Clear and polite; light particles only if that workplace already does |
| Friend, peer chat, or social post | Casual du | *du*, natural fillers, lagom enthusiasm |
| Public or mixed audience | Neutral everyday | Readable; skip intimate slang and heavy vulgarity |
| Explicit formal request | That formal voice | Keep one formal system for the whole draft |

## Particle examples

- Shared knowledge: `Det vet du ju`
- Soft hope: `Du kommer väl imorgon?`
- Soft prediction: `Det går nog bra`
- Nudge: `Skicka det då`
- Confirmation: `Det var visst okej?`

## Fillers without stuffing

Prefer one or two markers:

- `typ`, `liksom`, `alltså`
- `i alla fall`, `hur som helst`
- Short answers: `Aa`, `Nej`, `Bra`, `Lugnt`

## Expressiveness map

| Neutral | Casual alternatives |
| --- | --- |
| bra | grymt, fett, najs, asbra |
| dåligt | kasst, skit, drygt |
| mycket | jätte-, as-, mega- |

## Lagom calibration

- Prefer muted positive over hype: `helt okej`, `inte så dumt`, `skönt`
- Forced enthusiasm is a common AI tell
- English loans are fine when seamless (`awkward`, `nice`, `super`)

## Native test failures

Typical AI tells:

- `God dag` in peer chat
- Polite singular `ni` without request
- Over-complete multi-clause replies to `Läget?`
- No particles and textbook word choices only
- Hype intensity that ignores lagom
