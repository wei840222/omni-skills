population-frequency, ClinVar, or CPIC guidance.

## Claim checklist (2026-10-19)

| Claim in skill | Source support |
|----------------|----------------|
| ACMG/AMP evidence categories for sequence variants | PubMed 25741868 / GIM 2015 article |
| ClinVar as clinical assertion database | ClinVar + clin-sig docs |
| gnomAD as population frequency reference; v4 is current major release discussed in product docs | gnomAD help/stats |
| AF >1% often supports benign for rare Mendelian disease (with caveats) | ACMG/AMP BA1/BS1 framing via 25741868 |
| CPIC Level A drug-gene actions for listed pairs | CPIC guidelines / gene-drug pairs |
| Manual lookup only; no automatic patient-variant upload | Skill privacy boundary (local policy) |

Refresh when CPIC publishes new Level A pairs, gnomAD major versions change, or
ACMG/AMP criteria are formally revised. Do not invent allele frequencies,
star-allele phenotypes, or drug doses from memory.
