# Monetization models & paywall design

Load when choosing freemium vs trial vs subscription, placing a paywall, or sanity-checking consumer price anchors.

## Model selection

| Model | Best when | Suboptimal when |
|-------|-----------|-----------------|
| **Freemium** | Product has natural limits (storage, seats-as-power, exports, advanced features) | Core job is one finite action the free tier fully completes |
| **Free trial** | Value compounds over days of use | Value is instant and fully delivered in one session |
| **Subscription** | Ongoing value delivery and continuous cost | Pure one-time complete solution with no maintenance |
| **One-time** | Complete durable solution, low ongoing COGS | Costs scale linearly with usage or content |
| **Ads** | Massive scale and low willingness to pay | Premium positioning or high-trust categories |
| **Hybrid** | Distinct segments need different capture models | Extra plans create choice paralysis without segment proof |

## Paywall placement

### Hard vs soft vs metered

| Type | Description | Use when |
|------|-------------|----------|
| **Hard** | Block after N uses or trial clock | Strong activation already proven |
| **Soft** | Limit features, keep access | Habit still forming; viral or network upside |
| **Metered** | Pay per usage | Value varies sharply per user |

### Placement rules

1. **After aha moment** — user must feel value before price.
2. **At a natural limit** — storage full, export needed, advanced feature unlocked.
3. **After first-session value** — keep the first successful outcome uninterrupted when product allows.
4. **Clear upgrade path** — show what they gain, not only what is locked.

## Pricing psychology (heuristic anchors)

Anchors are **starting hypotheses**, not universal price law. Re-validate with willingness-to-pay interviews and local market data.

| Segment | Monthly range (hypothesis) | Annual discount (hypothesis) |
|---------|----------------------------|------------------------------|
| Casual consumer | $2–5 | 15–20% |
| Power user | $8–15 | 25–35% |
| Prosumer | $20–50 | 40–50% |

Tactics that often help conversion quality:

- Show annual price as monthly equivalent when annual is the target plan.
- Mark one target tier as recommended when multi-tier.
- Use crossed-out “original” prices sparingly; heavy discounting attracts churny cohorts.

## Red flags → preferred moves

| Signal | Preferred move |
|--------|----------------|
| Sub-$5/mo with high support COGS | Raise price or cut variable cost before scaling |
| Deep ongoing discounts as the main growth lever | Test value messaging and packaging; discounts as exception |
| Free tier fully solves the primary job | Narrow free scope or switch to time-boxed trial |
| Paywall before any aha | Move gate after first valued outcome |
