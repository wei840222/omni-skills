# Cycle examples

## Writing cycle

**Trigger:** Topic idea
**Done:** Published post with social snippets

```text
Outline → Draft → Self-critique → Revise → SEO → Publish
```

Gates: outline approval; final review before publish.

## Code review cycle

**Trigger:** PR opened
**Done:** Approved and merged

```text
Understand → Test locally → Review → Comment → Re-review → Approve
```

Gates: at least one human approval; CI green before merge.

## Research cycle

**Trigger:** Question or topic
**Done:** Synthesized report with sources

```text
Scope → Search → Filter → Analyze → Synthesize → Format
```

Gates: scope confirmation; source-quality check before synthesis.

## Expense report cycle

**Trigger:** End of week / policy deadline
**Done:** Submitted report with categorized receipts

```text
Gather receipts → Categorize & validate → Manager review → Submit
```

Gates: manager review before submit; reject incomplete receipt sets.
