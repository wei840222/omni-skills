# Kanban knowledge sources

Read this reference when explaining why the workflow requires visible boards, active item management, WIP limits, or explicit improvement. It is a source record, not a runtime dependency.

## Kanban practices

- **The Kanban Guide (May 2025)** — https://kanbanguides.org/the-kanban-guide/2025.5/
  - The official guide defines Kanban as optimizing value flow through three connected practices: defining and visualizing a workflow, actively managing items in the workflow, and improving the workflow.
  - This skill applies those practices through a visible board, deterministic transition and blocker handling, WIP-limit checks, and logged board updates that make improvement reviewable.
