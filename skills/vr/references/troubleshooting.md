# VR PC Troubleshooting and Common Issues

## PC VR Troubleshooting

- SteamVR issues: restart components in this order: SteamVR, headset, PC
- Tracking jitter: inspect lighting, reflective surfaces, and USB bandwidth
- Performance problems: lower supersampling first, then adjust other settings
- Link cable issues: try a different USB port; ensure a USB 3.0 connection is active
- Black screen: verify the display cable connection, update GPU drivers, and check headset firmware

## Common Issues

- Blurry image: adjust headset position on the face, verify IPD settings, and clean lenses
- Controller drift: recalibrate controllers in settings, and install firmware updates
- Battery drain when "off": turn the headset off fully rather than relying on sleep mode
- Fogging: allow the headset to warm up before playing, or apply anti-fog solutions
- Link/AirLink issues: connect via 5GHz WiFi for wireless, and use a dedicated router for best performance
