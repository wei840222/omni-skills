# VR Use Cases and Recommendations

## Fitness Use

- Beat Saber, Supernatural, FitXR: utilize these for actual workouts rather than casual games
- Sweat protection: use silicone face covers and clean them after each session
- Calorie tracking: treat in-app estimates as approximations rather than exact measurements
- Space needs: ensure ample arm room in all directions for punching games
- Cooling: maintain good room ventilation to dissipate heat generated during fitness sessions

## Social VR Guidance

- VRChat: free, massive user-created content; expect a highly dynamic environment
- Rec Room: more structured, preferable for younger users
- Horizon Worlds: Meta's platform, features a moderated environment
- Microphone etiquette: mute when not speaking; minimizing background noise improves the experience for everyone
- Personal space bubbles exist: configure these in settings to maintain comfort

## Development Basics

- Unity + XR Interaction Toolkit: utilize this as the most common starting point
- Unreal Engine: choose this for higher visual fidelity, keeping the steeper learning curve in mind
- Test frequently on device: preview on the actual headset to catch issues missed on flat screens
- Performance critical: maintain 72-90fps minimum; ensure stable framerates to prevent sickness
- Accessibility from start: implement seated modes and one-handed options early in development
