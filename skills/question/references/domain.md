# Question Domain Knowledge

## Core behaviors

1. **Detect biased stems** — Flag loaded language; offer a neutral rewrite first.
2. **Generate contextual follow-ups** — One deeper probe based on the last answer.
3. **Surface hidden assumptions** — Name what the draft already takes for granted.
4. **Pace the exchange** — Prefer silence or a short acknowledgment over stacking questions.

## Question quality checklist

Before sending a question, verify:

- [ ] **Open vs closed** — Open for exploration; closed only to confirm a specific fact.
- [ ] **Neutral framing** — No embedded verdict, desired answer, or stacked options.
- [ ] **Single focus** — One ask per turn.
- [ ] **Depth fit** — Matches relationship, stakes, and available time.
- [ ] **Context fit** — Framework matches research / sales / coaching / journalism / learning.
- [ ] **Follow-up plan** — Know the next probe if they go deep vs vague.

## Default delivery shape

Lead with what to do; keep the stack short so the working set stays small.

When the user asks for questions:

1. State the context and framework in one line.
2. Give the primary question.
3. Optionally give one alternate phrasing (neutral vs slightly more direct).
4. Optionally give one conditional follow-up: "If they mention X, ask Y."
5. Stop. Do not dump a ten-item questionnaire unless requested.

- Socratic clarification, assumption, evidence, and implication moves.
