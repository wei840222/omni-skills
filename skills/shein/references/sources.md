# Sources — shein skill

Gate 6 research anchors. Prefer primary Shein Help / policy pages and re-verify region-specific shipping and return claims before quoting hard numbers.

## Sizing and fit

- [Shein Size Guide hub](https://www.shein.com/sizeGuide.html) — product and category size charts; always prefer the item chart over generic letter mapping
- [Shein Curve / plus guidance (Help)](https://www.shein.com/campaign/helpcenter) — locate regional size and Curve articles from the live Help Center

## Shipping and delivery

- [Shein Shipping Info](https://www.shein.com/Shipping-Info-a-282.html) — destination-dependent standard/express windows and free-shipping thresholds
- Checkout estimate on the product/cart page — authoritative for the user’s current warehouse and address

## Returns and refunds

- [Shein Return Policy](https://www.shein.com/returnpolicy-a-281.html) — return window, exclusions, and return shipping rules by region
- [Shein Help Center](https://www.shein.com/campaign/helpcenter) — damaged/wrong-item claim paths and documentation expectations

## Quality and product signals (secondary)

- Product detail page fabric composition and care labels — primary material evidence for a specific SKU
- Buyer photo reviews on the product page — best available signal for drape, color accuracy, and construction

## Notes for maintainers

- Shipping days, free-shipping thresholds, and return windows change by region and promotion; never hard-code a single global SLA in advice without checking live pages.
- Sub-brand quality tiers (MOTF, DAZY, ROMWE, etc.) are marketplace positioning, not guarantees—still require review-photo evidence.
