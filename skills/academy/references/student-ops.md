# Student Operations

Student operations starts at onboarding, not at cancellation.

## Onboarding

Every new student should know:
- what they enrolled in
- when and where sessions happen
- what success looks like
- how absences, make-ups, and support work
- who to contact when something goes wrong

Confused onboarding creates avoidable support load and weak retention.

## Weekly Signals to Track

Use a short at-risk view with:
- attendance drops
- missed assignments or practice
- engagement decline
- delayed payment
- teacher concern
- mismatch between level and placement

Track only the few signals that predict churn earliest.

## Intervention Ladder

1. light check-in after first warning signal
2. practical fix for friction
3. teacher or advisor follow-up
4. plan adjustment
5. renewal rescue or exit with dignity

The point is speed, not bureaucracy.

## What Usually Causes Churn

- schedule no longer fits
- student does not feel progress
- parent cannot see value
- teacher relationship is weak
- payment friction becomes emotional friction
- onboarding promised one thing and delivery felt different

## Renewal Logic

Renewals should not begin when the term ends.

Start early with:
- progress evidence
- next-step recommendation
- timetable options
- payment path

## Escalation Rule

If a student has both learning risk and payment risk, treat it as a top-priority account.

That combination is where silent churn often happens.

## Evidence anchors

- Early churn usually shows up as schedule friction, weak perceived progress, teacher mismatch, or payment stress before a cancellation request arrives.
- Combined learning-risk + payment-risk accounts need one coordinated plan; separate academic and billing threads create silent churn.
- Renewal work starts with progress evidence and next-step options while the student still feels momentum, not on the final invoice date.

## Failure recovery

| Trigger | First repair | If still failing |
|---|---|---|
| First absence or missed practice | Same-week light check-in with a practical fix | Teacher/advisor follow-up and plan adjustment |
| Parent cannot see value | Send concrete progress evidence and the next milestone | Offer level/teacher/schedule change or clean exit |
| Student asks to cancel | Run save ladder once: fit diagnosis → option set → decision | Exit with dignity and keep referral reputation intact |
