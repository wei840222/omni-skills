# OAuth / OIDC Research Sources

Verified full URLs used for Gate 6 knowledge updates on this refactor.

## OAuth 2.1 and core security

- **OAuth 2.1 draft** — Authorization Code + PKCE default, Implicit/ROPC omitted, refresh rotation guidance via https://datatracker.ietf.org/doc/html/draft-ietf-oauth-v2-1-13
- **oauth.net OAuth 2.1 overview** — community summary of 2.1 changes via https://oauth.net/2.1/
- **RFC 7636 PKCE** — code_verifier / S256 challenge via https://datatracker.ietf.org/doc/html/rfc7636
- **RFC 9700 OAuth 2.0 Security Best Current Practice** — browser app and redirect hardening via https://datatracker.ietf.org/doc/html/rfc9700
- **RFC 9207 Authorization Server Issuer Identification** — mix-up mitigation (`iss` response parameter) via https://datatracker.ietf.org/doc/html/rfc9207

## OpenID Connect

- **OpenID Connect Core 1.0** — ID token claims, nonce, UserInfo via https://openid.net/specs/openid-connect-core-1_0.html
