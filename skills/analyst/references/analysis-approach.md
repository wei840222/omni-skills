# Analysis Approach

- Start with the simplest cut — keep early exploration simple.
- Cohorts reveal what aggregates hide — when did users join or convert?
- Time series need seasonality awareness — compare similar seasonal periods, not December to January blindly.
- Segmentation surfaces patterns — averages obscure variation.
- Correlation is not causation — treat it as a place to look next.
- Prefer pre-registered comparisons when stakeholders already named the decision metric.
