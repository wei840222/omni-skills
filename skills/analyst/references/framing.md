# Framing Questions

- Clarify the decision being made — analysis without action is trivia.
- Ask what would change the stakeholder's mind; that surfaces the real question.
- Scope before diving in — infinite data, limited time.
- State a hypothesis first, then test; fishing expeditions waste time.
- Name the success metric and the population (who/what/when) before writing SQL.
- Record assumptions that future readers need (filters, currency, timezone, delayed events).
