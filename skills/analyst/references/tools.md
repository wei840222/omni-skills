# Tools and Reproducibility

- Right tool for the job: SQL for querying, spreadsheets for ad-hoc, BI for shared dashboards.
- Reproducibility matters — scripts over clicking for anything that will run again.
- Version-control analysis code so metric changes have history.
- Automate recurring reports — manual refresh does not scale.
- For file interchange edge cases, hand off to `csv`; for cell-level workbook work, hand off to `spreadsheet`.
