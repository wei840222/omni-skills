# Study Strategies

## Study Plan Framework

### Phase 1: Diagnostic (Week 1)

1. Take a full Bluebook practice test under real conditions
2. Score and analyze by section/domain
3. Identify top 3 weakness areas
4. Set a realistic target score from baseline + weeks available

### Phase 2: Foundation Building (Weeks 2–4)

Focus on highest-ROI weaknesses:

- If Math < 650: prioritize algebra fundamentals
- If RW < 650: prioritize Standard English Conventions and high-frequency Craft/Information skills
- Daily: ~1 hour focused practice on weak areas
- Weekly: 1 full timed section practice

### Phase 3: Intensive Practice (Weeks 5–8)

- 2–3 full practice tests per week when stamina allows (otherwise 1 full + section drills)
- Deep analysis of every mistake into `<state_root>/mistakes/`
- Timed module drills with flagging practice
- Shift focus to Module 1 accuracy and pacing

### Phase 4: Final Prep (Week before test)

- Light review only — no cramming new systems
- Review mistake log for recurring patterns
- One confidence-building timed section or easier review set
- Sleep and device readiness prioritized (Bluebook install, charger, backup plan)

## Weekly Structure

| Day | Activity | Duration |
|-----|----------|----------|
| Mon | Weak area drilling | 60 min |
| Tue | Timed RW section | 64 min + review |
| Wed | Weak area drilling | 60 min |
| Thu | Timed Math section | 70 min + review |
| Fri | Vocabulary / formulas | 30 min |
| Sat | Full practice test | ~2.5 hours incl. break |
| Sun | Test review + mistake log | 60 min |

Adjust to available time. Rough minimum for meaningful movement: ~10 hrs/week.

## Points-per-Hour Priority

Not all topics are equal. Focus on high-frequency, high-point areas:

**High ROI (always prioritize):**

- Linear equations / systems (Math)
- Grammar fundamentals / Standard English Conventions (RW)
- Core reading comprehension / evidence (RW)

**Medium ROI:**

- Quadratics and nonlinear functions
- Data interpretation
- Punctuation / boundaries

**Lower ROI (if time permits):**

- Advanced trig edge cases
- Rare geometry configurations
- Obscure vocabulary memorization without context

## Spaced Repetition for Vocabulary

Digital SAT stresses **words in context**, not flashcard definitions alone.

1. Add new words to `<state_root>/vocabulary/`
2. Include: word, definition, example sentence, SAT-style usage
3. Review schedule: Day 1, 3, 7, 14, 30
4. Test in context, not isolation

## Practice Test Sources

Prefer official sources when predicting scores:

- College Board Bluebook app (full-length digital practice)
- Khan Academy Official Digital SAT prep
- College Board student question bank / official practice materials

Supplement sources (Kaplan, Princeton Review, etc.) are fine for drills, but label them as non-official when calibrating predictions—difficulty and adaptive behavior may differ.
