# Test-Taking Techniques

## General Principles

### Time Management

- RW: ~1.2 min per question (64 min / 54 questions)
- Math: ~1.6 min per question (70 min / 44 questions)
- Flag difficult questions and return later
- Bluebook provides a per-module timer—practice with it

### Answer Every Question

- No penalty for wrong answers
- Ensure every question has an answer selected before time expires
- If stuck, eliminate obviously wrong answers, then guess

### Read Questions With Purpose (RW)

For short RW stimuli: know what the question asks before over-investing in the passage.

- Identify the task (vocab-in-context, transition, evidence, grammar)
- Return to the exact sentence/span that controls the answer

### Use Process of Elimination

Most questions have 1–2 clearly wrong answers.

- Eliminate first
- Choose among remaining
- Educated guessing beats blanks

## Reading and Writing Techniques

### Evidence-Based Questions

- Answer must be supported by the passage/stimulus
- If you cannot point to specific text or data, it is probably wrong
- Avoid answers that "sound right" but are not stated

### Vocabulary in Context

- Review all definitions/fit before selecting
- Read the sentence with each answer choice
- Choose the option that preserves the passage meaning

### Grammar Questions

- Read the whole sentence, not just the underlined span
- Check subject-verb agreement and boundaries first
- When in doubt, prefer clearer, more conventional phrasing

### Transitions

- Understand what comes before **and** after
- Common trap: a transition that fits only one direction
- Types: addition, contrast, cause/effect, sequence

## Math Techniques

### Use the Calculator Wisely

- Learn Bluebook Desmos before test day
- Graph to visualize; do not over-rely for trivial arithmetic
- Mental math remains faster for simple linear work

### Plug In Answers

When algebra is messy:

1. Start with a middle choice when applicable
2. Substitute into the equation/constraint
3. Adjust based on result

### Plug In Numbers

For abstract variable problems:

1. Choose simple numbers (2, 3, 5)
2. Solve with those numbers
3. Match the answer that yields the same result

### Draw It Out

For geometry and word problems:

- Sketch the situation
- Label knowns
- Often reveals the equation path

### Check Units

In word problems:

- Units must make sense
- Rate × time = distance (not the inverse)
- Catches careless errors

## Module 1 Strategy

Remember: Module 1 routes Module 2 difficulty.

- Pace carefully through Module 1
- Double-check easy/medium items before submitting the module
- Strong Module 1 → harder Module 2 → higher section ceiling
- A few careful minutes early beat a rushed Module 1

## Flagging Strategy

Bluebook allows flagging:

1. First pass: answer everything you can quickly
2. Flag anything taking > ~90 seconds
3. Second pass: return to flagged items
4. Third pass: quick review if time remains

## Test Day

### Before the Test

- Sleep well for several nights, not only the night before
- Eat a normal breakfast
- Arrive early / start device readiness early
- Bring required ID and follow current Bluebook device rules; have a backup calculator if using handheld

### During the Test

- Use the break (~10 min between RW and Math)
- Stretch, restroom, snack
- Keep conversation away from exam content during break

### Mindset

- Expect some hard questions—everyone sees them
- One hard item does not dictate the next
- Stay with practiced strategies

## Assessment integrity

Help with practice, review, and strategy only. Do not provide answers to live, proctored SAT items during an active sitting.
