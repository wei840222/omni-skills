# First-use relocation setup

Use this reference when a user is beginning a relocation plan or has no existing state.

1. Ask for origin, destination candidates, target date, immigration basis, household, and the decision they need next. Ask one concise question at a time when the user is stressed.
2. Resolve `<state_root>` using the procedure in `SKILL.md` before reading or creating state.
3. Ask before creating persistent notes. If consent is given, create `<state_root>/memory.md` from `memory-template.md`; create `<state_root>/documents.md` only when document tracking is needed.
4. Record unknowns as questions, not assumptions. Keep official source URLs and access dates beside immigration, tax, and registration claims.
5. End the first session with one or two dated next actions and the highest-risk deadline. Do not try to collect every detail at once.
