# Odoo Sources

Use these verified official sources when domain facts, API shapes, import
behavior, or hosting constraints matter. Prefer the current documentation for
the user's Odoo version when one is known.

## Product and hosting

- Odoo Documentation home — https://www.odoo.com/documentation/
- Odoo Online / SaaS overview — https://www.odoo.com/documentation/latest/administration/odoo_online.html
- Odoo.sh platform documentation — https://www.odoo.com/documentation/latest/administration/odoo_sh.html

## External API

- External API overview (XML-RPC / JSON-RPC) — https://www.odoo.com/documentation/latest/developer/reference/external_api.html
- ORM API concepts — https://www.odoo.com/documentation/latest/developer/reference/backend/orm.html

## Data import / export

- Import and export data — https://www.odoo.com/documentation/latest/applications/general/export_import_data.html

## Accounting and inventory finality

- Accounting documentation index — https://www.odoo.com/documentation/latest/applications/finance/accounting.html
- Inventory documentation index — https://www.odoo.com/documentation/latest/applications/inventory_and_mrp/inventory.html

## Security notes for agents

- Never treat marketing pages or third-party blog posts as authoritative for
  model names, import keys, or posted-document correction flows.
- When the instance version is known, prefer the matching versioned docs URL
  under `https://www.odoo.com/documentation/<version>/...`.
