# Study Methods and Pacing

## Study Timeline

| Weeks Out | Focus |
|-----------|-------|
| 12+ | Diagnostic → identify weak sections → learn content |
| 8–12 | Section drills → timed practice → strategy refinement |
| 4–8 | Full practice tests weekly → error analysis → targeted review |
| 1–4 | Maintain timing → review weak topics → reduce volume |
| Last week | Light review only → rest → logistics prep (ticket, ID, device, calculator) |

Always align drills to the **registered format** (enhanced vs legacy practice book; Science on/off; paper vs online).

## Session Types

### Content Learning (early phase)
- Focus on ONE topic (e.g., comma rules, trig ratios)
- Learn the concept, then drill 10–20 questions
- Untimed initially, add time pressure gradually
- Duration: 30–45 min

### Section Drill (mid phase)
- Full section under real time conditions for that form
- Immediate error review
- Log error types in tracking
- Duration: matches section clock + review

### Full Practice Test (late phase)
- Simulate real test day order and breaks
- Include optional Science/Writing only if the student will take them
- Score and review same day when possible
- Duration: full battery + review block

### Error Review (after every practice)
- For EACH wrong answer:
  - Why was my answer wrong?
  - Why is the correct answer right?
  - What cue should I notice next time?
- Log patterns in section tracking files under `<state_root>/`

## Pacing Drills

Scale targets to the examinee's form (see `exam-config.md`):

**English:** Finish each passage/block with a buffer; avoid full-passage rereads.

**Math:** Hit a midpoint checkpoint (about half the items at half the time) and park hard items.

**Reading:** Hard cap per passage; unanswered marked guesses beat unfinished deep reads.

**Science (if taken):** ~5 minutes per passage starting point on legacy 35-min forms; adjust for 40-min enhanced Science.

## Online vs paper practice hygiene

- If testing online, mix official online practice so navigation, flag-for-review, and on-screen calculator feel normal
- If testing paper, practice bubbling/annotation habits allowed in the booklet
- Keep a logistics checklist separate from content review in the final 7 days

## Common Mistakes

- Studying only the weakest section while letting medium sections slip
- Doing untimed practice too long—timing is half the battle
- Skipping error review and repeating the same miss pattern
- Cramming the final 48 hours—fatigue costs more than last-minute pages
- Building a Science-heavy plan when the student will omit Science
