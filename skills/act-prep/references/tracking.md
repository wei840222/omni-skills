# Progress Tracking System

All paths below are relative to the resolved `<state_root>` from `SKILL.md`.

## What to Track

### Per Practice Test
```text
<state_root>/practice/YYYY-MM-DD.md

Date: 2026-01-15
Type: Full practice / Section drill
Format: Enhanced core / Legacy four-section / Online / Paper
Add-ons: Science yes/no; Writing yes/no
Conditions: Timed / Untimed

Scores:
- English: 28
- Math: 31
- Reading: 26
- Science: 29 (or N/A)
- Composite: 28 (state which sections ACT included)

Time Analysis:
- English: Finished with buffer / rushed last items
- Math: Parked N items
- Reading: Per-passage timing notes
- Science: N/A or pacing notes

Error Log:
- E#12: Comma splice — missed independent clauses
- M#30: Forgot 30-60-90 ratios
- R#8: Over-inferred; answer was literal in lines 40–45
```

### Per Section Progress
```text

Current score: 31

Strong areas:
- Basic algebra (high accuracy)

Weak areas (high-ROI):
- Word problem setup → largest expected gain
- Trig identities → medium gain
- Rare topics with low frequency → deprioritize near test day

Action items:
1. Daily 20-min word-problem setups
2. Weekend trig refresh
```

## Score Trend Analysis

Track over time:
- Best composite ever (for confidence and superscore planning)
- Best per-section ever
- Average of last 3 comparable sittings (same format!)
- Improvement rate (points per month)
- Format mismatch flags (do not average enhanced and legacy forms blindly)

## Red Flags to Surface

- Section flat for 3+ comparable practices → strategy or timing issue, not only "more content"
- Time pressure not improving → dedicated pacing drills
- Same error type repeating → concept gap with worked examples
- Scores dropping after volume spikes → recovery week, sleep, and lighter review
