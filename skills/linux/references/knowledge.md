# Domain Knowledge

Key references and research for Linux debugging and hardening:

- **Red Hat Enterprise Linux Documentation** — storage, networking, and systemd administration via https://docs.redhat.com/en/documentation/red_hat_enterprise_linux
- **Arch Wiki** — distribution-agnostic system behavior, boot, and service guidance via https://wiki.archlinux.org/
- **Debian Reference** — package management and system administration via https://www.debian.org/doc/manuals/debian-reference/
- **GNU Coreutils manual** — `df`, `du`, `cp`, `ls` behaviors and flags via https://www.gnu.org/software/coreutils/manual/coreutils.html
- **systemd documentation** — unit files, journald, and service management via https://www.freedesktop.org/software/systemd/man/
- **Linux man-pages project** — kernel and userspace interface reference via https://www.kernel.org/doc/man-pages/
