# Slovak language sources

Use these pages to check a ty/vy claim, colloquial particle, or contested terminology. They describe usage; they are not a license to invent slang or intimacy the user did not ask for.

## Language overview and address

- **Wikipedia — Slovak language** — overview of Slovak as a West Slavic language, orthography, and modern written/spoken norms. https://en.wikipedia.org/wiki/Slovak_language
- **Wikipedia — Slovak orthography** — spelling and written-language conventions relevant to clean Slovak drafts. https://en.wikipedia.org/wiki/Slovak_orthography
- **Wikipedia — T–V distinction** — general ty/vy-style address contrast used when deciding intimate vs polite forms. https://en.wikipedia.org/wiki/T-V_distinction
- **Wiktionary — ty (Slovak)** — familiar second-person pronoun used among peers. https://en.wiktionary.org/wiki/ty#Slovak
- **Wiktionary — vy (Slovak)** — polite/plural second-person pronoun used with strangers or formal recipients. https://en.wiktionary.org/wiki/vy#Slovak
- **Wiktionary — ahoj** — common informal greeting. https://en.wiktionary.org/wiki/ahoj

## Lexicon samples used in style guidance

## Access note

These sources are descriptive secondary references. Native-speaker frequency claims, dialect prescriptions, and crude slang boundaries need a supplied speaker sample or additional relevant evidence. When that evidence is unavailable, use broadly understandable casual **ty** for peer chat or careful **vy** for unfamiliar formal recipients, and name the uncertainty when it materially affects the draft.
