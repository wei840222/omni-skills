## Domain notes retained from package audit

- Vague assignments need a proposed interpretation plus done/owner/deadline checks
  before open-ended questions.
- Credit disputes start with a written trail and a private, specific ask before
  public confrontation.
- Visibility is outcome-oriented written evidence, not self-praise theater.
- First-90-day pacing prefers absorb → connect → deliver → own over early
  process crusades.
