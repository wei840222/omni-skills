# Vendor evaluation

Run this check before recommending any AliExpress purchase over $20. For a smaller order, still collect star rating plus photo-review quality.

## Store metrics

```text
[ ] Store age: prefer more than 2 years
[ ] Followers: prefer more than 5,000
[ ] Catalog: prefer more than 50 products
[ ] Positive feedback: prefer more than 97%
[ ] Detailed seller rating: prefer above 4.7 in each shown category
```

These cutoffs are comparison heuristics. A missing metric is a gap, not a silent pass.

## Communication test

Send one specific pre-purchase question.

- A reply within 24 hours is a positive indicator.
- A generic copy-paste answer is a warning sign.
- A specific answer that matches the listing is a trust signal.

## Review analysis

| Review type | Trust level |
|-------------|-------------|
| Photo review with detailed text | High |
| Photo review with short text | Medium |
| Text only, specific | Medium |
| Text only, generic | Low |
| No reviews | Seek another vendor |

Look for reviews that mention actual quality versus photos, real shipping time, and packaging condition.

## Warning signs

| Signal | Risk |
|--------|------|
| Store younger than 6 months | Higher scam risk |
| Only 5-star reviews | Review-quality risk |
| Price 50% or more below competitors | Bait-and-switch risk |
| Stock photos only | Middleman or unverified goods |
| No reply to a specific question | Support gap |

## Verification steps

1. Image search: use the product photo and check whether the same item is cheaper elsewhere.
2. Price check: search the product name on AliExpress and sort by orders.
3. Factory check: identical photos across vendors usually mean the same factory. Prefer the highest-rated of those stores.

## Badges that still need a check

A "Top Brand" badge, an AliExpress Choice label, a local-warehouse option, an anniversary badge, or a high repeat-buyer percentage is a positive indicator only after store age, photo reviews, and price comparison agree. The badge does not replace those checks.
