# Dropshipping on AliExpress

Use this file only when the user is reselling. A personal purchase uses `references/rules.md` and `references/vendors.md`.

## Supplier bar

| Metric | Minimum | Prefer |
|--------|---------|--------|
| Positive feedback | 98% | 99%+ |
| Store age | 2 years | 4+ years |
| Response time | <24h | <6h |
| Tracked shipping method | Required | AliExpress Standard or equivalent |
| Orders on that product | >500 | >2000 |

Source exclusively from stores that meet the minimum column. If a store misses one minimum, name the miss and look for another store.

## Margin calculation

```text
Gross Margin = Selling Price - Landed Cost

Landed Cost =
  product price
  + shipping to the customer's country
  + payment processing (often about 2.9% + $0.30; use the user's processor)
  + platform fees (Shopify, Etsy, or the actual channel)
  + return reserve (5-10%)
```

Target a gross margin above 30% after every line above. If any line is unknown, show the incomplete total and stop calling the margin "good".

## Product selection

### Positive indicators

- High order count that stays stable across months
- Photo reviews that show the actual goods
- Several vendors, which usually means the price can be compared
- Light weight, which keeps shipping inside the margin
- Unbranded goods, which keeps the listing on the legal side of trademark rules

### Warning signs

- Only one supplier for that product
- A seasonal spike followed by a drop
- Heavy or fragile goods whose shipping consumes the margin
- Brand lookalikes
- Complex sizing, which raises the return rate

## Shipping strategy

Read the method on the listing. Typical ranges used for planning, not as a promise:

| Method | Typical time | Typical cost | Tracking |
|--------|--------------|--------------|----------|
| AliExpress Standard Shipping | 15-25 days | $2-5 | Yes |
| ePacket-style tracked mail | 12-20 days | $3-7 | Yes |
| Cainiao economy | 20-40 days | $0-3 | Limited |
| Private line | 10-15 days | $5-15 | Yes |

Use a tracked method for every dropshipping order. Quote the listing's own delivery window to the end customer.

AliExpress documents delivery promises on the order and on Buyer Protection, not as one global day count: https://www.aliexpress.com/p/buyerprotection/index.html

## Order handling

1. Place a sample order and inspect quality before listing the product.
2. Keep a sheet with order ID, tracking number, customer, and status.
3. If an auto-sync tool is used (DSers or another current AliExpress app), still verify one order end to end before trusting the sync.
4. Record the order's buyer-protection expiry and file inside that window.

## Common challenges and the check that replaces them

- Listing before a sample arrives → inspect one received sample first.
- Promising a fast arrival from an economy method → quote the listing's delivery window.
- Using the cheapest untracked method → switch to a tracked method before taking the customer order.
- Margin math that omits fees → recompute with processor, platform, and return-reserve lines.
- No return reserve → hold 5-10% before calling the margin real.
