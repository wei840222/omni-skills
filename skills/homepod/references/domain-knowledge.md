# Apple documentation and platform facts

Use Apple documentation as the primary source for model-specific setup, pairing, stereo-pair, home-hub, and reset behavior. Re-check it when software releases or support guidance may have changed.

## Sources

- **HomePod User Guide** — setup, Siri, audio, stereo-pair, Apple TV, and Home workflows: https://support.apple.com/guide/homepod/welcome/homepod
- **Reset HomePod or HomePod mini** — restart before factory reset; ungroup a stereo pair before resetting a member: https://support.apple.com/en-us/108389

## Operational implications

- Begin with the device, room, home-hub, and network evidence relevant to the symptom; product capabilities vary by model and software version.
- Use restart and targeted configuration checks before factory reset. For a stereo pair, follow Apple’s ungrouping requirement before a member reset.
- Keep reset guidance linked to the current Apple page rather than copying version-sensitive button sequences into troubleshooting notes.
