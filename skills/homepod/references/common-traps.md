# Common troubleshooting traps

- Check account and home-hub state alongside the network path when Siri fails.
- Capture a reproducible trace before reset actions so the next test has a baseline.
- Change one automation variable at a time to preserve a clear cause.
- Compare software versions across devices before diagnosing intermittent routing or automation behavior.
- Test every affected room in a multiroom incident.
- Resolve an exact device identity before active playback control.
