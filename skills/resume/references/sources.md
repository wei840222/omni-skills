## Practice notes

- Claims such as “75% of resumes rejected by ATS” or fixed “6-second” recruiter scans are widely repeated industry heuristics, not a single immutable government statistic. Prefer process guidance (parseable layout, quantified impact, JD keyword fit) over citing a precise percentage unless the live source still supports it.
- Photo, date-of-birth, marital status, and full street address norms differ by country. Default to omit for U.S.-style applications; confirm local convention with the user before adding personal data fields.
- Never invent metrics to satisfy quantification guidance. Ask the user for evidence or leave the claim qualitative.
- When mapping skills for technical roles, prefer employer JD language first, then O*NET / NICE vocabulary for missing standardized labels.
