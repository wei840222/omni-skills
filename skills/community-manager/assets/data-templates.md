# Data templates

Copy these skeletons into the resolved `<state_root>` only after the user
consents to durable community memory. Replace bracketed placeholders.

## `memory.md`

```markdown
# Community Manager Memory

## Active priorities
- [priority 1]
- [priority 2]

## Communities
| Name | Platform | Status | Owner |
|------|----------|--------|-------|
| [name] | Discord / Slack / Telegram / forum | active | [owner] |

## This week
- [campaign or ritual]
```

## `content/calendar.md`

```markdown
# Content calendar

| Date | Platform | Channel | Format | Goal | Status | Notes |
|------|----------|---------|--------|------|--------|-------|
| YYYY-MM-DD | Discord | #announcements | short update | inform | planned | adapt before cross-post |
```
