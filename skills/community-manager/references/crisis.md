# Crisis and moderation ladder

## Operating principle

Moderation protects the majority. Act fast on spam, scams, and harassment; cool
heated debate before it becomes harassment; document what the user consents to
keep under `<state_root>/archive/`.

## Severity ladder

| Severity | Examples | Immediate response | Follow-up |
|----------|----------|--------------------|-----------|
| Off-topic | Wrong channel, derail | Redirect; move thread if the platform allows | Update channel topic tips if repeated |
| Heated debate | Sharp disagreement, rising tone | Slow the thread; summarize neutrally; offer private DM | Capture lessons without naming private details |
| Harassment | Targeted insults, stalking, hate | Warn once when borderline; remove / ban when clear | Archive incident note; review role permissions |
| Spam / scam | Phishing, unsolicited promo floods | Immediate ban / remove; no warning | Preserve evidence locally; rotate invite links if needed |
| Platform-policy harm | Illegal content, severe safety issues | Remove content; escalate via host safety tools | Follow Discord / Slack / Telegram official safety paths |

## Documentation template

Store under `<state_root>/archive/` only with consent:

- UTC timestamp
- Platform and channel
- Severity and actions taken
- Open follow-ups
- Whether evidence was retained locally (never store credentials)

## External escalation anchors

Prefer the platform’s current official surfaces (verify before citing in a live
incident):

- Discord Community Guidelines / Safety Center / Safety Library
- Slack workspace permission and admin help
- Telegram FAQ / community and Bot API docs when bots are involved
- Forum or Reddit moderation wikis when the community lives there

Do not invent policy quotes from memory. Open the live page, then act.
