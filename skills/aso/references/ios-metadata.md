# iOS metadata

Use App Store Connect as the source of truth for field availability and maximum lengths; limits can differ by localization and storefront. Start with a clear product promise, then map user intent to the title, subtitle, keywords, and product-page creative without keyword stuffing or misleading claims.

- Build a locale-specific keyword map. Avoid duplicating a term across fields unless it changes the user-facing meaning.
- Treat Promotional Text as release messaging rather than a substitute for metadata research; Apple documents that it can be updated without a new version submission.
- Check the current maximum lengths before finalizing copy. Do not rely on historical character-limit tables.
- Use Custom Product Pages only when the audience, acquisition context, and measurement plan are explicit. Keep screenshots and claims consistent with the app's actual experience.

Sources:
- Apple, *Maximum character lengths*: https://developer.apple.com/help/app-store-connect/reference/maximum-character-lengths/
- Apple, *Set an app's promotional text*: https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-apps-promotional-text/
- Apple, *Create Custom Product Pages*: https://developer.apple.com/help/app-store-connect/create-custom-product-pages/create-custom-product-pages/
