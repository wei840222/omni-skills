# Travel memory template

Use under the resolved `<state_root>/`.

## memory.md skeleton

```markdown
# Travel memory

## Preferences
- home_airports:
- passport_countries:
- trip_style:
- risk_posture:

## Boxes
- bookings/<year>.md — when dates or locators are discussed
- places/<slug>.md — when a destination has prior notes

## Due
| When (local) | What | Why |
|---|---|---|
```

## Place file skeleton (`places/<slug>.md`)

```markdown
# <Place>

## Windows tried
## Entry notes (with check date + URL)
## Spend baseline
## Would repeat
## Would skip
```

## Bookings row

`date | type | provider | locator | travellers | status | free change/cancel until | amount with currency | trip`
