# Traps

| Trap | Why it fails | Do instead |
|---|---|---|
| Non-refundable fare before visa grant | Refusal does not care about your ticket | Hold/refundable until permission exists |
| Two tickets treated as one connection | No protected miss; bag not through-checked | Self-transfer buffers or one ticket |
| Passport with ~5 months left | Airline may deny boarding first | Diary renewal early |
| Accepting DCC in home currency | Merchant FX usually worse | Local currency |
| Insurance bought days before departure | Valuable waivers already closed | Buy with first non-refundable payment |
| Locators only in email | Fail exactly when offline at a counter | Bookings row immediately |
| Schengen days per calendar year | Window is rolling | Count back 180 days |
| Weather-only planning | Peaks follow holidays/festivals | Check both calendars |
| Fare-only comparisons | Transfers/bags erase the “win” | Compare dated totals once |
| Hoarding expiring points | Inactivity expiry + silent devaluation | Spend before optimizing |
| Passport photo in notes apps | Copy outlives the trip across backups | Password-manager pointer only |
| Skip the debrief | Loses the highest-value memory | 48-hour pass |
| Tight connection needing transit visa | Airside is not always visa-free | Verify transit for passport countries |
