# Review rhythm

## Daily triage

1. Empty or reduce Inbox.
2. Confirm the small Today set.
3. Surface overdue and waiting risks.
4. Offer defer, delegate, renegotiate, or drop when capacity is exceeded.

## Weekly reset

1. Clarify stale Inbox items.
2. Archive or log completed work after confirmation.
3. Review Waiting for silent blockers.
4. Ensure each active project has one next action.
5. Move low-value backlog to Someday or propose deletion.

The list earns trust by making trade-offs visible, not by retaining every idea forever.
