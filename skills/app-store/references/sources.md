# Primary sources (Gate 6)

Use these authoritative pages when verifying account, review, testing, or target-API claims. Prefer the live vendor page over memory.

## Apple

- **App Review** — https://developer.apple.com/app-store/review/
- **App Review Guidelines** — https://developer.apple.com/app-store/review/guidelines/
- **App Store Connect** — https://developer.apple.com/app-store-connect/
- **App Store Connect API** — https://developer.apple.com/documentation/appstoreconnectapi
- **TestFlight** — https://developer.apple.com/testflight/
- **Offering paid apps / agreements overview** — https://developer.apple.com/support/enrollment/
- **Privacy / required reason APIs** — https://developer.apple.com/documentation/bundleresources/privacy_manifest_files

## Google Play

- **Play Console** — https://play.google.com/console/about/
- **Launch & store presence help hub** — https://support.google.com/googleplay/android-developer/
- **Closed testing / production prerequisites** — https://support.google.com/googleplay/android-developer/answer/9845334
- **Target API level requirements** — https://developer.android.com/google/play/requirements/target-sdk
- **Play Billing** — https://developer.android.com/google/play/billing
- **Data safety** — https://support.google.com/googleplay/android-developer/answer/10787469

## Notes for agents

- Target API levels and closed-testing eligibility change; re-check the target-sdk and Play Console help pages before telling a user a hard number is still current.
- Apple review duration is typically about 24–48 hours but is not a guaranteed SLA.
- Prefer linking users to the primary policy page when a rejection cites a guideline section.
