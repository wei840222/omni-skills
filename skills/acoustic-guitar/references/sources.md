# Sources

## Agent Skills packaging

- [Agent Skills Specification](https://agentskills.io/specification) — frontmatter, metadata, optional directories, and progressive-disclosure guidance.
- [skills-ref reference validator](https://github.com/agentskills/agentskills/tree/main/skills-ref) — validator implementation used by this repository.

## Instrument care

- [D'Addario Guitar Humidifiers, Hygrometers & Accessories](https://www.daddario.com/collections/guitar-humidifiers) — describes guitar humidity-control products and two-way protection; prefer the guitar maker's model-specific instructions for final storage guidance.
- [Fender — How Humidity Affects Your Guitar](https://www.fender.com/articles/setup-maintenance/how-humidity-affects-your-guitar) — manufacturer education on humidity risk, measurement, and why wood instruments move with environment.
- [Fender — How to Care for Your Acoustic Guitar](https://www.fender.com/articles/tech-talk/how-to-care-for-your-acoustic-guitar) — acoustic care framing that supports pausing unsafe home repairs and using maker guidance.

## Technique terminology

- [Wikipedia — Fingerstyle guitar](https://en.wikipedia.org/wiki/Fingerstyle_guitar) — background on playing strings directly with the fingers rather than a flat pick.
- [Wikipedia — Travis picking](https://en.wikipedia.org/wiki/Travis_picking) — alternating-thumb bass pattern associated with Merle Travis / country fingerstyle.
- [Wikipedia — Merle Travis](https://en.wikipedia.org/wiki/Merle_Travis) — biographical context for the Travis-picking name.
