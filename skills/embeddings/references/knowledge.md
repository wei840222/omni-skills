# Domain Knowledge: Vector Databases

A vector database (or vector store) is a specialized database designed to store, manage, and retrieve embeddings of data in high-dimensional vector spaces. These databases are fundamentally built around algorithms that compute similarities between vectors.

## Key Concepts

- **Embeddings:** Mathematical representations of raw data (such as text, images, or audio) in high-dimensional spaces. Typically generated by machine learning models (like OpenAI's text-embedding-3 or HuggingFace models), these vectors encode the semantic meaning of the data. The number of dimensions can range from hundreds to thousands.
- **Approximate Nearest Neighbor (ANN):** To query vector databases efficiently, approximate nearest neighbor search algorithms (e.g., HNSW, IVF) are used instead of exhaustive exact match. These algorithms optimize the retrieval of semantically similar vectors at scale.
- **Use Cases:** Similarity search, semantic search, multimodal search, recommendation engines, and retrieval-augmented generation (RAG) for large language models.
- **Hybrid Search:** Combining vector retrieval with traditional metadata filtering or lexical/keyword search (BM25) to provide more robust query results.
