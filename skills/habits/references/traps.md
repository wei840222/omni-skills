# Troubleshooting traps

| Pattern | Repair |
|---|---|
| Starting many habits together | Start one; wait until the current set is stable before adding another. |
| Treating the streak as the only metric | Lead with the rolling completion rate and keep the streak as context. |
| Backfilling from memory | Leave uncertain dates unlogged; keep the data boundary honest. |
| Setting a good-day minimum | Replace it with the under-two-minute worst-day version. |
| Anchoring to "when I have time" | Attach the action to an observable existing cue. |
| Adding punishment after a miss | Log the miss neutrally and diagnose after a repeat. |
| Creating long routine chains | Keep the chain short and introduce one new link at a time. |
| Tracking an automatic habit indefinitely | Review whether its tracking slot should be retired after sustained high completion. |
| Copying another person's routine | Preserve only the useful element and attach it to a cue that actually exists for this person. |
