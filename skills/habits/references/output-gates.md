# Output gates

Before a status report, new-habit design, or completed check-in:

1. For a rate, streak, or trend, read the current `<state_root>/logs/YYYY-MM.md`; otherwise state that the record is unavailable.
2. For a new habit, record all six Habit anatomy fields and use an existing cue plus a worst-day minimum.
3. Base a pattern claim on at least four comparable samples; make one repair at a time.
4. Log a miss without moral language. If clinical, withdrawal, injury, distress, or compulsive-tracking signals appear, apply `references/red-flags.md` instead of continuing normal coaching.
5. Write any durable completion, miss, definition, pause, retirement, review, or plan into the selected `<state_root>` tree; identify each file changed in the response.
