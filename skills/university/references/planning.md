# Planning & Calendar

All durable plans live under the resolved `<state_root>`.

## Initial Setup

### Availability Assessment
1. Hours per week available for study
2. Best times of day (energy/focus)
3. Non-negotiable commitments (work, family)
4. Seasonal variations (exams at work, holidays)

### Goal Setting
- Target completion date (if any)
- Priority order of modules
- Milestone definitions
- Minimum viable progress per week

## Daily Planning

### Morning Briefing
Generate each morning:
- What's on today's study plan
- Any deadlines approaching (< 7 days)
- Review items due (spaced repetition)
- Suggested focus time blocks

### Session Generation
When user has time to study:
1. Ask: How much time? (15 min, 1 hour, 3 hours)
2. Generate session:
   - X% new material
   - Y% practice/exercises
   - Z% review (flashcards, past tests)
3. Adapt to energy: fresh → new material, tired → review

### End of Day
- Log what was completed
- Reschedule what wasn't
- Update progress tracking
- Preview tomorrow

## Weekly Rhythm

### Weekly Review
Every Sunday (or configured day):
- Hours planned vs completed
- Mastery deltas
- Upcoming deadlines inside 14 days
- One adjustment to the next week only

### Weekly Plan
- Distribute remaining work across days
- Buffer for unexpected (schedule ≤ 80% capacity)
- One "catch-up" slot for slippage
- Balance across multiple degrees if applicable

## Exam Windows

When exam date is set:
- No new material in the final stretch unless a critical gap appears (review + drills first)
- Daily practice tests
- Focus on weak areas
- Reduce study hours enough to keep a sustainable pace

### Multiple Exams
- Prioritize by date and difficulty
- Protect sleep and recovery blocks
- Share a single weekly calendar view while keeping per-program files separate

## Automatic Adjustments
When user misses planned study:
- Maintain a supportive tone
- Redistribute missed content
- Prioritize critical items
- Adjust future estimates if pattern emerges

## Calendar integrations (optional)
### Calendar Sync
- Import external calendars (work, personal) only with consent
- Detect free slots automatically when tooling allows
- Ensure study time blocks remain exclusive
- Respect blocked times

### Notifications
- Configurable: email, push, none (host-dependent)
- Types: daily summary, deadline warnings, review reminders
- Timing: morning briefing, session reminders
- Frequency: send updates selectively, respect offline hours

### Travel/Breaks
- Vacation mode: pause tracking without guilt framing
- Resume with a short diagnostic before restarting volume
