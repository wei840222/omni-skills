# Research Sources — Polkadot & Substrate Ecosystem

Primary technical documentation, specifications, and architecture references for Polkadot, Substrate, and Cross-Consensus Messaging (XCM).

## Protocol & Architecture Documentation

- **Polkadot Wiki** — https://wiki.polkadot.com/
  - Shared security, Relay Chain, System Parachains (Asset Hub, Bridge Hub), DOT tokenomics, and existential deposit rules.
- **Polkadot Agile Coretime** — https://wiki.polkadot.com/learn/learn-agile-coretime/
  - Transition from 2-year auction leases to dynamic coretime allocation (bulk 28-day sales cycles and on-demand coretime).
- **Polkadot System Chains** — https://wiki.polkadot.com/learn/learn-system-chains/
  - System parachains holding permanent cores (Asset Hub, Bridge Hub, People Chain).
- **Substrate Documentation** — https://docs.substrate.io/
  - Substrate runtime primitives, pallets, SS58 address encoding, and extrinsic dispatch.
- **Cross-Consensus Message Format (XCM)** — https://wiki.polkadot.network/docs/learn-xcm
  - XCM instruction set, teleport transfers, reserve-backed transfers, and multi-location addressing.

## Staking & Governance

- **Polkadot OpenGov** — https://wiki.polkadot.network/docs/learn-polkadot-opengov
  - Tracks, origins, conviction voting multipliers, and delegation.
- **Nomination Pools Guide** — https://wiki.polkadot.network/docs/learn-nomination-pools
  - Pool mechanics, dynamic nomination floor, and permissionless reward claims.
