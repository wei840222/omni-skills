# Grammar guidelines

Load this reference when explaining corrections, reviewing text that mixes language varieties, or deciding whether an apparent error is an intentional stylistic choice.

## Preserve intent before applying a rule

Grammar correction is not a rewrite. First identify the intended meaning, audience, register, and language variety. A sentence fragment, dialect form, code-switched phrase, or loanword can be intentional and should remain unchanged unless the user explicitly requests standardization.

## Explain only the requested level of detail

When explaining a correction, name the rule and show the smallest relevant before/after change. Common categories include articles, count and noncount nouns, subject-verb agreement, verb tense, pronoun reference, punctuation, and prepositions. Purdue OWL's grammar resources cover these topics, including articles, agreement, and prepositions.

## Regional varieties and consistency

Treat regional spelling and conventions as valid varieties. Preserve the source text's established convention; ask the user before changing an inconsistent document to a chosen house style.
