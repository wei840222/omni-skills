# Bucharest Skill — Setup Guide

## First-time setup

This skill helps navigate Bucharest for visiting, moving, working, studying, or starting a business.

### Step 1: Initialize the profile

Create the Bucharest knowledge base only after the user wants continuity:

```text
<state_root>/
├── memory.md           # Profile + priorities (from assets/memory-template.md)
├── progress.md         # Checklist of completed admin steps
├── bookmarks.md        # Saved places and resources
└── notes.md            # Personal observations
```

### Step 2: Define context

Copy `assets/memory-template.md` into `<state_root>/memory.md` and fill:

1. **Role**: visitor, planning-to-move, resident, tech/remote, student, entrepreneur
2. **Timeline**: arrival month, length of stay
3. **Situation**: EU/non-EU, visa/residency status, employment type
4. **Priorities**: cost, commute, nightlife vs quiet, schools, language comfort

### Step 3: Choose the first load set

| Role | Start with |
| --- | --- |
| Tourist | `visitor-attractions.md`, `visitor-itineraries.md` |
| Planning to move | `visas.md`, `cost.md`, `neighborhoods-choosing.md` |
| Recently arrived | `resident.md`, `local.md`, `neighborhoods-index.md` |
| Working remotely / tech | `tech.md`, `cost.md`, `neighborhoods-north.md` / `neighborhoods-expat.md` |
| Starting a business | `business.md`, `startup.md`, `visas.md` |
| Student | `education.md`, `neighborhoods-emerging.md`, `cost.md` |
| With family | `education.md`, `healthcare.md`, `neighborhoods-expat.md` |

## Using this skill

- Start from `SKILL.md` for the topic index; open `domain.md` + `sources.md` before money or legal claims.
- Ask only for the next missing detail that changes the recommendation (passport, month, budget currency, Old Town vs north priority).
- Update `<state_root>/progress.md` as admin steps complete; keep passport numbers, bank credentials, and full card/IBAN dumps out of state files.

## Freshness

- Re-check rent listings, STB/Metrorex fares, and IGI/MAE entry products before bookings or filings.
- Neighborhood character and climate patterns change slowly; treat them as durable unless a major redevelopment note appears.
