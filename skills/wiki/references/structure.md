# Wiki Structure and Templates

## Getting Started / map page

Create or refresh a top-level map that:

1. States what the wiki covers in one paragraph
2. Lists major sections with links
3. Points newcomers to the 3–5 most-used pages
4. Shows how to propose edits / ownership if the team has a process

## Default page template

```markdown
# <Page title>

<summary: one sentence saying what this page answers>

**Last updated:** YYYY-MM-DD

## Overview
<short context for zero-knowledge readers>

## <Primary procedure or body>
1. ...
2. ...

## Related
- [<Concept A>](<path-or-title>)
- [<Concept B>](<path-or-title>)
```

## Focus and length

- One topic per page.
- Prefer splitting when a page exceeds ~500 words of mixed topics.
- Keep procedure pages task-shaped; keep glossary pages definition-shaped — do not blend both without clear headings.

## Consistency

- Same section order across the same page class (procedure vs concept vs policy).
- Same date format and related-links placement.
- Same link style as the host (MediaWiki internal links, GitHub wiki Markdown links, etc.).
