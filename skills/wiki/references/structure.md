# Wiki Structure and Templates

## Getting Started / map page

Create or refresh a top-level map that lists major sections and entry points.

## Default page template

```markdown
# <Page title>

<summary: one sentence>

**Last updated:** YYYY-MM-DD

## Overview
...

## Procedure or body
1. ...
2. ...

## Related
- ...
```

## Focus and length

- One topic per page.
- Prefer splitting when a page exceeds ~500 words of mixed topics.
