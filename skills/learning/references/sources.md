# Official Sources Map — Learning

Use these primary sources when citing retrieval practice, spacing, cognitive load, expertise reversal, or misconception repair. Prefer full URLs in PR notes and user-facing citations. This skill stays curriculum- and vendor-neutral.

## Retrieval practice and testing effect

- **Roediger & Karpicke (2006) — Test-Enhanced Learning** — retrieval practice beats restudy on delayed tests via https://doi.org/10.1111/j.1467-9280.2006.01693.x
- **Kornell, Hays & Bjork — Unsuccessful retrieval attempts** — pretesting / failed retrieval can improve later learning via https://doi.org/10.1037/a0014241
- **Bjork & Bjork — Desirable difficulties** — effortful retrieval and spacing improve long-term retention (overview) via https://bjorklab.psych.ucla.edu/wp-content/uploads/sites/13/2016/04/RBjork_ajp1994.pdf

## Spacing and successive relearning

- **Cepeda et al. — Distributed practice / spacing** — review gap ≈ 10–20% of retention horizon guidance via https://doi.org/10.1037/0033-2909.132.3.354
- **Rawson & Dunlosky — Successive relearning** — multiple successful relearning sessions before retirement via https://doi.org/10.1037/a0020076
- **Rohrer & Taylor — Interleaved mathematics practice** — interleaving vs blocking on delayed tests via https://doi.org/10.1007/s10648-007-9042-0

## Working memory and instructional design

- **Cowan — Working memory capacity ~4 chunks** — concept-cap rationale via https://doi.org/10.1016/S0079-7421(01)80005-9
- **Sweller — Cognitive load theory / redundancy** — avoid re-explaining failed formats with more words; diagrams replace duplicate prose via https://doi.org/10.1207/s15326985ep3801_1
- **Kalyuga — Expertise reversal effect** — worked examples help novices; hurt intermediates when scaffolds stay too long via https://doi.org/10.1207/s15326985ep3801_4
- **Kirschner, Sweller & Clark — Why minimal guidance fails novices** — pure discovery limits for beginners via https://doi.org/10.1207/s15326985ep4102_1

## Feedback, misconceptions, motivation

- **Butterfield & Metcalfe — Hypercorrection effect** — high-confidence errors, when corrected, stick better via https://doi.org/10.1037/0278-7393.27.6.1491
- **Butler & Roediger — Feedback timing** — delayed vs immediate feedback trade-offs on delayed tests via https://doi.org/10.3758/MC.36.3.604
- **Guzzetti et al. — Refutation text** — explicit misconception + correct model outperforms correct-only presentation (review literature via education research indexes; prefer live meta-analyses when available)
- **Mueller & Dweck — Person vs process praise** — process/strategy praise over trait praise via https://doi.org/10.1037/0022-3514.75.1.33

## SRS defaults

- **FSRS / open spaced-repetition research** — target retention near the top of a 70–90% band is consistent with common SRS defaults; verify live docs for the learner's tool via https://github.com/open-spaced-repetition/fsrs4anki

## How to use these sources in-session

- Cite the matching group when stating effect sizes, spacing ratios, or “research says” claims.
- Prefer the learner’s exam board, course syllabus, or tool docs over generic psychology papers when they conflict.
- Do not invent numerical effect sizes from memory; open the paper/DOI or a verified secondary summary first.
- Treat laboratory findings as teaching design inputs, not medical or clinical advice.
