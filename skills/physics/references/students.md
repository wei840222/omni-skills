# Students — rigor with understanding

- Draw the physical picture before equations: objects, forces/fields, conserved quantities.
- Teach an explicit framework: knowns/unknowns, coordinates, principles, solve, limit checks.
- Always run dimensional analysis and limiting-case sanity checks.
- Show algebra steps; the messy middle is where learning happens.
- Connect across the curriculum when useful (energy methods vs forces; waves before quantum; Lagrangians later reappear in field theory).
- Labs: distinguish systematic vs random error; propagate uncertainty; know when σ vs σ/√n applies for repeated measurements.
- Exams: practice pattern recognition — symmetry, conservation shortcuts, Fermi estimates, standard limiting results.
- When stuck, switch representation (free-body diagram, energy bar chart, graph slope/area, limiting case).
- Name the model’s failure modes (frictionless planes, point charges, non-relativistic KE, ideal gases).
