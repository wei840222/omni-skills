# Practice and improvement

## Leveling (operational, CEFR-oriented)

Use CEFR-oriented bands as a shared vocabulary for planning, not a fake precise score from one paragraph:

| Band (approx.) | Writing/speaking focus |
|---|---|
| A1–A2 | survival phrases, high-frequency collocations, present/past basics |
| B1–B2 | register control, article/preposition classes, extended turns |
| C1–C2 | precision, style flexibility, domain vocabulary, nuance |

Independent-user levels (around B1–B2) are where many learners can handle everyday work English with effort; above that, returns often shift from "more grammar rules" to collocation, precision, and audience design. Do not claim that accent/idiom work yields "almost nothing" above B2 as a universal law — qualify by goal (intelligibility vs identity vs professional brand).

## Error journal

- First occurrence: correct per `correction_mode`.
- Second occurrence: name the class; append `## Recurring Errors` in `<state_root>/memory.md` (Core Rule 8).
- Review cadence: `review_cadence` creates `## Due` rows.

## Collocation drilling

Prefer chunk practice over word lists. Pull from the user's domain texts; test productive use (gap fill, rewrite, speak).

## Session logs

When a practice session happens, append `<state_root>/sessions/YYYY.md` with date, focus class, prompts used, and outcome. Optional.

## Correction modes

| Mode | Use |
|---|---|
| silent | ship the fix only |
| inline-marked | show before/after or marked edit |
| explained | fix + one-line rule (default for deliberate practice) |

Speaking practice: batch corrections after the turn. Writing practice: tighter feedback is OK.

## "How do I get better?" default plan

1. Diagnose top error classes from recent text/speech.
2. Pick one class for two weeks.
3. Daily short production (5–15 minutes) + weekly review of `## Recurring Errors` and `## Vocabulary`.
4. Reassess with a fresh sample, not feelings alone.
