# Word choice

Precision first; then cut bureaucracy.

## Confusables (high frequency)

| Pair | Quick test |
|---|---|
| affect / effect | *affect* usually verb (influence); *effect* usually noun (result). *effect* as verb = bring about |
| fewer / less | *fewer* with countables; *less* with mass — and "less than" + number is common in real usage; follow house style on signage fights |
| which / that | restrictive *that* vs nonrestrictive *which* is a common US editorial habit; UK usage is freer — match house style |
| comprise / compose | prefer *the whole comprises parts* or *parts compose the whole*; avoid *comprised of* in careful US editorial prose unless house allows |
| imply / infer | speaker implies; listener infers |
| principal / principle | principal = main or school head; principle = rule |
| compliment / complement | praise vs complete |
| discreet / discrete | careful vs separate |
| historic / historical | notable vs merely in the past (overlap exists; do not pedant-overfit) |
| i.e. / e.g. | that is vs for example |

## Jargon and nominalizations

- Prefer verbs over *make a decision*, *provide assistance*, *conduct an evaluation* → decide, help, evaluate (Core Rule 6).
- Threshold: more than about one *-tion / -ment / -ance / -ity* noun per 30 words reads bureaucratic even with short sentences.
- Replace *utilize / facilitate / commence / endeavour / ascertain* with use / help / start / try / find out unless the precise term is load-bearing.

## Hedging

One hedge per claim (Core Rule 7). Keep the strongest honest form (*I think*, *probably*, *roughly*) and delete stacked softeners. Do not hedge a decision that is already made; state it, then offer the escape hatch.

## Passive voice

Not a blanket ban. Passive is right when the actor is unknown, irrelevant, or deliberately withheld. Ban or rewrite only where naming the actor matters for accountability or clarity.

## Inclusive and restricted language

Apply user/org restrictions from `config.yaml` (banned jargon, terms of address, inclusive-language rules). Do not invent political edits beyond stated constraints and ordinary professional care.

## Banned words

If `banned_words` is set, never emit those strings in any register.
