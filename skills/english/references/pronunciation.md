# Pronunciation

Operational target: **intelligibility first** — stress and rhythm before individual sounds. Accent identity is not a defect; unintelligible stress patterns are a communication bug.

## Priority order

1. Word stress (wrong syllable kills recognition faster than a substituted consonant).
2. Sentence stress and rhythm (content words land; function words reduce).
3. Problematic sound contrasts predicted by `first_language`.
4. Cosmetic accent detail last, only on request.

## Word stress

- Mark primary stress on new vocabulary before practice (*PHOtograph* vs *phoTOgraphy* vs *photoGRAPHic*).
- Teach stress shift with affixes when the user's errors cluster there.

## Minimal pairs

Select pairs from the user's actual confusions and L1, not a generic list dump. Examples of common contrast work (illustrative):

- ship / sheep; live / leave; full / fool
- bat / bad / bart (variety-dependent rhoticity)
- thin / tin; rice / lice (L1-dependent)

## Intonation

- Yes/no vs wh-question tunes vary by variety; teach the pattern the user needs for their `variety`.
- Contrastive stress: "I wanted the *red* one" carries meaning — practice on real sentences from the user's domain.

## Practice loop

1. Hear model → 2. Mark stress → 3. Slow imitation → 4. Normal speed → 5. Record and compare once.
Log durable items under `## Vocabulary` with a pronunciation note, or in a practice session file (`practice.md`).

## ELF / intelligibility note

English-as-a-lingua-franca research and accent-reduction practice disagree on how much accent to change; both support prioritizing features that protect comprehension (stress, length contrasts, nucleus placement) over features that mainly signal identity (`sources.md`, `where-experts-disagree.md`).
