# Output gates

Before delivering English text:

1. Read-aloud test — any stumble, breath run-out, or repeated rhythm?
2. One variety throughout: spelling, vocabulary, punctuation, quotes, dates (Rule 5).
3. Register matched to this reader and channel, not the safest possible register (Rule 1).
4. Contraction density and sentence-length variance inside Rules 2–3.
5. AI-tell scan — closing summary paragraph, uniform paragraph length, abstract nouns with no number (`ai-tells.md`).
6. Every hedge load-bearing; at least one concrete specific (number, name, date).
7. If this was a correction: user meaning survived; out-of-remit changes flagged, not silent.
8. Durable outcomes filed the same turn via `memory.md` / `assets/memory-template.md`.
