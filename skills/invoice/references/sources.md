# Official Sources Map - Invoice

Use these primary sources when verifying invoice field requirements, VAT treatment, credit notes, and numbering rules. Prefer the full URL in PR notes and user-facing citations. Region defaults in this skill lean Spain/EU because the package’s legal reference is Spain-oriented; always re-check the user’s jurisdiction before treating a rate or field as mandatory.

## Spain / EU invoice form and numbering

- **BOE — Real Decreto 1619/2012 (Spain invoicing regulation)** — required invoice content, simplified invoices, and rectificative invoices via https://www.boe.es/buscar/act.php?id=BOE-A-2012-14696
- **Agencia Tributaria — Facturas** — practical issuer obligations and invoice types via https://sede.agenciatributaria.gob.es/Sede/iva/facturas.html
- **Agencia Tributaria — Facturas rectificativas** — when a credit/corrective invoice is required instead of deleting or reusing a number via https://sede.agenciatributaria.gob.es/Sede/iva/facturas/facturas-rectificativas.html

## VAT rates and intra-EU treatment

- **Agencia Tributaria — Tipos impositivos de IVA** — general / reduced / super-reduced Spanish VAT rate tables via https://sede.agenciatributaria.gob.es/Sede/iva/tipos-impositivos-iva.html
- **European Commission — VAT in the European Union** — cross-border B2B VAT framing and reverse-charge concepts via https://taxation-customs.ec.europa.eu/taxation/vat/vat-european-union_en
- **European Commission — VAT Explanatory Notes (e-commerce / cross-border packages as context)** — treat as secondary context only; verify the specific regime before advising via https://taxation-customs.ec.europa.eu/taxation/vat_en

## Freelancer withholding (IRPF) context (Spain)

- **Agencia Tributaria — Retenciones e ingresos a cuenta** — professional withholding concepts that may appear on freelancer-to-company invoices via https://sede.agenciatributaria.gob.es/Sede/irpf/retenciones-ingresos-cuenta.html

## Portable PDF / generation hygiene

- **PDF Association — PDF basics** — treat generated invoices as durable documents; prefer stable archival PDFs over ad-hoc screenshots via https://www.pdfa.org/resource/pdf-basics/

## How to use these sources in-session

- Cite the matching source group when stating required legal fields, VAT rates, or credit-note rules.
- If the user’s country is not Spain, do not invent local statute numbers; load jurisdiction-specific primary docs before finalizing legal claims.
- Keep tax IDs, IBANs, and credentials local; sources above justify field presence, not data exfiltration.
