# Official Sources Map - AGI

Use these primary sources when verifying epistemic humility language, multi-step planning habits, metacognition cues, or cognitive-bias traps. Prefer the full URL in PR notes and user-facing citations. This skill stays vendor-neutral: sources justify reasoning principles, not a mandatory persona brand.

## Epistemic humility and uncertainty

- **Stanford Encyclopedia of Philosophy — Epistemology** — knowledge, justification, and limits of belief via https://plato.stanford.edu/entries/epistemology/
- **Stanford Encyclopedia of Philosophy — Evidence** — how claims should track available evidence rather than confidence theater via https://plato.stanford.edu/entries/evidence/
- **Stanford Encyclopedia of Philosophy — Self-Knowledge** — monitoring what one does and does not know via https://plato.stanford.edu/entries/self-knowledge/

## Planning, decomposition, and verification

- **NIST AI RMF 1.0 overview** — map, measure, and manage risk before irreversible action via https://www.nist.gov/itl/ai-risk-management-framework
- **NIST AI RMF 1.0 publication record** — canonical framework citation via https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10
- **NIST.AI.100-1 PDF** — primary text for risk functions and measurement language via https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-1.pdf
- **Google SRE Book table of contents** — embrace risk, verification, and operational checkpoints rather than perfectionism via https://sre.google/sre-book/table-of-contents/
- **PRINCE2 overview** — staged planning, controlled phases, and exception paths for multi-step work via https://www.prince2.com/usa/what-is-prince2
- **MindTools — PDCA** — plan-do-check-act loop as a lightweight verification milestone pattern via https://www.mindtools.com/a4wo118/plan-do-check-act-pdca

## Metacognition and cognitive traps

- **APA Dictionary — Metacognition** — monitor and regulate one's own thinking quality via https://dictionary.apa.org/metacognition
- **APA Monitor — Metacognition cover feature** — practical metacognitive habits in learning and judgment via https://www.apa.org/monitor/2017/03/cover-metacognition
- **The Decision Lab — Cognitive Biases** — overconfidence, anchoring, and social-approval bias patterns via https://thedecisionlab.com/biases
- **Kahneman Thinking, Fast and Slow (publisher page)** — System-1 autopilot vs deliberate System-2 checks; conceptual map only via https://www.penguinrandomhouse.com/books/176228/thinking-fast-and-slow-by-daniel-kahneman/

## Communication calibration

- **Nielsen Norman Group — How Users Read on the Web** — scannable, honest structure beats padded certainty via https://www.nngroup.com/articles/how-users-read-on-the-web/
- **Interaction Design Foundation — Trust** — credibility and calibrated communication principles via https://www.interaction-design.org/literature/topics/trust
- **Google Developer Documentation Style Guide** — match audience expertise; avoid filler hedges and false precision via https://developers.google.com/style
- **Google style highlights** — consistency habits that keep explanations crisp via https://developers.google.com/style/highlights

## How to use these sources in-session

- Cite the matching group when claiming uncertainty calibration, planning structure, bias checks, or communication fit.
- Do not invent live demographic, market, or vendor numbers; point to a current primary source or admit the gap.
- Keep AGI invisible: sources improve judgment quality; they are not content to lecture unless the user asks.
- If the user's domain standard conflicts with a general heuristic, prefer the local standard and record the constraint under `<state_root>/`.
