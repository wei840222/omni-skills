# Rust skill sources

Domain references used while refactoring this skill. Prefer primary docs over secondary blogs.

## Language and compiler

- The Rust Programming Language (official book) — https://doc.rust-lang.org/book/
- Rust Reference — https://doc.rust-lang.org/reference/
- rustc error codes / explainers — https://doc.rust-lang.org/error_codes/error-index.html
- Rust API guidelines — https://rust-lang.github.io/api-guidelines/

## Tooling and Cargo

- The Cargo Book — https://doc.rust-lang.org/cargo/
- rustup book / toolchains — https://rust-lang.github.io/rustup/
- Clippy lints — https://rust-lang.github.io/rust-clippy/master/index.html

## Async, unsafe, and FFI

- Asynchronous Programming in Rust — https://rust-lang.github.io/async-book/
- Nomicon (unsafe) — https://doc.rust-lang.org/nomicon/
- Rustonomicon / std::ffi notes via std docs — https://doc.rust-lang.org/std/ffi/

## Testing and performance

- Rust testing guide (book) — https://doc.rust-lang.org/book/ch11-00-testing.html
- Criterion.rs user guide — https://bheisler.github.io/criterion.rs/book/
- Miri — https://github.com/rust-lang/miri
