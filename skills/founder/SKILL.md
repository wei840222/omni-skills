# Founder

Founder-operating judgment for **validation, PMF, capital posture, early team,
execution, pivots, survival, and psychology**. Knowledge-only coaching: this
skill does **not** own durable company records. Persist venture notes through
the user's existing system or a sibling skill after the recommendation is clear.

## When to load

Load for founder-mode questions:

- pre-product validation and smallest MVP bets
- PMF signals, retention vs acquisition trade-offs
- whether/when to raise, how to prepare, how to read rejection
- first 10 hires, equity caution, firing speed
- weekly execution cadence and focus
- pivot vs persevere with runway constraints
- cash/runway stress and founder mental load

## Primary workflow

Execute in order. Stop early when a missing input blocks a safe recommendation.

1. **Classify the ask** — early-stage validation, PMF diagnosis, fundraising,
   team, execution, pivot, survival, or psychology.
2. **Inventory known facts** — stage evidence, customers talked to, retention
   signal, cash/runway in weeks, burn, growth rate, team size, last irreversible
   decision. Label unknowns; do not invent traction, revenue, or investor intent.
3. **Load only the reference that owns the bottleneck**:

| Bottleneck | Load |
|------------|------|
| Domain rules across stages (validation → psychology) | `references/domain.md` |
| Verified source URLs used in this package | `references/sources.md` |

4. **Apply core operating rules** (below) to the known facts.
5. **Produce one evidence-bound next step** — recommendation, missing-data asks,
   and a dated owner action when the user wants movement. If evidence is thin,
   say what is missing instead of fabricating proof.

## Core rules

### 1. Validate before you scale building

- Talk to customers before large build programs; assumptions are usually wrong.
- Validate the problem before locking a solution.
- Ship an embarrassingly small MVP that tests one hypothesis.
- Optimize for speed of learning early; polish follows proven demand.
- Treat cofounder choice like a high-stakes partnership: complementary skills,
  aligned values, stress-tested working norms.

### 2. Treat PMF as measurement

- Prefer the Sean Ellis dependence bar: among recent active users, ≥40% would be
  "very disappointed" without the product (classic threshold; re-check source).
- Retention beats acquisition while the bucket still leaks.
- Pull (inbound demand you can barely keep up with) beats push persuasion.
- Before PMF, scale only what already works for the dependent cohort.

### 3. Raise from momentum, prepare the numbers

- Prefer raising with momentum rather than desperation.
- Know ARR/growth, burn, runway (in weeks), and unit economics cold.
- Expect pattern-matching from investors; know which pattern you fit.
- SAFE vs priced round both have trade-offs; name them explicitly.
- Many meetings per yes is normal; a short reject streak is weak company signal
  by itself.

### 4. Build the first team carefully

- The first ~10 hires set culture; choose slowly.
- Early, prefer slope (learning speed) over pedigree.
- Fire fast when performance stays poor after clear feedback.
- Equity is scarce — be generous and deliberate.
- Founders doing everything forever blocks scale; delegate before collapse.

### 5. Execute with focus

- Focus means declining good ideas, not only bad ones.
- One north-star metric plus 2–3 supporting metrics; more usually dilutes focus.
- Weekly cadence: set goals, execute, review, repeat.
- Ship and iterate from feedback rather than waiting for perfect.
- Default to action when analysis loops stop changing the decision.

### 6. Pivot with conviction and runway

- Pivot strategy while keeping the core problem/vision when evidence demands it.
- Let customer/data evidence show what fails; customers suggest what might work.
- Half-pivots fail — commit or stay the course deliberately.
- More runway expands pivot options; late pivots with weeks of cash are fragile.
- Kill projects before sunk-cost loyalty kills the company.

### 7. Survive on cash discipline

- Cash is oxygen — track runway in weeks.
- Paying customers solve more arguments than slideware.
- Cut costs in chunks that change runway, not demoralizing nickels.
- Down rounds happen; survival can outrank valuation optics.
- Protect mental health as operating capacity, not optional luxury.

### 8. Stabilize founder psychology

- Imposter feelings are common; they are not unique proof of unfitness.
- Emotional variance is extreme; expect regression to the mean.
- Keep founder peers who understand the load.
- Separate personal identity from company outcomes.
- Ask for help early; private help-seeking is normal.

## Failure branches

| Condition | Action |
|-----------|--------|
| No customer conversations and a large build plan | Pause build scale; design a smallest validation loop first |
| Retention unknown / leaking and user wants paid acquisition | Prioritize retention diagnosis before spend |
| Raise panic after few investor passes | Recheck runway weeks + traction evidence; avoid panic pivot |
| Hiring senior team pre-infrastructure | Prefer founder-done scar tissue or lean generalists first |
| Irreversible pivot with < ~8–12 weeks runway and no plan | Surface survival options before strategy rewrite |
