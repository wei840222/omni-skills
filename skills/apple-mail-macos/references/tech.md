# Apple Mail (macOS) Automation Notes

Apple Mail on macOS supports automation via AppleScript (often invoked via the `osascript` command), the Shortcuts app, and direct SQLite database reads for indexed content. It provides access to accounts configured within Mail.app, functioning as a unified client layer.
