# Codes, Zoning, and Permits

This skill gives **boundary guidance**, not sealed drawings or guaranteed approvals. Local adopted codes, amendments, and licensed professionals control final compliance.

## What to ask first

1. Project location (city / county / country).
2. Building type and occupancy (house, multifamily, commercial, accessory structure).
3. Work type (new build, addition, change of use, interior only, structural change).
4. Whether the site is in a historic district, floodplain, coastal zone, or HOA.

## Zoning vs building code

- **Zoning** sets what is allowed on the lot: use, setbacks, height, floor-area ratio, parking, lot coverage.
- **Building codes** set how the structure must perform: egress, structural safety, fire, energy, accessibility.
- A design can be zoning-legal and still fail building code (and the reverse).

## Permit boundary

- Cosmetic finishes often need no structural permit; moving walls, openings, stairs, MEP, or change of use usually does.
- Unpermitted work can create insurance, resale, and liability problems — surface that risk early.
- Historic districts and overlay zones add review layers before construction drawings are “done.”

## Professional handoff

Route to local licensed professionals when the ask involves:

- structural sizing, foundations, lateral systems
- MEP design and fire-life safety systems
- accessibility barrier-removal compliance for public or multifamily buildings
- sealed drawings, permit applications, or variance petitions

For role-based IBC depth and practice notes, hand off to `architecture`. For renovation contractor sequencing, hand off to `home-renovation`. For room-level fit-out, hand off to `interior-design`.

## Positive default path

1. Capture location + program.
2. List zoning unknowns to verify with the local planning desk.
3. Keep concept plans labeled **preliminary / not for construction**.
4. Name the next official step (planning check, architect of record, engineer) before any build advice.
