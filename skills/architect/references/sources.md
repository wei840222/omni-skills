# Domain sources

Primary references used for domain accuracy. Prefer the current adopted local code over model-code summaries.

## Building codes and practice

- **International Code Council — IBC overview** — model commercial/building code family used widely as a base for local adoptions. https://www.iccsafe.org/products-and-services/i-codes/2018-i-codes/ibc/
- **International Code Council — IRC overview** — model residential code family for one- and two-family dwellings where adopted. https://www.iccsafe.org/products-and-services/i-codes/2018-i-codes/irc/
- **ICC Codes landing** — current code products and adoption context. https://www.iccsafe.org/products-and-services/i-codes/code-development/

## Accessibility

- **U.S. Access Board — ADA Accessibility Standards** — federal accessibility standards for applicable facilities in the United States. https://www.access-board.gov/ada/
- **ADA.gov — Design Standards** — official U.S. Department of Justice accessibility design standards entry. https://www.ada.gov/law-and-regs/design-standards/

## Passive design and energy

- **U.S. Department of Energy — Passive Solar Home Design** — orientation, glazing, thermal mass, and shading fundamentals. https://www.energy.gov/energysaver/passive-solar-home-design
- **U.S. Department of Energy — EnergySaver home design** — whole-home efficiency context for residential envelopes. https://www.energy.gov/energysaver/energy-saver

## Planning and zoning context

- **American Planning Association — knowledge center** — planning practice context for zoning and land use process (jurisdiction still controls). https://www.planning.org/knowledgebase/

## Historic and regulated work boundaries

- When work may disturb lead paint in pre-1978 U.S. housing, follow EPA RRP requirements via a certified firm as applicable: https://www.epa.gov/lead/renovation-repair-and-painting-program

Record the exact local municipal code URL in project notes when the user provides a jurisdiction.
