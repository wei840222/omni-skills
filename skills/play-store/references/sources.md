# Official Sources & Technical Specifications

This document records the official Android Developer and Google Play Console documentation.

## Official Android & Google Play References

- **Android Target API Level Requirements**: [https://developer.android.com/google/play/requirements/target-sdk](https://developer.android.com/google/play/requirements/target-sdk)
  - Target SDK enforcement: starting August 31, 2026, standard new apps and updates must target Android 16 (API level 36); Wear OS and Automotive target API 35; Android TV and XR target API 34.
- **Android App Bundle (AAB) Guide**: [https://developer.android.com/guide/app-bundle](https://developer.android.com/guide/app-bundle)
  - Publishing format requirement replacing monolithic APKs, dynamic feature delivery, and Play Feature Delivery / Play Asset Delivery.
- **Google Play Developer Content Policy**: [https://play.google/developer-content-policy/](https://play.google/developer-content-policy/)
  - Store listing requirements, restricted content categories, deceptive behavior prohibitions, and monetization rules.
- **Google Play Test Tracks & Release Management**: [https://support.google.com/googleplay/android-developer/answer/9845334](https://support.google.com/googleplay/android-developer/answer/9845334)
  - Release track administration (internal testing, closed beta, open beta) and rollout progression to production.
