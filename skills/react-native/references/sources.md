# Official Sources & Architecture References

This document records the primary official documentation and technical specifications for React Native and Expo mobile app development.

## Official Framework Documentation

- **React Native Documentation**: [https://reactnative.dev/docs/getting-started](https://reactnative.dev/docs/getting-started)
  - Core component library (`View`, `Text`, `ScrollView`, `FlatList`), native event loops, and styling flexbox models.
- **React Native New Architecture**: [https://reactnative.dev/architecture/landing-page](https://reactnative.dev/architecture/landing-page)
  - Fabric concurrent renderer, TurboModules native bridging, JSI (JavaScript Interface), and Bridgeless mode.
- **Expo Documentation**: [https://docs.expo.dev/](https://docs.expo.dev/)
  - Expo SDK workflow, Config Plugins, Prebuild, and cross-platform native modules.
