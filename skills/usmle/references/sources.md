# Sources — USMLE

Official and primary references used to ground USMLE prep guidance. Prefer these over secondary blogs when format, scoring, eligibility, or calendar claims change. Re-check the linked page before quoting a live deadline, fee, cut score, or pathway rule.

## USMLE / FSMB / NBME program authorities

- United States Medical Licensing Examination (USMLE) home — via https://www.usmle.org/
- USMLE Bulletin of Information — via https://www.usmle.org/bulletin-information
- USMLE Step 1 overview — via https://www.usmle.org/step-exams/step-1
- USMLE Step 2 CK overview — via https://www.usmle.org/step-exams/step-2-ck
- USMLE Step 3 overview — via https://www.usmle.org/step-exams/step-3
- NBME for students / examinees — via https://www.nbme.org/examinees
- Federation of State Medical Boards (FSMB) — via https://www.fsmb.org/

## Scores, scheduling, and practice

- USMLE scores and score reporting — via https://www.usmle.org/scores-transcripts
- NBME Self-Assessments (CBSSA / CCSSA family entry) — via https://www.nbme.org/examinees/self-assessments
- Prometric USMLE scheduling entry — via https://www.prometric.com/test-takers/search/usmle

## IMG / ECFMG pathway

- ECFMG / Intealth certification overview — via https://www.ecfmg.org/
