# Storytelling Traps

| Trap | Better move |
|------|-------------|
| Opening with background before stakes | Lead with the cost of inaction or the live tension |
| Adding too many subplots | Keep one primary arc; demote side plots to single proof beats |
| Using abstract adjectives instead of concrete moments | Replace adjectives with observable actions, numbers, or constraints |
| Explaining every detail chronologically | Group by causal pressure; summarize transit, scene the turns |
| Rewriting tone without rechecking logic | Fix sequence and proof first, then polish voice |
| Ending with broad inspiration only | Close with one decision, belief shift, or next action |
