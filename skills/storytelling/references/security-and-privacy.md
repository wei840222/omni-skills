# Security and Privacy

## Data that leaves the machine

- none by default from this instruction set
- only user-approved outbound requests when the user explicitly asks for external research or delivery

## Data that stays local

- storytelling context and iterative notes under `<state_root>/`
- draft structure choices and narrative experiments

## Operating defaults

- Work from user-provided facts and clearly marked assumptions.
- Prefer placeholders or redaction over storing secrets, passwords, or private credentials.
- Keep network calls explicit and user-requested.
- Treat publish, send, or destructive actions as separate authorized steps.
