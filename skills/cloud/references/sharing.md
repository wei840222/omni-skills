# Sharing Files in the Cloud

## Quick reference

| Situation | Best approach |
|-----------|---------------|
| Send a file once to anyone | Share link (with expiration when available) |
| Collaborate on a document | Shared folder or live doc |
| Family photo sharing | Shared album or folder |
| Recipient prefers simple methods | Email attachment under ~25 MB |
| Sensitive document | Encrypt first or use a secure non-link channel |

## iCloud

1. Files app or iCloud.com → Share File/Folder
2. Choose "Only people you invite" or "Anyone with the link"
3. Set view-only vs can make changes

**Shared Album (photos):** Photos → Albums → Shared Album → add people.

**End sharing:** Manage Shared File / Remove Access.

**Gotcha:** editing often requires an Apple ID; view-only links are broader.

## Google Drive

1. Right-click → Share
2. Add people by email **or** Get link → Anyone with the link
3. Role: Viewer, Commenter, or Editor
4. Set expiration in advanced settings when available

**End sharing:** remove people or turn the link off.

**Gotcha:** "Shared with me" items are not in My Drive until added; they may
not count against the recipient quota.

## Dropbox

1. Share → email invite or create link
2. Can edit vs can view
3. Paid plans may add password and expiration on links

**Shared folder:** appears in each member's Dropbox; leaving removes it from
yours without deleting others' copies when you are not the sole owner.

**End sharing:** delete the link or adjust folder membership.

## OneDrive

1. Share → Anyone / Specific people
2. Allow editing on/off; block download when needed
3. Set expiration / password when the tenant allows it

**Gotcha:** work/school OneDrive policies can disable anonymous links entirely.

## Permission levels

| Level | Typical capability |
|-------|--------------------|
| Viewer | Open / download |
| Commenter | View + comments (Docs-style) |
| Editor | Modify and often delete |
| Owner | Full control, transfer, reshare |

Give the minimum role that still unblocks the task. Start at Viewer.

## Security tips

- Prefer expiring links for one-off sends
- Review sharing quarterly
- Share specific folders, not entire drives
- Password-protect sensitive packages when the product supports it
- Do not put unencrypted ID or financial scans on "anyone with the link"
