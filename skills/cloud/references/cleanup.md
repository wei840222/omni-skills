# Freeing Up Cloud Storage

## iCloud

1. **Check usage:** Settings → [Your Name] → iCloud → Manage Account Storage
   (wording varies by iOS/macOS version).
2. **Photos:** delete blurry/duplicates; empty Recently Deleted.
3. **Old device backups:** remove backups for devices you no longer own.
4. **Messages:** large histories count against quota when Messages in iCloud is
   on.
5. **App data:** review per-app usage and delete unused data.

Nuclear option (photos only): turn off iCloud Photos, ensure originals are on
device or another backup, delete from iCloud, then re-enable with Optimize
iPhone/Mac Storage if desired.

## Google Drive / Google One

1. **Check usage:** [drive.google.com/settings/storage](https://drive.google.com/settings/storage)
   or Google One storage.
2. Storage is shared with **Gmail** and **Google Photos**.
3. Sort Drive by size; empty Trash.
4. Gmail: search `has:attachment larger:10M` and remove unneeded mail.
5. Photos: empty Trash.

Shared files you do not own usually do not count against your quota; items in
your Trash do.

## Dropbox

1. Check plan usage under account settings.
2. Permanently delete items under Deleted files.
3. Leave shared folders you no longer need (frees local and account space
   depending on ownership).
4. Disable Camera Uploads if another service already backs up the camera roll.
5. Version history can retain space on higher plans — contact support only when
   ordinary cleanup is exhausted.

## OneDrive

1. Check Manage Storage from OneDrive web or the Windows app.
2. Empty the recycle bin (retention is multi-week, not instant).
3. Review PC folder backup (Desktop/Documents/Pictures) for unexpected bulk.
4. Confirm personal vs work account before deleting.

## General tips

- Empty trash on **every** provider involved.
- Run exactly one photo auto-backup.
- Use each vendor storage analyzer for large outliers.
- WhatsApp and similar app backups often hide multi-GB archives.

## Upgrade vs clean

**Upgrade** when cleanup is done, time costs more than the plan, and the data
is worth protecting.

**Clean** when junk, duplicates, or multi-year unreviewed media dominate.
