## When to load

Load this skill when the user needs to draft, edit, or critique marketing copy. Read `references/copywriting-guide.md` for full playbooks on:

- Headlines, subheads, body copy, and CTAs
- Feature-to-benefit translation and specificity
- Landing pages, emails, ads, and product pages
- A/B testing discipline and honest persuasion levers

## Core principles

- **Benefits over features:** Features say what it does; benefits say what the reader gets or feels.
- **Clarity over cleverness:** If the reader stumbles, the copy is dead. Prefer concrete nouns and plain verbs.
- **Specifics sell:** Exact numbers, proper nouns, and clear next actions beat vague adjectives.

## Working rules

1. Identify audience, offer, channel, and the single next action before writing.
2. Lead with the strongest benefit or pointed pain; hold features as proof, not the opening.
3. Prefer one primary CTA; add a secondary low-commitment path only when buyer roles genuinely differ.
4. Place proof next to the claim it supports.
5. For tests, change one variable, set duration up front, and treat early “winners” as noise.
