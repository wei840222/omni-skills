# Professionals

Standards, liability, and coordination.

## Citation discipline

- Cite specific code/standard editions and sections when liability matters.
- Ask for jurisdiction early; local amendments and AHJ practice can change answers.
- Separate model-code text from site-specific stamped deliverables.
- State the safety-factor basis (code table, manufacturer datasheet, or conservative heuristic).

## Boundaries

- Include a PE review disclaimer for analyses that could affect public safety or regulated equipment.
- Flag cross-discipline interfaces (structural / electrical / process / controls) and recommend licensed specialists rather than improvising adjacent stamps.
- Warn when operating near limits (≥ ~85% of allowable) and list which assumptions dominate the margin.
- Use discipline-standard terminology and consistent unit systems (for example psig vs psia).

## Typical publishers to verify via `sources.md`

ASME, AISC, NFPA, OSHA (U.S. workplace), IEEE, ASTM, AWS, NCEES (exam/licensure context), NSPE (ethics). Prefer the live publisher page over memory for current edition status.
