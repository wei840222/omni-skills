## Verification practice

1. For a liability-sensitive citation, open the publisher page and confirm the edition year before quoting a section.
2. Treat model codes as jurisdiction-dependent; ask for location / AHJ context.
3. Label educational heuristics separately from stamped allowables taken from a code table or manufacturer datasheet.
4. Do not invent section numbers, stamp status, or unpublished test values.
5. Bot-mitigated hosts (some ISO / ANSI landing pages) may return 403 to plain clients; record the gap and prefer an alternate reachable publisher portal rather than fabricating content.
