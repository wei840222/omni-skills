# Writing taste — prose judgment

## Core test

Read aloud. Mark stumbles, boredom, and skip-ahead moments. The mouth catches what the eye forgives.

Plain-language and web-scanning research support short sections, familiar words, and scannable structure for digital prose (Digital.gov plain language; NN/g how users read on the web — see `sources.md`). Taste still decides voice, rhythm, and which clichés die.

## Signals of strong prose

- Rhythm variation — long sentence, then short; rest after density
- Specific over general — “oak leaves” not “nature”
- Verbs doing work — adjectives not piled as decoration
- Confident cuts — fewer hedges (`very`, `somewhat`, `a bit`)
- Earned complexity — density only where it pays off

## Signals of weak prose

| Pattern | Problem |
|---|---|
| Throat-clearing openings | “In today’s world…”, “It’s important to note…” |
| Over-explanation | Same point three ways |
| Intensifier addiction | very / extremely / incredibly / absolutely |
| Passive everywhere | Avoiding commitment |
| Everything equal | No emphasis hierarchy |

## Editing test

For each element:

1. Does this add or only repeat? → cut repeats
2. Could this be half as long? → cut if yes
3. Would its absence be missed? → cut if no

Strong prose feels complete at minimum length. Weak prose needs extra explanation to seem finished.

## LLM writing patterns to reject

| Default pattern | Problem |
|---|---|
| “It’s worth noting that…” | Hedge filler |
| “This is a game-changer” | Cliché hype |
| “Let’s dive into…” | Generic CTA |
| “In conclusion…” | Unnecessary signpost |
| Mechanical “First… Second… Third…” | Outline voice without thought |
| Excessive parallelism | Pattern-matched symmetry |

These mark committee writing — statistically average, not aesthetically specific.

## Voice consistency

Pick one primary mode per piece:

- Formal or conversational
- Authoritative or exploratory (mark intentional shifts)
- Dense or sparse

Unplanned voice drift reads like multiple authors.

## Sentence-level cuts

Prefer:

- “In order to” → “To”
- “Due to the fact that” → “Because”
- “It is important to” → state the important thing
- “There are many who” → name them

Watch:

- Stacked adjectives before nouns
- Adverbs on already-strong verbs
- Qualifiers that undercut confidence
- Abstract nouns where concrete ones exist

For multi-format voice memory systems or conversion copy systems, hand off to `writing` or `copywriting` after the taste diagnosis.
