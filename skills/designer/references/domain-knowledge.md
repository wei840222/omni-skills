# Domain Knowledge and Sources

Use these primary sources to verify standards or platform guidance before making a compliance claim. Interpret the current page in the context of the target platform and version.

## Accessibility

- **W3C WCAG 2.2** — normative success criteria for color contrast, reflow, text spacing, focus visibility, and target size. https://www.w3.org/TR/WCAG22/
- **W3C Understanding SC 1.4.3 Contrast (Minimum)** — explains the WCAG AA text-contrast threshold and its exceptions. https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
- **W3C Understanding SC 2.5.8 Target Size (Minimum)** — explains the WCAG 2.2 target-size criterion and exceptions. https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html

## Platform design systems

- **Material Design 3** — Android and cross-platform guidance for color, typography, elevation, and component behavior. https://m3.material.io/
- **Apple Human Interface Guidelines** — Apple-platform guidance for navigation, safe areas, system typography, and controls. https://developer.apple.com/design/human-interface-guidelines/
