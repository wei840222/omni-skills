# Official Sources & Technical Specifications

This document records the official standards and API documentation for Fastmail and the JSON Meta Application Protocol (JMAP).

## Official Standards & Fastmail Developer Documentation

- **RFC 8620 (JMAP Core)**: [https://www.rfc-editor.org/rfc/rfc8620.html](https://www.rfc-editor.org/rfc/rfc8620.html)
  - Core JSON Meta Application Protocol data model, session resource, standard request/response envelope, method call batching, and error handling taxonomy.
- **RFC 8621 (JMAP for Mail)**: [https://www.rfc-editor.org/rfc/rfc8621.html](https://www.rfc-editor.org/rfc/rfc8621.html)
  - Data models and methods for `Mailbox`, `Thread`, `Email`, and `EmailSubmission` resources, query filtering syntax, and push notifications.
- **Fastmail Developer Portal & APIs**: [https://www.fastmail.com/dev/](https://www.fastmail.com/dev/)
  - API token authentication, session discovery URL (`https://api.fastmail.com/jmap/session`), Masked Email API specifications, and rate limit guidelines.
