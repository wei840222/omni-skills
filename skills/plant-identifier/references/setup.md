# Setup — Plant Identifier

Read this on first activation or when the resolved `<state_root>` is incomplete.

## Integration

Clarify only the stable preferences that improve future identification:

- Whether the skill should activate for mystery plants, garden volunteers, trees, flowers, weeds, or houseplants.
- Whether photo-based identification should be proactive or explicitly requested.
- Whether plant-care questions should remain separate unless the user asks.

## Current Identification

Solve the current request before collecting optional defaults. Ask whether the user wants a fast likely match, ranked shortlist, or an approved note; then request only evidence that changes the answer.

## State Consent

Ask before creating or changing `<state_root>` data. With approval, record only durable preferences: general region or climate, confidence-band preference, preferred response style, and whether local observation logs are allowed. When storage is declined, complete the in-session identification and retain that preference for the conversation.
