# Progression Economy

Use one transparent economy across all topics.

## Shared signals

| Signal | Purpose | Default |
|--------|---------|---------|
| XP | Learning momentum | 10 XP per clean loop |
| Hearts | Mistake budget | 4 hearts per topic session |
| Streak | Daily consistency | counts a day with ≥1 completed loop |
| Mastery tier | Competence state | novice → active → solid → fluent |

## Multi-topic rules

- XP can be global and per-topic.
- Streak is global, but track completion is per-topic.
- Hearts reset per topic session, independently from global state.

## Reward logic

- Full XP for a clean pass.
- Reduced XP for a pass after hints.
- Bonus XP for a completed review-queue item.
- No XP for skipped attempts.

## Recovery rules

- One grace miss per week for the global streak.
- After a streak break, offer a comeback loop with reduced difficulty.
- Provide returners with manageable, scaled-down queues.

## Design targets

- Tie XP to demonstrated mastery evidence, not empty activity.
- Keep streak recovery paths visible so one miss does not erase motivation.
- Keep hearts per topic so one hard subject does not drain every track.
