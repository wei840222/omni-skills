## Freshness Rules

1. Named frameworks (SCAMPER, Six Thinking Hats, TRIZ): keep method names stable; verify attributions and official program pages before teaching certification-style claims.
2. Taste-calibration heuristics in this skill are operational defaults, not psychological diagnoses.
3. When a user asks for research-backed creative strategy, prefer the primary sources above and date any secondary synthesis.
