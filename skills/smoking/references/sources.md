# Sources — Smoking

Primary references used for Gate 6 knowledge updates. Prefer these over informal blogs when guidance conflicts.

## Cessation guidance

- **CDC — Quit Smoking** — evidence-based quit strategies, counseling, and medication overview via https://www.cdc.gov/tobacco/campaign/tips/quit-smoking/index.html
- **CDC — How to Quit** — stepwise practical quit actions via https://www.cdc.gov/tobacco/campaign/tips/quit-smoking/guide/index.html
- **NHS — Quit smoking** — practical stop-smoking support framing via https://www.nhs.uk/better-health/quit-smoking/
- **NICE NG209 — Tobacco: preventing uptake, promoting quitting and treating dependence** — clinical guideline framing for behavioral and pharmacologic support via https://www.nice.org.uk/guidance/ng209

## Craving, relapse, and medication discussion scope

- **CDC — Medications for quitting tobacco** — discuss NRT/prescribed options with clinicians; do not dose in-skill via https://www.cdc.gov/tobacco/campaign/tips/quit-smoking/quit-smoking-medications/index.html
- **WHO — Quitting tobacco** — global public-health framing for cessation support via https://www.who.int/activities/quitting-tobacco
