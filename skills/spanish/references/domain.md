# Spanish Domain Knowledge

Use this file for register, muletillas, diminutives, expressiveness, reactions, and delivery checks while drafting Spanish. It describes common conversational patterns; it is not a license to invent intimacy, slang, or a dialect the user did not ask for. Keep glosses aligned with `references/sources.md`.

## Formality Default

Default AI register is often too high. Casual Spanish among peers is warm and direct. Unless the audience is professional, institutional, older, unfamiliar, or explicitly formal, lean casual:

- Prefer `vale` / `bueno` over stiff `de acuerdo`
- Prefer short fragments over fully completed textbook sentences
- Prefer selective diminutives and muletillas over perfectly polished prose

For unknown recipients in work or institutional settings, prefer careful `usted` rather than inventing intimacy.

| Situation | Default | Delivery rule |
| --- | --- | --- |
| Official, academic, or unfamiliar institution | `usted` + clearer greetings | Complete sentences; avoid heavy slang and intimate interjections |
| Work chat with known colleagues | soft `usted` or established `tú` by workplace norm | Clear and friendly; light muletillas only if that chat already uses them |
| Friend, peer chat, SMS, or social post | `tú` (or requested `vos`) | Short lines, fragments, selective reactions |
| Public or mixed audience | Neutral everyday | Stay readable; skip intimate slang stacks unless requested |

## Tú vs Usted vs Vos

Critical distinction:

- **`usted`**: elders, professional or institutional contexts, strangers initially
- **`tú`**: friends, peers, most Spanish internet once the relationship is clear
- **`vos`**: Argentine / Rioplatense (and other user-named voseo locales only); keep morphology aligned
- Overusing `usted` among peers sounds cold; inventing `tú`/`vos` for unfamiliar formal recipients is a Required failure

Keep pronouns, clitics, verb agreement, and greetings aligned with the chosen address for the whole draft. Mid-text address drift is a Required failure.

## Sentence Completeness

Embrace fragments when the channel is conversational:

- `¿Vienes?` / `Sí, ahora.` (preferred over `Sí, voy ahora mismo.`)
- `¿Qué tal?` / `Bien, ¿y tú?` / `Tirando.`
- Let shared context carry weight; do not pad every reply into a full essay

## Diminutives

Use diminutives for warmth, not as a childish quota:

- `un momentito`, `cerquita`, `poquito`
- `ahora mismo` → `ahorita` in Mexican / broader Latin American casual speech
- Missing all diminutives in peer chat can sound cold; stacking them into formal `usted` copy is wrong

## Connectors

Swap formal transitions for natural ones in casual drafts:

- `Sin embargo` → `Pero bueno` / `Aunque`
- `Por lo tanto` → `Así que` / `Entonces`
- `Además` → `Y encima` / `Aparte`
- `No obstante` → prefer everyday `Pero` / `Aunque` in casual speech

## Muletillas and Flow

Optional conversational choices that keep prose from sounding textbook-stiff:

- `Bueno, es que…` / `Pues mira…` / `O sea…`
- `¿Sabes?` / `¿Entiendes?` / `¿No?`
- `La verdad es que…` / `Lo que pasa es que…`

Keep factual messages direct; insert a muletilla only where it helps the speaker's flow.

## Expressiveness

Match the source sentiment rather than replacing every ordinary word:

- `Bien` → `Genial` / `De puta madre` / `Guay` (Spain casual) when enthusiasm is intended
- `Mal` → `Fatal` / `Horrible`; crude intensifiers only when the source clearly wants them
- `Grande` → `Enorme` / `Tremendo` / `Bestial` when intensity still fits

## Emphatic Patterns

Spanish often doubles for emphasis—use when the speech act needs it:

- `A mí me parece…` (not only `Me parece`)
- `Lo que pasa es que…`
- `Es que no puedo`
- `Sí que lo hice`

## Interjections and Reactions

Sprinkle only when the context calls for emotional reaction, and keep one region:

- Spain: `¡Joder!` / `¡Hostia!` / `¡Flipante!` / `Madre mía`
- Mexico: `¡Órale!` / peer reactions that match Mexican Spanish
- Argentina: `¡Che!` and peer-appropriate Rioplatense reactions
- Shared soft reactions: `Uf`, `Buf`, `Bah`, `Anda`, `Venga`
- Shared surprise: `¿En serio?` / `¿De verdad?` / `¡No me digas!`

## Regional Lock

If a region is known or assumed, commit and stay consistent:

| Region | Safe casual markers | Do not mix in |
| --- | --- | --- |
| Spain | `vale`, `tío`, `mola`, `flipar`, `currar` | Mexican `güey` / Argentine `che` stacks |
| Mexico | `órale`, `chido`, `padre`, `güey`, `chamba`, `ahorita` | Spain `tío` / Argentine `boludo` stacks |
| Argentina | `che`, peer-only `boludo`, `re copado`, `laburar`, `morfar`, `vos` morphology | Spain `vale tío` / Mexican `órale güey` stacks |

Public or mixed audiences: stay in neutral everyday Spanish and skip intimate slang stacks unless requested.

## Delivery Check

Before sending:

1. One address form (`tú` / `usted` / `vos`) with matching morphology.
2. One regional variety when slang or interjections appear.
3. Source facts, names, numbers, dates, commitments, and uncertainty preserved.
4. Muletillas, diminutives, fragments, and slang appear only when the channel supports them.
5. A native reader would not screenshot the draft as stiff textbook Spanish for the chosen register.
6. Legal, medical, financial, or publication-sensitive Spanish keeps the requested formality and flags the need for qualified native review.
