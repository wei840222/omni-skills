# Business — Workplace Chinese

Workplace Chinese has rigid conventions. Getting them wrong signals outsider status.

---

## Email Skeleton

Standard Chinese business email structure:

```
主题：关于XXX的事宜

王总，您好！

[正文：直接说事，1-3段]

此致
敬礼！

张伟
2025年1月17日
```

### Opening

- 您好！(formal, safe for anyone)
- X总/X经理，您好！(address by title)
- Never open with just 你好 in first contact — too casual

### Body Rules

- Get to the point in the first sentence
- Use 关于/就 for topic framing: 关于下周会议安排…
- Requests use 请/烦请/恳请 (escalating politeness)
- Numbers and dates in Arabic numerals, not Chinese

### Closing

| Formality | Closing |
|-----------|---------|
| Very formal | 此致敬礼 |
| Standard | 祝好 / 祝工作顺利 |
| Semi-formal | 谢谢 / 麻烦了 |
| Internal/casual | (no closing needed) |

## Title Conventions

### The 总 Rule

Chinese workplace uses shortened titles, never full formal titles:

| Correct | Wrong |
|---------|-------|
| 王总 | 王总经理 |
| 李副总 | 李副总经理 |
| 张局 | 张局长 |
| 刘处 | 刘处长 |
| 陈科 | 陈科长 |

**Rule**: Surname + shortened rank. Never use the full title in direct address.

### Common Title Shortenings

| Full | Shortened | Used for |
|------|-----------|----------|
| 总经理 | 总 | Company head |
| 副总经理 | 副总 | Deputy head |
| 总监 | 总 | Director level |
| 经理 | 经理 | Manager (not shortened) |
| 主管 | 主管 | Supervisor |
| 主任 | 主任 | Office director |
| 处长 | 处 | Division chief (gov) |
| 科长 | 科 | Section chief (gov) |
| 局长 | 局 | Bureau chief (gov) |

### When No Title is Clear

- Use 老师 (teacher) as universal respectful address in many industries
- In tech: 哥/姐 (senior colleague) or just name
- In state enterprises: always use title

### Avoid

- 老板 (too colloquial for direct address, okay in third person)
- Full name without title (rude to seniors)
- 小X for someone senior (小X is for juniors)

## 通知 / 汇报 / 请示 — Format Differences

These three document types are often confused by AI.

### 通知 (Notice)

Top-down communication. Authoritative, informative.

```
关于XXX的通知

各部门：

[背景/原因，1-2句]
现将有关事项通知如下：
一、[事项1]
二、[事项2]
三、[事项3]

特此通知。

                                    XX部门
                                 2025年1月17日
```

**Key markers**: 现将有关事项通知如下 / 特此通知

### 汇报 (Report)

Upward communication. Describes what happened, results, status.

```
关于XXX的汇报

X总：

根据工作安排，现将XXX情况汇报如下：

一、基本情况
[描述现状]

二、主要做法
[做了什么]

三、存在问题
[遇到什么困难]

四、下一步计划
[打算怎么做]

以上汇报，请审阅。

                                    汇报人：张伟
                                 2025年1月17日
```

**Key markers**: 现将…汇报如下 / 以上汇报，请审阅

### 请示 (Request for Instructions)

Upward communication. Needs approval for something.

```
关于XXX的请示

X总：

[背景说明]
为[目的]，拟[方案]。现将有关事项请示如下：

一、[请示事项1]
二、[请示事项2]

妥否，请批示。

                                    XX部门
                                 2025年1月17日
```

**Key markers**: 请示如下 / 妥否，请批示 (or 当否，请批示)

### Quick Comparison

| Type | Direction | Purpose | Key closing |
|------|-----------|---------|-------------|
| 通知 | Down | Inform | 特此通知 |
| 汇报 | Up | Report status | 以上汇报，请审阅 |
| 请示 | Up | Request approval | 妥否，请批示 |

## Meeting Minutes Style (会议纪要)

```
XX公司第X次XX会议纪要

时间：2025年1月17日 14:00-16:00
地点：三楼会议室
主持：王总
出席：[名单]
记录：张伟

一、会议议题
本次会议主要讨论了以下事项：
（一）XXX
（二）XXX

二、会议决定
经讨论，会议决定：
（一）由XX部门负责XXX，于X月X日前完成。
（二）原则同意XXX方案，具体细节由XX修改后报X总审批。
（三）XXX

三、其他事项
[如有]
```

**Style rules:**

- Use 会议决定 not 大家决定
- Assign responsibility explicitly: 由XX负责
- Include deadlines
- No opinions, just decisions
- Past tense not needed (Chinese doesn't mark it)

## Workplace Chat Etiquette

### Messaging the Boss

- Keep it short and structured
- Lead with the ask or the conclusion
- Use 您 not 你
- Don't send voice messages
- Respond promptly during work hours

### Messaging Peers

- Can be more casual
- 你 is fine
- Voice messages OK if culture allows
- Still keep work topics clear

### Group Announcements

- Use @所有人 sparingly (only for truly important things)
- Format clearly with line breaks
- Include who needs to do what by when

---

## Key Principles

1. **Hierarchy matters** — title and tone shift with rank
2. **Brevity is respect** — busy people don't read long messages
3. **Structure signals competence** — use numbered lists in work docs
4. **Close properly** — every formal doc needs its formulaic ending
5. **Never confuse the three types** — 通知 informs, 汇报 reports, 请示 asks
