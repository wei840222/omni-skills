# Spoken Chinese for Scripts

Patterns for call scripts, voice notes, presentations, and spoken delivery.

---

## Spoken vs Written Register

| Feature | Written | Spoken |
|---------|---------|--------|
| Sentence length | Longer, complex | Shorter, fragmented |
| Particles | Fewer | More (啊, 呢, 吧, 嘛) |
| Repetition | Avoided | Topic repeated |
| Self-correction | Rare | Common |
| Formality | Higher | Lower |

---

## Call Scripts

### Customer service opening
```
您好，这里是[公司名]，我是[姓名]，请问有什么可以帮您？
```

### Returning a call
```
您好，我是[公司名]的[姓名]，刚才您致电咨询[事项]，请问现在方便吗？
```

### Transferring
```
请稍等，我帮您转接到[部门/同事]，他们可以更专业地为您解答。
```

### Closing
```
感谢您的来电，祝您生活愉快，再见。
```

### Rules
- Use 您 for customers
- Speak slower than normal conversation
- Repeat key information (dates, numbers, names)
- Confirm understanding: 请问我说明白了吗？

## Voice Notes

### Structure
1. **Greeting** (optional in close relationships)
2. **Context** (why you're sending this)
3. **Main point** (keep it under 30 seconds)
4. **Call to action** (what you need)

### Example
```
诶，是我。刚才开会说了个事，就是下周五之前要交那个报告，
你负责的数据分析部分，记得弄一下哈。有问题随时找我。
```

### Rules
- Shorter than you think (15-30 seconds ideal)
- One topic per voice note
- If it needs more than 45 seconds, call instead
- Use particles naturally (啊, 呢, 吧)
- Drop formal punctuation in transcription

## Toast / Presentation Patterns

### Toast structure
```
[称呼]，
[感谢/回顾]，
[祝愿/展望]，
[干杯/请]。
```

### Example (wedding)
```
各位亲朋好友，
感谢大家今天来见证我们的幸福时刻。
祝愿我们白头偕老，也祝大家身体健康、万事如意。
干杯！
```

### Presentation opening
```
大家好，今天我想跟大家分享/讨论[主题]。
[简要说明背景或问题]。
接下来我会从[几个方面]来展开。
```

### Presentation closing
```
以上就是我今天分享的内容。
[总结核心观点]。
谢谢大家，欢迎提问/讨论。
```

## Spoken Chinese Characteristics

### Topic repetition
Spoken Chinese repeats the topic because listeners can't re-read:

**Written:**
> 这个方案虽然成本高，但长期来看更划算。

**Spoken:**
> 这个方案吧，成本是高了点，但是呢，长期来看，这个方案其实更划算。

### Particle density
Spoken Chinese carries more particles:

**Written:**
> 这个方案可行。

**Spoken:**
> 这个方案应该可以吧。/ 这个方案我觉得行。/ 这个方案没问题啊。

### Self-correction
Spoken Chinese includes false starts and corrections:

```
我们下周一——不对，是周二——开会。
```

### Fragment sentences
Spoken Chinese uses fragments:

```
——然后呢？
——然后就没了。
——哦，这样啊。
```

## Reading Aloud Test

Before finalizing any script:

1. **Read it aloud** at normal speaking pace
2. **Time it** — should feel natural, not rushed
3. **Check for breath points** — long sentences need breaks
4. **Listen for stiffness** — if you wouldn't say it, rewrite it

### Signs it's too written
- Every sentence is complete (subject + verb + object)
- No particles (啊, 呢, 吧, 嘛)
- No repetition or self-correction
- Formal vocabulary in casual context (进行, 予以, 具备)

## Register Matching

| Context | Register | Example |
|---------|----------|---------|
| Customer call | Formal (您) | 请问有什么可以帮您？ |
| Colleague voice note | Casual (你) | 那个事你记得弄一下哈 |
| Wedding toast | Semi-formal | 感谢大家，祝愿… |
| Team presentation | Neutral | 大家好，今天讨论… |
| Friend voicemail | Very casual | 诶是我，那个事… |

---

## Common Mistakes

1. **Writing a script like an essay** — too structured, no particles
2. **Forgetting to repeat key info** — listeners can't re-read
3. **Using written vocabulary** — 进行讨论 → 讨论
4. **No breath points** — break long sentences
5. **Mismatched register** — 您 with close friends, 你 with customers
