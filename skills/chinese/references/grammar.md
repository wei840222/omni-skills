# Grammar — Chinese Grammar Mechanics

Chinese grammar has subtle rules that AI often gets wrong. This reference covers the most common pitfalls.

---

## 的/地/得 Rules

These three particles sound identical (de) but have different functions.

### 的 — Possessive/Attributive

**Function**: Connects modifier to noun (X 的 Y = X's Y, or X-ly Y)

**Structure**: [Modifier] + 的 + [Noun]

**Examples**:
- 我的书 (my book)
- 红色的车 (red car)
- 快速的发展 (rapid development)

**Test**: Can you insert "是…的" (is...)? If yes, use 的.
- 这车是红色的 ✓ → 红色的车 ✓

### 地 — Adverbial Marker

**Function**: Connects adverb to verb (X 地 Y = X-ly does Y)

**Structure**: [Adjective/Adverb] + 地 + [Verb]

**Examples**:
- 快速地跑 (run quickly)
- 认真地学习 (study seriously)
- 高兴地跳起来 (jump happily)

**Test**: Can you replace with [Adverb] + [Verb] without 地? If yes, 地 is optional but correct.
- 快速跑 ✓ → 快速地跑 ✓

**Modern usage**: In casual Chinese, 地 is often dropped. 快速跑 is acceptable.

### 得 — Complement of Degree/Result

**Function**: Connects verb to complement (does X so [adjective])

**Structure**: [Verb] + 得 + [Complement]

**Examples**:
- 跑得快 (run fast)
- 学得好 (study well)
- 高兴得跳起来 (so happy that jumped)

**Test**: Is it describing how well/completely an action is done? Use 得.
- 跑得快 (how fast did you run?) ✓
- 红色的车 (describes the car, not the action) ✗

### Quick Decision Tree

```
Is it connecting to a noun? → 的
  我的书, 红色的车

Is it connecting to a verb (adverbial)? → 地
  快速地跑, 认真地学

Is it after a verb (describing result/degree)? → 得
  跑得快, 学得好
```

### Common Mistakes

**Wrong**: 他跑的很快 (should be 得, describing how he runs)
**Right**: 他跑得很快

**Wrong**: 他认真的学习 (acceptable but 地 often dropped in casual)
**Right**: 他认真学习 / 他认真地学习

## 了 Aspect Markers

了 has two functions, often confused.

### 了₁ — Perfective Aspect (Verb 了)

**Position**: Immediately after verb
**Function**: Marks completed action

**Examples**:
- 我吃了饭 (I ate / I have eaten)
- 他看了电影 (He watched a movie)
- 我买了书 (I bought books)

**Test**: Can you add 已经 (already)? If yes, use 了₁.
- 我(已经)吃了饭 ✓

### 了₂ — Change of State (Sentence 了)

**Position**: End of sentence
**Function**: Marks new situation, change of state

**Examples**:
- 下雨了 (It's raining now / It started to rain)
- 我饿了 (I'm hungry now)
- 他来了 (He's here now / He has come)

**Test**: Is there a change from previous state? Use 了₂.
- 之前不饿，现在饿了 → 我饿了 ✓

### Both Together

Sometimes both appear:
- 我吃饭了 (I've eaten / I ate)
- 他看电影了 (He watched a movie)

**Structure**: Verb + 了₁ + Object + 了₂

### Negation

**Rule**: Don't use 了 with 没/没有 (past negation).

**Wrong**: 我没吃了饭
**Right**: 我没吃饭

**Exception**: 了₂ can appear with negation if marking change of state.
- 我不饿了 (I'm not hungry anymore)

### Common Mistakes

**Wrong**: 我昨天去了超市买东西 (double 了)
**Right**: 我昨天去超市买东西了 / 我昨天去了超市

**Wrong**: 我没看了那本书
**Right**: 我没看那本书

## 把/被 Constructions

### 把 — Disposal Construction

**Function**: Emphasizes what happens to the object

**Structure**: Subject + 把 + Object + Verb + Complement

**Examples**:
- 我把书放在桌上 (I put the book on the table)
- 请把门关上 (Please close the door)
- 他把作业做完了 (He finished the homework)

**When to use 把**:
1. Object is definite/specific (the book, not books in general)
2. Verb has a complement (result, direction, location)
3. Emphasis is on what happens to the object

**Test**: Can you rephrase as "Subject + Verb + Object + Complement" without 把? If yes and object is specific, 把 is optional but often preferred.

### 被 — Passive Construction

**Function**: Marks passive voice (often negative or unexpected)

**Structure**: Subject + 被 + Agent + Verb + Complement

**Examples**:
- 书被我放在桌上了 (The book was put on the table by me)
- 窗户被风吹开了 (The window was blown open by the wind)
- 他被老师批评了 (He was criticized by the teacher)

**When to use 被**:
1. Focus is on the receiver of action
2. Action is negative or unexpected
3. Agent is mentioned (if no agent, use 受/遭 instead)

**被 vs 受/遭**:
- 被 + Agent + Verb: 被老师批评
- 受/遭 + Noun (no agent): 受批评, 遭殃

### 把 vs 被

**把**: Active, focus on what you do to object
- 我把书放在桌上 (I put the book on the table)

**被**: Passive, focus on what happens to subject
- 书被我放在桌上 (The book was put on the table by me)

### Common Mistakes

**Wrong**: 我把饭吃了在食堂 (complement before 了)
**Right**: 我在食堂把饭吃了 / 我把饭在食堂吃了

**Wrong**: 我被批评 (missing agent if specific)
**Right**: 我被老师批评 / 我受批评 (no agent)

## 是…的 Pattern

**Function**: Emphasizes details of a completed action (time, place, manner, agent)

**Structure**: Subject + 是 + [Emphasized Element] + Verb + 的

**Examples**:
- 我是昨天来的 (It was yesterday that I came)
- 他是在北京学的中文 (He learned Chinese in Beijing)
- 我们是坐飞机去的 (We went by plane)

**When to use**:
1. Action is completed
2. You want to emphasize when/where/how/who
3. The fact itself is known, details are new information

**Test**: Can you ask "When/Where/How did X happen?" If yes, use 是…的.

### Negation

**Structure**: Subject + 不是 + [Emphasized Element] + Verb + 的

**Examples**:
- 我不是昨天来的 (It wasn't yesterday that I came)
- 他不是在北京学的中文 (He didn't learn Chinese in Beijing)

### Omission

是 can be omitted in casual speech:
- 我昨天来的 (= 我是昨天来的)
- 他北京学的中文 (= 他是在北京学的中文)

But 的 cannot be omitted.

### Common Mistakes

**Wrong**: 我是昨天来了 (了 and 是…的 don't mix)
**Right**: 我是昨天来的

**Wrong**: 我是去北京的 (verb should be inside)
**Right**: 我是去北京的 (this is actually correct if emphasizing destination)
**Better**: 我是坐飞机去北京的 (emphasizing manner)

## Europeanised Chinese (欧化中文)

Chinese influenced by English grammar patterns. Often sounds unnatural.

### Pattern 1: Passive Overuse

**AI-typical**: 这个问题被我们解决了
**Natural**: 我们解决了这个问题

**Rule**: Chinese prefers active voice. Use 被 only when necessary.

### Pattern 2: Excessive 的 Chains

**AI-typical**: 这是一个非常重要的关于环境保护的决定
**Natural**: 这个环境保护的决定非常重要

**Rule**: Break up long 的 chains. Move modifiers to predicate position.

### Pattern 3: Nominalization

**AI-typical**: 对他的批评引起了争议
**Natural**: 批评他引起了争议

**Rule**: Don't turn verbs into nouns unnecessarily.

### Pattern 4: Redundant 进行

**AI-typical**: 我们进行讨论
**Natural**: 我们讨论

**Rule**: 进行 is often filler. Delete it.

### Pattern 5: Overly Explicit Subjects

**AI-typical**: 我认为我们应该保护环境
**Natural**: 应该保护环境 (subject implied)

**Rule**: Chinese drops subjects more than English.

### Pattern 6: Literal Translations

**AI-typical**: 我对你表示感激
**Natural**: 我很感谢你

**Rule**: Don't translate "express gratitude" literally. Use 感谢.

### Rewrite Exercise

**AI-typical**:
> 这个问题的解决需要进行深入的研究，并且需要考虑到各种因素的影响。

**Natural**:
> 要解决这个问题，得深入研究，考虑各种因素。

## Measure Words (量词)

Every noun needs a measure word when counted.

### Common Measure Words

| Measure Word | Used For | Examples |
|--------------|----------|----------|
| 个 | Generic, people | 一个人, 一个苹果 |
| 只 | Animals, one of pair | 一只猫, 一只鞋 |
| 条 | Long thin things | 一条鱼, 一条路 |
| 张 | Flat things | 一张纸, 一张桌子 |
| 本 | Books | 一本书 |
| 件 | Matters, clothes | 一件事, 一件衣服 |
| 把 | Things with handles | 一把刀, 一把椅子 |
| 辆 | Vehicles | 一辆车 |
| 台 | Machines | 一台电脑 |
| 位 | People (respectful) | 一位老师 |
| 名 | People (formal) | 一名学生 |
| 口 | Family members, well | 一口人, 一口井 |
| 棵 | Trees | 一棵树 |
| 朵 | Flowers, clouds | 一朵花, 一朵云 |
| 片 | Slices, flat areas | 一片面包, 一片地 |
| 滴 | Drops | 一滴水 |
| 颗 | Small round things | 一颗心, 一颗糖 |
| 支 | Stick-like things | 一支笔, 一支队伍 |
| 双 | Pairs | 一双鞋, 一双筷子 |
| 对 | Pairs (abstract) | 一对夫妻, 一对矛盾 |

### Selection Rules

1. **Shape-based**: Long thin → 条, flat → 张/片, round → 颗/个
2. **Function-based**: Machines → 台, vehicles → 辆, books → 本
3. **Respect-based**: People → 个 (neutral), 位 (respectful), 名 (formal)
4. **Convention-based**: Some are just memorized (一朵花, 一棵树)

### Common Mistakes

**Wrong**: 一个书 (book needs 本)
**Right**: 一本书

**Wrong**: 一个老师 (neutral, but 位 is more respectful)
**Right**: 一位老师 (in formal context)

**Wrong**: 一个鱼 (fish needs 条)
**Right**: 一条鱼

---

## Key Principles

1. **的/地/得**: Noun → 的, Adverb → 地, Complement → 得
2. **了**: After verb = completed, End of sentence = change of state
3. **把/被**: 把 = active disposal, 被 = passive (often negative)
4. **是…的**: Emphasizes details of completed action
5. **Avoid Europeanised patterns**: Active voice, drop 进行, break up 的 chains
6. **Measure words**: Every noun needs one, learn by shape/function/convention
