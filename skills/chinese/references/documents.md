# Formal Document Templates

Skeletons for common formal documents in Chinese.

---

## 请假条 (Leave Request)

```
请假条

尊敬的[上级姓名/职位]：

因[原因]，需请假[天数]天，自[起始日期]至[结束日期]。
工作已交接给[同事姓名]，期间保持电话畅通。

恳请批准。

此致
敬礼

[姓名]
[日期]
```

---

## 辞职信 (Resignation Letter)

```
辞职信

尊敬的[上级姓名]：

经过慎重考虑，我决定辞去[职位]一职，最后工作日为[日期]。

感谢公司[年数]年来的培养和支持，这段经历对我非常宝贵。
我会配合完成工作交接。

祝公司未来发展顺利。

此致
敬礼

[姓名]
[日期]
```

## 简历 (Resume)

Structure:
- 基本信息 (name, contact)
- 求职意向 (target position)
- 教育背景 (education, reverse chronological)
- 工作经历 (work experience, reverse chronological)
- 项目经历 (projects, if relevant)
- 技能证书 (skills, certifications)
- 自我评价 (brief, 2-3 sentences max)

Rules:
- One page preferred, two pages maximum
- Use 动词 + 成果 format: "负责XX项目，实现XX%增长"
- Quantify achievements where possible
- 自我评价: avoid 吃苦耐劳/团队合作 clichés; be specific

## 邀请函 (Invitation)

```
邀请函

尊敬的[姓名/职位]：

[主办方]诚邀您出席[活动名称]。

时间：[日期] [时间]
地点：[地点]
活动简介：[1-2 sentences]

如蒙应允，请于[截止日期]前回复。

此致
敬礼

[主办方]
[日期]
```

## 感谢信 (Thank You Letter)

```
感谢信

尊敬的[姓名]：

感谢您在[事项]中的[具体帮助]。
[说明影响：这件事对我/项目的意义]。

[可选：提及后续合作或保持联系的意愿]。

再次感谢。

此致
敬礼

[姓名]
[日期]
```

---

## 合同条款 (Contract Clause)

Structure:
- 第X条 [条款标题]
- X.1 [具体内容]
- X.2 [具体内容]

Rules:
- Use 甲方/乙方 consistently
- Avoid ambiguity: 应当 (obligation) vs 可以 (permission)
- Specify deadlines with dates, not "尽快"
- Include consequences: "如违反，需承担XX责任"

## 公文 (Official Document)

### 请示 vs 报告

| | 请示 | 报告 |
|---|------|------|
| Purpose | 请求指示或批准 | 汇报工作、反映情况 |
| Response required | Yes | No |
| Timing | Before action | After or during action |
| Closing | 妥否，请批示 | 特此报告 |

### 请示 Template

```
关于[事项]的请示

[上级单位/领导]：

[背景说明，1-2 sentences]。
[请示事项，具体请求]。
[理由，为什么需要批准]。

妥否，请批示。

[单位名称]
[日期]
```

### 报告 Template

```
关于[事项]的报告

[上级单位/领导]：

[背景]。
[工作内容/情况]。
[结果/成效]。
[存在的问题或下一步计划]。

特此报告。

[单位名称]
[日期]
```

## 通知 (Notice)

```
关于[事项]的通知

各[部门/单位]：

[背景或目的]。
[具体内容，分条列出]。
[执行要求或时间节点]。

特此通知。

[发文单位]
[日期]
```

---

## Key Principles

1. **Purpose first**: State the reason before the request
2. **Be specific**: Dates, names, amounts — not "近期""一些"
3. **Match the form**: 请示 and 报告 are different documents
4. **Proper closing**: 此致敬礼 for letters, 妥否请批示 for 请示
5. **Concise**: Formal doesn't mean verbose
