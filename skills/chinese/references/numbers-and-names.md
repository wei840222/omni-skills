# 数字、日期、姓名、地址

## 数字分组：万/亿制

中文数字以 **万**（10⁴）和 **亿**（10⁸）为分组单位，与英文的 thousand/million/billion 不同。

| 阿拉伯数字 | 中文 | 换算 |
|-----------|------|------|
| 10,000 | 一万 | ÷10,000 |
| 100,000 | 十万 | ÷10,000 |
| 1,000,000 | 一百万 | ÷10,000 |
| 10,000,000 | 一千万 | ÷10,000 |
| 100,000,000 | 一亿 | ÷100,000,000 |
| 1,000,000,000 | 十亿 | ÷100,000,000 |

**规则**：
- 中文语境下，大数字优先用"万""亿"表达
- 例：`350,000,000` → `三亿五千万`（非"350 million"）
- 金额：`¥1,250,000` → `一百二十五万元`

## 两 vs 二

| 场景 | 用"两" | 用"二" |
|------|--------|--------|
| 量词前 | 两个人、两天 | ✗ |
| 数字序列 | ✗ | 第一、第二、二号 |
| 小数/分数 | ✗ | 零点二、三分之二 |
| 多位数中 | ✗ | 二十二、二百 |
| 传统度量衡 | 两斤、两亩 | ✗ |

**口诀**：量词前用"两"，序数/小数/多位数中用"二"。

## 日期格式

- **标准格式**：`2024年3月15日`（年月日全写）
- **简写**：`2024-03-15`（ISO 格式，正式文档推荐）
- **口语**：`三月十五号`（加"号"）
- **星期**：`星期一`（非"周一"，正式场合）
- **时间**：`下午3点` 或 `15:00`（24小时制更正式）

## 电话号码

- **手机号**：`138-1234-5678`（3-4-4分组）
- **固话**：`010-12345678`（区号-号码）
- **国际**：`+86 138 1234 5678`（国家代码+空格）

## 金额书写

- **小写**：`¥1,234.56`（千分位逗号，两位小数）
- **大写**（合同/支票）：`壹仟贰佰叁拾肆元伍角陆分`
- **口语**：`一千二百三十四块五毛六`

## 地址排序：从大到小

中文地址按 **行政层级从大到小** 排列：

```
中国北京市海淀区中关村大街1号
```

结构：国家 → 省/直辖市 → 市 → 区/县 → 街道/路 → 门牌号

**英文地址**则相反（从小到大）：
```
No.1 Zhongguancun Street, Haidian District, Beijing, China
```

## 姓名规范

- **姓在前，名在后**：`张伟`（张=姓，伟=名）
- **双字名**：`欧阳娜娜`（欧阳=复姓，娜娜=名）
- **正式场合**：全名（`张伟`）
- **非正式**：
  - 名字：`伟`（亲密）
  - 小名/昵称：`伟伟`（叠字，长辈对晚辈）
  - 老/小+姓：`老王`（年长）、`小李`（年轻）

## 称呼：姓+哥/姐

- **职场/社交**：`张哥`、`李姐`（表示尊重+亲切）
- **适用**：对方年长或资历深，关系较熟
- **不适用**：非常正式的场合（用"先生/女士"）

## 常见错误

1. `2个人` → 应为 `两个人`
2. `第2天` → 应为 `第二天`
3. 地址从小到大排列（英文习惯）→ 应从大到小
4. 金额 `1234元` 未加千分位 → `1,234元`
