# 标点符号规范

## 基本全角标点

| 标点 | 名称 | 用法 |
|------|------|------|
| ， | 逗号 | 句中停顿，分隔分句或并列成分 |
| 。 | 句号 | 陈述句末尾，语气平缓 |
| 、 | 顿号 | 并列词语之间，仅用于词/短语级 |
| ； | 分号 | 并列分句之间，层次高于逗号 |
| ： | 冒号 | 提示下文或总结上文 |
| ？ | 问号 | 疑问句末尾，包括反问 |
| ！ | 叹号 | 感叹句、祈使句末尾，语气强烈 |

## 省略号与破折号

- **省略号**：`……`（两个字符，六个点）。不可用 `...` 或 `…`（单字符）。占两格。
  - 例：他想了很久……终于开口。
- **破折号**：`——`（两个字符）。不可用 `-` 或 `—`。占两格。
  - 例：北京——中国的首都。
  - 用法：解释说明、话题转折、声音延长。

## 书名号与引号

- **书名号** `《》`：用于书名、报刊名、文件名、影视剧名。
  - 例：《红楼梦》《人民日报》
  - 嵌套时用单书名号 `〈〉`：《读〈史记〉有感》
- **引号**（大陆规范）：
  - 双引号 `""`：外层引用
  - 单引号 `''`：内层嵌套引用
  - 例：他说："我记得老师说过'学而不厌'。"
- **引号**（台湾/港澳规范）：
  - 直角引号 `「」`：外层引用
  - 双直角引号 `『』`：内层嵌套引用
  - 例：他說：「我记得老师说过『学而不厌』。」

## 汉外混排间距

- **汉字与英文/数字之间**：加半角空格（推荐）或不加（紧凑风格）。全文统一。
  - 推荐：`使用 Python 3.10 编写`
  - 紧凑：`使用Python 3.10编写`
- **汉字与标点之间**：不加空格。全角标点自带视觉间距。
  - 正确：`今天天气很好，我们去公园吧。`
  - 错误：`今天天气很好 ， 我们去公园吧 。`
- **英文与标点之间**：遵循英文排版规则（标点后加空格，前不加）。

## 常见错误

1. 半角逗号 `,` 代替全角 `，`
2. 三个点 `...` 代替省略号 `……`
3. 单破折号 `-` 代替双破折号 `——`
4. 引号方向错误：`"中文"` 应为 `"中文"`
5. 顿号用于句子级并列（应改用逗号或分号）
