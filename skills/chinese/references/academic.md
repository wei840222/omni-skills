# Academic Chinese Writing

Conventions for 论文, 摘要, and scholarly communication in Chinese.

---

## 论文 Structure

Standard structure for Chinese academic papers:

1. **标题** (Title)
   - Concise, specific, no more than 20 characters preferred
   - Avoid 研究/分析 unless necessary
   - Include key variables or scope

2. **摘要** (Abstract)
   - 200-300 characters
   - Structure: 目的 → 方法 → 结果 → 结论
   - No citations, no abbreviations undefined

3. **关键词** (Keywords)
   - 3-5 terms
   - Specific to general
   - Separated by semicolons

4. **正文** (Body)
   - 引言 (Introduction)
   - 文献综述 (Literature Review)
   - 研究方法 (Methodology)
   - 结果与分析 (Results and Analysis)
   - 讨论 (Discussion)
   - 结论 (Conclusion)

5. **参考文献** (References)
   - GB/T 7714 format

---

## 摘要 Writing Rules

### Length
- 200-300 characters (Chinese)
- 150-250 words (English version if required)

### Structure
```
[目的] 为了解决/探讨/研究[问题]，
[方法] 采用[方法/模型/数据]，
[结果] 结果表明/发现[主要发现]，
[结论] 因此/由此得出结论[核心结论]。
```

### Rules
- **本文 not 我**: Use 本文/本研究, not 我/我们 (unless co-authored reflection)
- No first person
- No citations
- No abbreviations unless defined
- Past tense for methods/results, present for conclusions

### Example

> 为探讨社交媒体对青少年心理健康的影响，本研究采用问卷调查法，对500名13-18岁青少年进行了实证研究。结果表明，每日使用社交媒体超过3小时的群体，焦虑和抑郁水平显著高于对照组。由此得出结论，过度使用社交媒体对青少年心理健康存在负面影响，建议家长和学校引导合理使用。

## 关键词 Conventions

- 3-5 terms
- Specific → general order
- Separated by semicolons (；)
- Avoid generic terms like 研究/分析

**Example:**
社交媒体；青少年；心理健康；焦虑；使用时长

## 术语 Handling

### First occurrence
- Chinese term (English original): 机器学习（machine learning）
- Or: 机器学习，即 machine learning

### Subsequent occurrences
- Use Chinese term consistently
- English in parentheses only if ambiguity exists

### Established translations
Use official or widely accepted translations:

| English | Chinese |
|---------|---------|
| machine learning | 机器学习 |
| deep learning | 深度学习 |
| neural network | 神经网络 |
| artificial intelligence | 人工智能 |
| big data | 大数据 |
| cloud computing | 云计算 |

### Untranslated terms
Keep in English when:
- No established Chinese translation
- The English term is standard in the field (API, HTTP, GPU)
- Translating would cause confusion

## GB/T 7714 Citation Format

### Journal article
```
[序号] 作者. 文章标题[J]. 期刊名, 年, 卷(期): 起止页码.
```

Example:
```
[1] 张三, 李四. 社交媒体对青少年心理健康的影响[J]. 心理学报, 2023, 55(3): 456-468.
```

### Book
```
[序号] 作者. 书名[M]. 出版地: 出版社, 年: 页码.
```

Example:
```
[2] 王五. 机器学习基础[M]. 北京: 科学出版社, 2022: 123-145.
```

### Conference paper
```
[序号] 作者. 论文标题[C]//会议名称. 会议地点: 出版者, 年: 页码.
```

### Online source
```
[序号] 作者. 标题[EB/OL]. (发布日期) [引用日期]. URL.
```

## Self-Reference: 本文 not 我

### Wrong
> 我们发现…
> 我认为…
> 我们的研究表明…

### Right
> 本研究发现…
> 本文认为…
> 本研究表明…

### Exception
In co-authored reflection or preface, 我们 is acceptable.

## Register and Tone

- **Objective**: Avoid 我觉得/我认为
- **Precise**: Use specific terms, not 东西/事情
- **Formal**: 书面语, not 口语
- **Concise**: Avoid filler words

### Common academic phrases

| Purpose | Phrase |
|---------|--------|
| Introduce topic | 本文探讨/研究… |
| State method | 采用…方法 |
| Present results | 结果表明/显示… |
| Draw conclusion | 由此得出结论… |
| Acknowledge limitation | 本研究存在以下局限… |
| Suggest future work | 未来研究可以… |

---

## Common Mistakes

1. **Using 我 instead of 本文/本研究**
2. **摘要 too long** (>300 characters)
3. **关键词 too generic** (研究, 分析, 探讨)
4. **Citation format inconsistent**
5. **Mixing 口语 and 书面语**
6. **Undefined abbreviations**
7. **Vague conclusions** (需要进一步研究 without specifics)
