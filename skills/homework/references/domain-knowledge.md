# Homework Tutoring — Domain Knowledge

Load this file when verifying teaching defaults, academic-integrity posture, or subject coaching claims against primary sources.

## Teaching over answering

- Scaffolding and the zone of proximal development remain the default posture for assignment help: give the smallest useful nudge, then expand only as needed.
  - Wood, Bruner & Ross (1976), "The role of tutoring in problem solving" — https://doi.org/10.1111/j.1469-7610.1976.tb00381.x
  - Vygotsky summary (ZPD) via Simply Psychology — https://www.simplypsychology.org/zone-of-proximal-development.html

- Retrieval and worked-example balance: for math/science, worked steps help early; later prefer student-generated steps with feedback on the error locus.
  - Sweller, Ayres & Kalyuga — Cognitive Load Theory overview — https://www.instructionaldesign.org/theories/cognitive-load/
  - Dunlosky et al., improving student learning with effective techniques — https://journals.sagepub.com/doi/10.1177/1529100612453266

## Academic integrity posture

- Prefer guidance that keeps the student authoring the final work (outlines, hints, critique) rather than producing a submission-ready artifact unprompted.
  - International Center for Academic Integrity — fundamental values — https://academicintegrity.org/resources/fundamental-values
  - Harvard Honor Code / academic integrity orientation (example institutional framing) — https://honor.fas.harvard.edu/academic-integrity

## Subject coaching anchors

- Writing: thesis/outline coaching before prose; revision comments target weakness rather than silent rewrite.
  - Purdue OWL — Writing process / thesis statements — https://owl.purdue.edu/owl/general_writing/the_writing_process/index.html
- Math word problems: translate language → quantities → equation before arithmetic.
  - NCTM problem-solving resources — https://www.nctm.org/Classroom-Resources/Problems/
- Science setup errors dominate calculation errors; name the model/formula choice first.
  - PhET interactive simulations (concept before plug-and-chug) — https://phet.colorado.edu/

## Safety notes

- Do not store LMS credentials or full identity documents in skill state.
- Match explanation level to the apparent learner; inflated polish can hide missing understanding.
