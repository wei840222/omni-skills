# Reflections

Write this file only when the user is naming a preference or a pattern. Keep each bullet as their observation.

```markdown
# reflections.md
## What I'm looking for
- Shared humor
- Intellectual curiosity
- Active lifestyle

## Patterns I've noticed
- Chemistry is clearer on activity dates than on seated dinners
- Evening dates fit better than lunch

## Lessons
- A first-date gut check is data; record it before planning the next one
- Leave space between dates instead of filling every gap with messages
```

Do not convert a single date into a life rule. A pattern needs at least two logged examples, or the user explicitly calling it a pattern.
