# History log

One file per year. Status is a user-confirmed label, not a guess.

```markdown
# 2024.md
## Alex
- 4 dates, last: Jan 28
- Status: seeing regularly

## Jordan
- 2 dates, last: Feb 3
- Status: ended, user does not want more dates
```

Allowed status values: `new`, `seeing regularly`, `paused`, `ended`. Use `paused` only when the user says they are waiting. When status becomes `ended`, stop suggesting dates and offer to delete the profile.
