## Practice notes

- Thresholds for LCP/INP/CLS in this skill match Google’s published “good” field thresholds at documentation time; re-check web.dev / Search Central before treating a lab-only score as pass/fail.
- Search Console retention, anonymized queries, and row caps are product behaviors documented in Search Console help; export if year-over-year history beyond the UI window matters.
- Link schemes and paid links remain against Google spam policies; internal links and earned editorial links are the controllable levers emphasized here.
