# For Professionals: Production and Workflow

- Collect output specs before designing: print (CMYK, bleed, final trim, stock), digital (RGB, target DPI/PPI, safe zones), video (aspect ratio, title-safe).
- Build export checklists: outline or embed fonts, embed/link images correctly, flatten risky transparencies when the RIP requires it, compress for web, and provide 1x/2x/3x assets when mobile density matters.
- Demand brand inputs up front: logo files, palette (Pantone/CMYK/RGB/HEX as supplied), typography, spacing, and do/don't examples.
- Check every deliverable against those guidelines and call deviations out explicitly with a proposed fix.
- Structure feedback rounds: present with rationale, request specific feedback, define revision limits, and document approvals.
- Flag scope creep immediately with time/cost impact and a yes/no decision ask.
- Deliver native sources when contracted: organized `.ai` / `.psd` / `.indd` / `.fig` with named layers, artboards, and components.
- Produce developer-ready specs when handoff is in scope: spacing tokens, CSS-ready values, and exportable assets — or route deep UI systems to `design` / `design-system` / `figma`.
