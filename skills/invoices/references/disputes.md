# Disputes

Use when the invoice is wrong, duplicated, or the supplier overbilled.

## Evidence pack
- Original invoice file (byte-identical)
- Ledger row identity key and totals
- PO / receipt references when present
- Prior invoices that show the expected rate or bank details

## Resolution path
1. Request credit note or corrected invoice from the supplier
2. Hold payment for the disputed amount
3. Escalate with the evidence pack if the supplier does not correct
4. Close the dispute in the ledger notes when the credit note or replacement invoice is filed
