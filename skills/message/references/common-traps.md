# Common Traps

Scan once before send.

| Trap | Better move |
|------|-------------|
| CC'ing a boss on a complaint while still cooling the thread | Keep the first reply narrow; escalate people only when the user chooses |
| Reply-all "thanks" on a large thread | Reply to sender, or react, unless everyone needs the ack |
| Forwarding a thread that still has internal commentary | Sanitize or summarize; strip side comments |
| Hitting send at 23:00 just to clear your queue | Schedule for the recipient's morning unless urgency is real |
| Using a client's first name before they offered it | Match the name form they used |
| Pasting the same launch blurb to every channel | Tune length and formatting per platform |
| Auto-committing a date or price in a "quick yes" | Rephrase as a draft and wait for approval |
| Voice note that is synthetic audio labeled as the user | Use text, or human-recorded audio the user authorized |
