# Korean language sources

Use these pages to check a speech-level label, honorific mapping, or contested terminology. They describe usage; they are not a license to invent slang or intimacy the user did not ask for.

## Language overview and speech levels

- **Wikipedia — Korean language** — overview of Korean as a language, orthography, and modern written/spoken norms. https://en.wikipedia.org/wiki/Korean_language
- **Wikipedia — Korean speech levels** — documents 합쇼체, 해요체, 해체/반말 and related honorific speech-level contrasts used in writing and conversation. https://en.wikipedia.org/wiki/Korean_speech_levels
- **Wikipedia — Korean honorifics** — honorific vocabulary and addressee/referent politeness patterns that interact with speech level. https://en.wikipedia.org/wiki/Korean_honorifics

## Lexicon samples used in style guidance

- **Wiktionary — 해요체** — polite speech-level label commonly used as a safe written default. https://en.wiktionary.org/wiki/해요체
- **Wiktionary — 반말** — familiar/banmal speech style used among peers or intimate relationships. https://en.wiktionary.org/wiki/반말

- Load `japanese`, `chinese`, or `traditional-chinese` when the target language is not Korean.
- Load `translate` for multi-pair catalogs, ICU/XLIFF workflows, or non-Korean-first localization jobs.

## Access note

These sources are descriptive secondary references. Native-speaker frequency claims, dialect prescriptions, and crude slang boundaries need a supplied speaker sample or additional relevant evidence. When that evidence is unavailable, use broadly understandable 해요체 and name the uncertainty when it materially affects the draft.
