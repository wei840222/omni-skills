## How to update

1. Read existing pattern files before editing.
2. Add a dated bullet when a new entry clearly features the element.
3. On review requests, rank by frequency in the requested window (week / month / all available).
4. Phrase surfaces as observations: “Flying is the most logged symbol this month (n=4), twice with landing anxiety.”
5. If files are missing, create the skeleton only when the user wants tracking; otherwise answer from recent journal files directly.
6. Never copy third-party dream dictionaries as authoritative meanings; optional cultural notes stay labeled as speculation.
