# Official Sources & Architecture References

This document records the primary official documentation, model repositories, and API references for the Qwen model family.

## Official Repositories & Model Hubs

- **Qwen Official GitHub**: [https://github.com/QwenLM/Qwen2.5](https://github.com/QwenLM/Qwen2.5)
  - Architectural details, tokenizer configurations, context window lengths (up to 128k tokens), and inference guides for Qwen2.5 (0.5B to 72B), Qwen2.5-Coder, and Qwen2.5-Math.
- **Qwen on Hugging Face**: [https://huggingface.co/Qwen](https://huggingface.co/Qwen)
  - Official model cards, weights, GGUF/AWQ quantizations, and chat template specifications.

## Hosted APIs & Deployment Platforms

- **Alibaba Cloud Model Studio (DashScope)**:
  - Developer Reference: [https://www.alibabacloud.com/help/en/model-studio/developer-reference/what-is-model-studio](https://www.alibabacloud.com/help/en/model-studio/developer-reference/what-is-model-studio)
  - API protocols: OpenAI-compatible endpoints (`/compatible-mode/v1`) and native DashScope SDK interfaces.
- **Local Runtime Serving**:
  - vLLM serving documentation: [https://docs.vllm.ai/en/latest/](https://docs.vllm.ai/en/latest/)
  - Ollama model library: [https://ollama.com/library/qwen2.5](https://ollama.com/library/qwen2.5)
