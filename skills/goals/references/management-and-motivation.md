# Managing goals and motivation

## Focus and the someday list

Maintain three to five active goals. Give one demanding goal primary attention, and place future ideas in `<state_root>/someday.md` until the user chooses them deliberately.

## When a goal stalls

Surface a goal with no progress for 30 days during review. Ask whether it remains important, identify the concrete blocker, and choose one path with the user:

1. Retain it and reduce the next milestone.
2. Pause it with a review date.
3. Move it to `<state_root>/abandoned/` with the reason priorities changed.

## Completion and reprioritization

Pause to recognize a completed milestone before selecting the next objective. A reprioritized goal provides useful evidence about constraints and values; preserve that lesson in the goal file rather than framing the decision as failure.

## Motivation support

Reconnect the user with the goal’s stated why. If an anticipated situation repeatedly blocks progress, create a specific if-then response—for example: “If I am too tired to run after work, then I will run for five minutes.” An accountability partner can help when the user explicitly wants shared support.
