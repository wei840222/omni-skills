# Research sources (Gate 6)

Full URLs used while verifying stable-domain management guidance. Prefer these over model memory for attributions and framework definitions.

## Strategy and org frameworks

- **Porter — How Competitive Forces Shape Strategy (HBR)** — Five Forces framing for industry analysis — https://hbr.org/1979/03/how-competitive-forces-shape-strategy
- **McKinsey — Enduring Ideas: The 7-S Framework** — internal alignment model (strategy, structure, systems, shared values, skills, style, staff) — https://www.mckinsey.com/capabilities/strategy-and-corporate-finance/our-insights/enduring-ideas-the-7-s-framework
- **Kotter — The 8-Step Process for Leading Change** — sequenced large-scale change — https://www.kotterinc.com/methodology/8-steps/
- **Prosci — ADKAR Model** — individual change outcomes (Awareness, Desire, Knowledge, Ability, Reinforcement) — https://www.prosci.com/methodology/adkar
- **Mind Tools summary of Bridges' Transition Model** — endings / neutral zone / new beginnings (secondary explainer; pair with primary book when quoting Bridges directly) — https://www.mindtools.com/a8b55k5/bridges-transition-model

## Classic management thinkers
