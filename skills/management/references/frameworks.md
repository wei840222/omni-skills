# Frameworks and classic sources

Pick one primary frame that matches the decision. Explain fit, then adapt with the missing-data caveats the user still owes you.

## Strategy and external analysis

| Need | Framework | Use carefully for |
|---|---|---|
| Industry structure / profit pool | Porter's Five Forces | Rivalry, entry, substitutes, buyer/supplier power—not a full internal plan |
| Broad external scan | PESTEL | Political, economic, social, tech, environmental, legal drivers |
| Portfolio mix | BCG matrix | Relative share × growth; crude without real share/growth data |
| Competitive position narrative | SWOT | Strengths/weaknesses (internal) × opportunities/threats (external); weak if generic |

## Internal alignment and change

| Need | Framework | Use carefully for |
|---|---|---|
| Org alignment check | McKinsey 7S | Strategy, structure, systems, shared values, skills, style, staff—spot misfit clusters |
| Large change sequence | Kotter 8 steps | Urgency → coalition → vision → communicate → empower → wins → consolidate → anchor |
| Individual change adoption | ADKAR | Awareness, Desire, Knowledge, Ability, Reinforcement—diagnose which letter is stuck |
| Transition psychology | Bridges | Ending → neutral zone → new beginning; useful when "resistance" is grief/identity |

## How to apply in answers

1. **State the question** the framework is answering (not "do a SWOT because MBA").
2. **Fill only cells with evidence** from the prompt or cited sources; mark blanks explicitly.
3. **Derive 1–3 recommendations** with owner, timeline, and resource implication.
4. **Name failure modes**: cargo-cult frameworks, universal prescriptions, skipping legal/HR when people decisions are involved.

## Attribution anchors (stable-domain)

- Drucker: management by objectives / effectiveness focus — treat as classic orientation, not a compliance checklist.
- Mintzberg: strategy as craft and emergent patterns — use when pure deliberate planning is the user's blind spot.
- Kotter: leading change sequence — use for multi-stakeholder transformations with visible urgency gaps.

Primary URLs for verification live in `sources.md`. Do not invent numeric benchmarks, statutory deadlines, or jurisdiction-specific employment rules from memory.
