# Capture — Input → Testable Items

Load when material was consumed but cannot be reproduced.

## Rule

Input without retrieval is not learning. After any reading/watching block, convert durable facts and procedures into atomic items **before** the session ends.

## Item shape

- One retrievable fact or decision per item
- Prompt that works cold (no options unless recognition is the intentional level)
- Answer short enough to grade in seconds
- Tag the misconception or source if relevant

## Working-memory cap

Introduce at most 3–4 new items, then run a retrieval interrupt before more encoding. Working memory holds roughly four chunks; a fifth new concept before retrieval silently evicts earlier ones (Cowan; see `research-sources.md`).

## From tutorials

While following a tutorial, keep a gap log: every "I copied this and don't know why" becomes a queue item that night. That bridges project-first motivation with fundamentals coverage.
