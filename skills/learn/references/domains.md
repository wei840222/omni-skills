# Domains — Same Loop, Different Ratios

Load when the subject type changes the drills.

| Domain | Emphasize | Common failure |
|--------|-----------|----------------|
| Language | Production under time; graded input until ~90% known | Recognition-only reading |
| Code | Blank-file projects; tests as feedback | Tutorial copy without ownership |
| Music | Daily production; slow accurate reps | Theory without playing |
| Math | Unprompted method choice; interleaved problem types | Only worked examples |
| Facts-heavy | Atomic cards + spaced queue | Paragraph answers |
| Physical skill | Short frequent motor reps; video feedback | Marathon low-quality sessions |

Immersion (language and analogues) works when input is mostly comprehensible; below that it is noisy effort. Use graded material until the threshold, then immerse.
