# Plateaus — Stalls, Motivation, Relearning

Load when progress flattens, motivation collapses, or someone returns after a lapse.

## Three-question split

1. Is practice still near the ~85% band on the *hard* sub-skills?
2. Is feedback still inside the latency budget?
3. Is the exit test still the right target?

| Diagnosis | Fix |
|-----------|-----|
| Wrong practice (too easy / no transfer) | Raise difficulty; add unprompted whole tasks |
| True plateau near ceiling | Change drill variety; seek outside feedback |
| Burnout | Cut volume; keep retrieval + tiny production; protect sleep |

## Relearning

Do not restart the beginner course by default. Cold-test first; rebuild only what failed. Relearning is usually faster than first learning—spending that savings on already-known material is waste.
