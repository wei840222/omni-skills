# Projects — Build to Learn

Load for tutorial hell, blank-file freeze, or project-vs-fundamentals debates.

## Scaffolding ladder

1. **Copy** — reproduce a working example
2. **Modify** — change requirements while the scaffold remains
3. **Blank file** — same class of problem with no starter

Put dates on each rung. Leaving someone on Copy indefinitely produces recognition without capability.

## Gap log

Project-first wins motivation and transfer, and hides holes. Every unexplained copy becomes a capture item that night (`capture.md`).

## Shared box

Durable build-to-learn projects may be referenced in the projects shared box by name only; formats live in `assets/memory-template.md`.
