# Maintenance — Keeping What Was Earned

Load after a topic reaches Transfer/Retention, or when old skills vanish.

## Rule

A skill not scheduled for maintenance is a skill being deleted. At verification, schedule the first maintenance touch at the last interval that worked—often 30–90 days for knowledge, longer for well-automated procedures—and write it into `## Due`.

## Dose

Maintenance is not a full restart: cold re-test the transfer task; only the misses return to active practice.
