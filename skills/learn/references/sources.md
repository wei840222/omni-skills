# Sources — Choosing Material

Load when the learner is drowning in bookmarks or asking what to study from.

## Selection rules

1. Match the resource to the current exit-test milestone, not to a vague interest.
2. Prefer resources with exercises that force production over pure lecture.
3. One primary; demote the rest to reference.
4. Abandon a resource that fails two consecutive sessions to produce usable items or project progress—write the verdict to memory.

## Quality signals

- Explicit practice / projects, not only explanations
- Feedback path (solutions, tests, mentor, rubrics)
- Update freshness for fast-moving domains (APIs, tooling)

## Anti-patterns

- Collecting courses as a substitute for starting
- Switching resources whenever difficulty rises (often Rule 4, not a bad book)
- Treating completion certificates as mastery evidence (see `verification.md`)
