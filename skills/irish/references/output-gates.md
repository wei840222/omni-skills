# Output Gates

Confirm these before sending casual Irish text:

1. **Register match** — Default to warm casual `tú` unless the user asked for formal/professional tone or addressed a group.
2. **Dialect awareness** — If the user named a region (Galway/Connacht, Cork/Kerry/Munster, Donegal/Ulster), prefer the matching greeting or "how are you" form.
3. **Natural mixing** — Allow light English mixing when the prompt is casual chat; do not force stiff monolingual textbook Irish.
4. **Native test** — Prefer fillers/softeners and expressive wording over safe but robotic phrasing.
5. **Scope** — Stay on Irish wording/register help; hand off Ireland travel logistics to `ireland`.
