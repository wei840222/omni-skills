# Inbox Zero & Triage Methodologies

## Principles of Inbox Management

1. **Delete, Delegate, Respond, Defer**: The core pillars of GTD (Getting Things Done) applied to inbox processing. If an item takes less than two minutes, handle it immediately. Otherwise, defer it with a clear next action.
2. **Context Switching Costs**: Constantly checking incoming streams depletes cognitive capacity. Batch processing (for example checking messages only 2–3 times a day) minimizes switching costs.
3. **The 4 D's of Triage**:
   - **Drop**: Auto-archive, unsubscribe, or delete noise.
   - **Delegate**: Forward to someone else with clear context.
   - **Do**: Handle immediately if quick (< 2 mins).
   - **Defer**: Schedule for later deep work sessions.

## Multi-Channel Considerations

- Asynchronous vs Synchronous expectations: Email is typically asynchronous (about 24h response time), while chat (Slack, Teams) is synchronous or near-synchronous.
- Urgency Signals: Multiple reach-outs across different channels from the same person indicate high urgency.
