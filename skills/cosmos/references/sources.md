# Research Sources — Cosmos & IBC Ecosystem

Primary technical documentation and specifications for Cosmos Hub, Inter-Blockchain Communication (IBC), and Cosmos SDK chains.

## Protocol Documentation

- **Cosmos Hub Documentation** — https://docs.cosmos.network/
  - Hub architecture, ATOM tokenomics, 21-day unbonding period, validator staking parameters, and on-chain governance.
- **IBC Protocol Specification** — https://ibcprotocol.dev/
  - Core IBC architecture, packet lifecycle, channel states, sequence ordering, and client verification.
- **Interchain Developer Academy** — https://academy.interchain.io/
  - Cosmos SDK modules (auth, bank, staking, slashing, gov, ibc-transfer).

## Tooling & Explorers

- **Mintscan Explorer** — https://www.mintscan.io/
  - Validating IBC packet status, relayer activity, validator performance, and sequence tracking.
- **Keplr Developer Documentation** — https://docs.keplr.app/
  - Multi-chain wallet connection, transaction signing, and fee estimation.
