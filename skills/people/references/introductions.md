# Introductions

## Double opt-in

1. Ask party A privately whether an intro to B is welcome.
2. Ask party B privately with a forwardable blurb.
3. Only then connect both; track until first reply lands.
4. Write an open-loop line with both names and dates.

## Forwardable blurb

- Who + one-line context
- Why this intro helps both
- No confidential third-party detail
- No credential or private contact data beyond what each party already shared for the intro
