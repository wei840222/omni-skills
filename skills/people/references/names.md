# Names

## Store as data

- Spelling as the person writes it
- Preferred form (nickname vs legal)
- Pronunciation note when useful (`"Siobhan" ~ shi-VAWN`)
- Name order per `name_order` config: `as-given`, `given-first`, `family-first`

## Rules

- Say the name back at introduction when unsure; do not guess in durable notes.
- Disambiguators belong in `Key` (`jane-chen-acme`), never `jane-chen-2`.
- A rename updates the display name and file pointer; `Key` changes only when the identity token itself changes (new email), with merge rules in `hygiene.md`.
