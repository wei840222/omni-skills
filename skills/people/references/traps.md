# Traps

| Trap | Why it fails | Do instead |
|---|---|---|
| Logging everything said | Transcript buries the useful line | Thirty-second filter (`details.md`) |
| Birthday without year | Milestones and ages become guesswork | Store `YYYY-MM-DD` or `--MM-DD` (`dates.md`) |
| "Just checking in" | Nothing to reply to | Lead with remembered specific (`keeping-in-touch.md`) |
| Reconnect + ask together | Reads as extraction | Reconnect first (`network.md`) |
| Bulk-import promote | 900 nameless rows kill the box | Candidates only (`hygiene.md`) |
| Merge on name | Strangers share names | Match `Key` (`hygiene.md`) |
| Auto-send birthday texts | Fires for the dead / estranged | Surface + user sends (Rule 7) |
| Third-party diagnosis/salary | No consent; files travel | Topic marker only (`privacy.md`) |
| Judgment words | "Flaky" ages badly | Behaviors with dates (Rule 8) |
| Address book as CRM | People become leads | Commercial work → `crm` |
| Delete on drift | Context vanishes when they return | Move to `dormant` |
| Favor scoreboard | Kills reciprocity | Open loops only (`network.md`) |
| Brief leads with title/city | Least useful pre-call | Lead with what changed (`briefing.md`) |
