# Life events

Draft only. User sends.

| Event | Timing | Register |
|---|---|---|
| Birthday | On the day | Specific reference, short |
| New job / promotion | Within 2 days | Name leave + join |
| Birth of child | ~2 weeks after | Warm, no advice pile-on |
| Bereavement | 48h, then 4–6 weeks | Presence; second message matters |
| Death anniversary | On day if marked before | One line is enough |
| Illness | On their terms | Concrete offers |
| Layoff / failure | Within a week | No advice early |
| Move | Day of + day 30 | Practical + social |

Follow-ups nobody sends are often more valuable than the first note.
