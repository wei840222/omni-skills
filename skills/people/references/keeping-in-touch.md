# Keeping in touch

## Overdue sweep

1. Read contacts + person files + `do-not-surface.md`.
2. For each non-suppressed person with tier `inner`/`regular`, compute silence length.
3. Flag when silence exceeds tier cadence or per-person `cadence`.
4. Report once per config `nudge_style` rules.

## Reconnection draft pattern

1. Name the gap in one short clause.
2. Lead with one remembered specific thing.
3. Ask for nothing in the first message.
4. Offer an easy optional reply path.

Favor-attached reconnection after long silence is a trap (`traps.md`).
