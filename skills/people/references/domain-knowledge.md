# Domain knowledge — personal address books

## Design stance

Personal relationship tooling works when it stores **context that changes the next conversation**, not when it mimics sales CRM pipelines. Cadence tracking helps prevent drift; automated outreach and metric-scoring friendships usually backfire.

## Practical defaults retained by this skill

- Shared contacts box readable by other skills
- Identity key on each row
- Last-contact arithmetic for overdue sweeps
- Suppression before nudges
- Draft-only messaging
