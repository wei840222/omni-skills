# Capture — first contact

Within 24 hours of meeting someone worth keeping, write five fields:

1. **Name as they say it** (spelling confirmed once if uncertain)
2. **Where** you met
3. **Who introduced** (or "none")
4. **One specific thing** that would change the next conversation
5. **Next step** if any (open loop with date)

## Procedure

1. Resolve contacts root; read `contacts.md` and match on `Key` before append.
2. Create or update the row: `Name | Key | Role | Preferred channel | Context | Last contact | File`.
3. If detail exceeds one row, create `<contacts_root>/<name>.md` and set `File`.
4. Set `Last contact` to today; tier defaults to `orbit` until a second real interaction.
5. Log the interaction line per `interactions.md`.

Do not interview the user for a complete biography. Empty fields stay empty.
