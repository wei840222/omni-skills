# Where experts disagree

- **Structure vs freeform.** Structured fields make queries work; pure prose keeps humanity and fails at scale. Frontier: structure identity, tier, dates, last contact; leave the rest prose.
- **Proactive nudging vs on-demand.** Tools push scheduled outreach; others say prompted friendship is hollow. Default here is `on-ask` because a wrong nudge is expensive.
- **Tiering at all.** Some refuse ranks. Untiered rosters still need per-person `cadence` or they nag everyone equally.
- **Secondhand facts.** Record with source + date, or omit. Unattributed rumor equals false first-person memory later.
