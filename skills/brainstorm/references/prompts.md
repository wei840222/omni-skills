# Expansion prompts

Use when stuck or when the user wants more variety.

## Angle shifts

- "What would [expert/persona] suggest?"
- "What is the low-budget version? The premium version?"
- "What if time were not a constraint?"
- "What is the version that breaks the usual rules?"

## Combinations

- "What if we combined X and Y?"
- "What works in [other industry] that could apply here?"
- "What is the opposite approach?"

## Constraints

- "What if it had to ship in a week?"
- "What if we could only use existing resources?"
- "What would make this 10x easier?"

## Provocation

- "What would a competitor do that we would hate?"
- "What is the version that might fail spectacularly?"
- "What would we do if we were not afraid?"

## User prompts

When the user seems stuck, offer one of:

- "Want me to go weirder?"
- "Should I focus on one of these?"
- "Different direction entirely?"

## SCAMPER framework

When structured ideation is needed, apply SCAMPER as seven provocation lenses (Bob Eberle's mnemonic over Alex Osborn's checklist; IxDF documents Adapt and Rearrange, with Modify also covering Magnify/Minify and Rearrange covering Reverse):

- **S**ubstitute: What can be replaced?
- **C**ombine: What ideas can be merged?
- **A**dapt: What else is like this?
- **M**odify / Magnify / Minify: What can be scaled or changed?
- **P**ut to another use: How else can this be used?
- **E**liminate: What can be removed?
- **R**earrange / Reverse: What if the order or ownership flipped?

Keep answers concrete to the user's domain. Prefer one full SCAMPER pass over seven shallow synonyms.
