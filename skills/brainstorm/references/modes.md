# Brainstorm modes

Detect from context, or let the user request a mode explicitly.

## Rapid Fire

Quick ideas, pure ideation. For naming, early exploration, unblocking.

```text
List ideas. Omit explanations. Go wide.
```

## Structured

Organized output with categories. For complex decisions and comparisons.

```text
Group by [theme]. Include trade-offs.
```

## Deep Dive

Fewer ideas, more development. For refining a direction.

```text
Take [idea] and explore variations, implications, and next steps.
```

## Provocative

Challenge assumptions and take unconventional angles. For breaking out of ruts.

```text
What if the opposite were true? What would a competitor do? What is the version that scares you?
```

## Collaborative

Build together in back-and-forth turns. For thinking out loud with the user.

```text
Respond to each idea. Ask "what about...?" Iterate together.
```
