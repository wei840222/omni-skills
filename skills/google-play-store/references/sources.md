# Official Sources & Technical Specifications

This document records the official Google Play Console documentation, testing policies, and publishing specifications.

## Official Google Play Policies & Requirements

- **Google Play Developer Policy Center**: [https://play.google/developer-content-policy/](https://play.google/developer-content-policy/)
  - Core content standards, spam prevention, user data privacy, and intellectual property compliance.
- **Testing Requirements for Personal Developer Accounts**: [https://support.google.com/googleplay/android-developer/answer/14151465](https://support.google.com/googleplay/android-developer/answer/14151465)
  - Mandatory policy for personal developer accounts created after November 13, 2023: must run a closed test with at least 12 opted-in testers for 14 continuous days before requesting production access.
- **Google Play Data Safety Section**: [https://support.google.com/googleplay/android-developer/answer/10787469](https://support.google.com/googleplay/android-developer/answer/10787469)
  - Disclosure requirements for user data collection, data sharing with third parties, encryption in transit, and account deletion request mechanisms.
- **Android Target API Level Requirements**: [https://developer.android.com/google/play/requirements/target-sdk](https://developer.android.com/google/play/requirements/target-sdk)
  - Target API level cadence: starting August 31, 2026, standard new apps and updates must target Android 16 (API level 36); Wear OS and Automotive target API 35; Android TV and XR target API 34.
- **Release Tracks & Testing Setup**: [https://support.google.com/googleplay/android-developer/answer/9845334](https://support.google.com/googleplay/android-developer/answer/9845334)
  - Configuration of internal testing, closed testing, and open testing tracks before promoting to production.
