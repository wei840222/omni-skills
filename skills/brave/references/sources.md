# Official Sources & Technical Specifications

This document records the official documentation, privacy architecture, and developer references for the Brave Browser.

## Official Brave Documentation & Architecture

- **Brave Shields Architecture**: [https://brave.com/shields/](https://brave.com/shields/)
  - Native tracker blocking, fingerprinting randomization (farbling), cookie partitioning, and script execution controls.
- **Brave Browser Privacy Protections**: [https://brave.com/privacy/browser/](https://brave.com/privacy/browser/)
  - Telemetry isolation, debouncing, bounce tracking mitigation, and network-level privacy guarantees.
- **Brave Browser Source Repository**: [https://github.com/brave/brave-browser](https://github.com/brave/brave-browser)
  - Chromium upstream tracking, desktop build flags, release channels, and issue management.
- **Brave Adblock Engine (Rust)**: [https://github.com/brave/adblock-rust](https://github.com/brave/adblock-rust)
  - Native Rust implementation of Brave's ad-blocking engine matching EasyList and cosmetic filter syntax at line speed.
