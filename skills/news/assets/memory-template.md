# Memory Template

Create this layout under the resolved `<state_root>/` on first durable write (after brief consent):

```text
<state_root>/
├── memory.md       # Profile: interests, mix, format, timing
├── history.md      # Past briefings and engagement
└── sources.md      # Trusted sources and known leanings (optional)
```

## memory.md starter

```markdown
# News profile

- Interests: <!-- specific topics, not generic buckets -->
- Mix: <!-- e.g. 70% AI / 30% markets; optional -->
- Format: <!-- bullets | narrative | headlines-only -->
- Timing: <!-- morning | evening | weekly | on-demand -->
- Avoid: <!-- optional blocked topics -->
- Notes: <!-- locale, language, depth -->
```

## history.md starter

```markdown
# Briefing history

<!-- Append date, topics delivered, engagement (expanded/skipped), corrections -->
```

## sources.md starter

```markdown
# Trusted sources

<!-- name | URL or outlet | notes on leanings / beat -->
```
