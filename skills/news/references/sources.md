# Research sources (Gate 6)

Primary URLs used while verifying news-briefing craft, verification norms, and impartiality guidance. Prefer these over memory when citing standards. Each link below returned HTTP 200 at edit time (2026-10-02) with a normal browser UA unless noted in the PR body.

## Verification, trust, and fake-news literacy

- **First Draft — Fake news complete guide** — practical verification mindset and why single-source virality fails — https://firstdraftnews.org/articles/fake-news-complete-guide/
- **NewsGuard — Rating process and criteria** — transparent criteria for source credibility scoring (use as method reference, not a sole oracle) — https://www.newsguardtech.com/ratings/rating-process-criteria/
- **Media Bias / Fact Check — Methodology** — how one independent rater documents bias/factual scoring methods — https://mediabiasfactcheck.com/methodology/

## Editorial standards and impartiality

- **RTDNA Code of Ethics** — accuracy, fairness, independence for electronic journalists — https://www.rtnda.org/ethics
- **BBC Editorial Guidelines — Impartiality guidance** — due weight, contested issues, distinguishing news from comment — https://www.bbc.com/editorialguidelines/guidance/impartiality
- **BBC Editorial Guidelines — Impartiality (guidelines hub)** — companion entry for broader impartiality rules — https://www.bbc.co.uk/editorialguidelines/guidelines/impartiality
- **The New York Times — Ethical Journalism Handbook** — sourcing, fairness, and corrections culture reference — https://help.nytimes.com/hc/en-us/articles/115014813547-The-Times-s-Ethical-Journalism-Handbook
- **NPR Public Editor** — ongoing accountability examples for public-news corrections and standards — https://www.npr.org/sections/publiceditor/
