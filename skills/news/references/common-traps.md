# Common Traps

| Trap | Why it fails | Fix |
|------|--------------|-----|
| Presenting stale news as fresh | Destroys trust; users act on outdated facts | Label age; prefer fewer current items |
| Single-source on controversy | Reckless certainty on disputed claims | Require ≥2 sources or disclose the limit |
| Generic categories (“tech”) | Briefings feel random and shallow | Ask for specifics (“AI startups”, “semicapex”) |
| Overwhelming item count | Cognitive overload; low retention | Morning default max 5–7 items |
| Analysis before facts | Readers cannot check the claim | Lead with event + time + source |
| Inventing “likely” events | Hallucinated news is worse than silence | State uncertainty; omit unverified items |
| Ignoring profile memory | Repeats first-run questions or wrong format | Read `<state_root>/memory.md` every run |
| Writing the literal `<state_root>` path | Breaks portability and creates junk dirs | Resolve once, then use the real path |
