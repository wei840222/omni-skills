# Sources

Use these primary sources when a chemistry answer depends on safety policy, naming, or what counts as current instructional guidance. Do not invent a DOI, exposure limit, statute, or computational benchmark.

| Need | Source | URL |
|---|---|---|
| Instructional chemical safety policy | ACS Safety Guidelines | https://www.acs.org/education/policies/safety.html |
| Laboratory safety publications | ACS Committee on Chemical Safety | https://www.acs.org/about/governance/committees/chemical-safety/publications-resources.html |
| Chemical naming authority | IUPAC Nomenclature | https://iupac.org/what-we-do/nomenclature/ |
| Context-first chemistry teaching | ACS Chemistry in Context | https://www.acs.org/education/resources/undergraduate/chemistryincontext.html |

## How to use

- Safety before a procedure: follow the ACS safety guidelines. State PPE, ventilation, and what not to mix before steps.
- Naming: prefer IUPAC names. Keep a common name only when the literature the user is reading uses it, and say which name is which.
- Teaching: start from a concrete observation, then add the equation or mechanism. Mark a simplification as a simplification.
- Literature: cite a primary paper by DOI or journal, year, and page. Do not cite a review as if it were the original measurement.
- Regulatory or exposure limits: do not quote a number from memory. Point the user to the current official schedule or exposure table and say the value was not verified in this turn.
