# Quiz design sources (Gate 6)

Verified on 2026-10-01. Prefer these URLs when citing item-writing, progress UX, or touch-target guidance. Do not invent cut-scores or vendor claims without a live check.

## Item writing and multiple choice

- **Vanderbilt CFT — Writing Good Multiple Choice Test Questions** — stem clarity, one best answer, plausible distractors, avoid all/none-of-the-above traps — https://cft.vanderbilt.edu/guides-sub-pages/writing-good-multiple-choice-test-questions/ (HTTP 200)
- **Agent Skills specification** — skill package layout and progressive disclosure constraints for this repo — https://agentskills.io/specification (HTTP 200)

## Progress and completion UX

- **Baymard Institute — Progress Indicators** — when progress UI reduces uncertainty and abandonment on multi-step flows — https://baymard.com/blog/progress-indicators (HTTP 200)

## Accessibility / touch targets

- **W3C WCAG 2.2 — Target Size (Minimum)** — minimum interactive target guidance for quiz option controls — https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html (HTTP 200)

## How to use in this skill

- Cite the Vanderbilt guide when defending distractor quality or positive stem framing.
- Cite Baymard when arguing for visible question count / progress bars on longer quizzes.
- Cite WCAG target-size when reviewing mobile option hit areas.
- Mark any platform-specific pricing, API limits, or LMS feature claims as unverified until checked on the vendor’s current docs.
