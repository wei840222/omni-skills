# Code Memory Setup

## Initial setup

After resolving `<state_root>` per `SKILL.md` State location:

```bash
mkdir -p "<resolved_state_root>"
cp skills/code/assets/data-templates.md "<resolved_state_root>/memory.md"
# or seed an empty file and paste the template sections
```

Replace `<resolved_state_root>` with the concrete path chosen for this
invocation (for example `/path/to/workspace/code`). Never create a directory
literally named `<state_root>`.
