# Official Sources Map - Banking

Primary references used to ground payment-control, fraud-containment, and consumer-protection guidance. Prefer full URLs in PR notes and user-facing citations. Always re-check the user's jurisdiction before treating a rule as mandatory.

## Agent Skills / package format

- **Agent Skills specification** — frontmatter, resources, progressive disclosure via https://agentskills.io/specification
- **Agent Skills document index** — via https://agentskills.io/llms.txt

## Payments and settlement (US-oriented operational framing)

- **Federal Reserve — Fedwire Funds Service** — same-day finality and operational overview via https://www.frbservices.org/financial-services/wires
- **Federal Reserve — Fedwire Funds Service Operating Circular 6** — funds transfer rules context via https://www.frbservices.org/publications/operating-circulars.html
- **Nacha — ACH Network** — ACH operating framework and return concepts via https://www.nacha.org/ach-network
- **CFPB — Electronic Fund Transfers (Regulation E)** — consumer EFT error resolution framing via https://www.consumerfinance.gov/rules-policy/regulations/1005/

## Fraud, disputes, and consumer protections

- **CFPB — Unauthorized transactions / error resolution overview** — consumer rights orientation via https://www.consumerfinance.gov/consumer-tools/bank-accounts/
- **FTC — Identity theft and account takeover** — containment-oriented consumer steps via https://consumer.ftc.gov/articles/what-know-about-identity-theft
- **FFIEC — Authentication and access to financial institution services** — control expectations context via https://www.ffiec.gov/

## AML / sanctions orientation (escalation, not DIY compliance)

- **FinCEN — Bank Secrecy Act overview** — AML program orientation via https://www.fincen.gov/resources/statutes-and-regulations/bank-secrecy-act
- **OFAC — Sanctions programs and information** — sanctions screening escalation anchor via https://ofac.treasury.gov/
- **FATF — Recommendations** — international AML/CFT standard framing via https://www.fatf-gafi.org/en/publications/Fatfrecommendations/Fatf-recommendations.html

## How to use these sources in-session

- Cite the matching group when stating rail finality, consumer error-resolution windows, or escalation triggers.
- If the user's country is outside the US/EU framing above, load jurisdiction-specific primary docs before finalizing compliance claims.
- Sources justify control presence and escalation paths; they do not authorize data exfiltration or portal automation.
