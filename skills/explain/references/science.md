# Learning-science checks

Use this reference when a concept is difficult enough that presentation order matters.

## Manage working memory

- Start with the smallest useful model, then add one dependency or exception at a time.
- Use headings, examples, and familiar terms to make the structure visible.
- Remove decorative detail that does not advance the answer.
- Ask a focused check question after a multi-step explanation; revise the explanation if the answer reveals a gap.

## Teach-back loop

For a complex or safety-sensitive concept:

1. State the concept in plain language.
2. Show one concrete example.
3. Ask the user to restate the causal link or apply it to a nearby case.
4. Repair the specific gap, then return to the original task.

## Progressive disclosure

Provide the direct answer and the next actionable detail first. Expand into mechanisms, exceptions, or background when the user requests it or the decision depends on it.

## Sources
