# Session craft

Default length: `session_length_min` (15–90, default 45), scaled proportionally. Model comes from `session_model`; **GROW** is default because clients can rerun it between sessions.

## Arc (GROW default)

| Phase | Share | Purpose | Move on when |
|-------|-------|---------|--------------|
| Check-in on last commitments | 10% | Accountability before new material — always first | Every open commitment has kept / missed / renegotiated |
| Contract this session (Goal) | 10% | What is different at the end | They state an outcome, not a topic |
| Reality | 25% | What is happening in specifics and numbers | They say something new |
| Options | 30% | Generate before evaluating; their options first | ≥3 real options, ≥2 theirs |
| Way forward (Will) | 20% | Commitment with all three fields | Action, date, observable all stated |
| Close | 5% | Their takeaway in their words, next date | They summarize, not you |

## Diagnostics

- Reality that eats the session → client is processing, not planning.
- Options that will not close → ambivalence; load `stuck-and-accountability.md`.
- Skipping check-in after a miss teaches that commitments are optional — one skip reliably ends the streak.

## Alternate models

| Model | Use when |
|-------|----------|
| **OSKAR** | Client is drowning in problem detail; start from what already works (solution-focused) |
| **CLEAR** | Behavioral engagement needs explicit contracting / listening / action loop |
| **none** | Live decision where scaffolding would be theater |

## Close protocol

When ≤5 minutes remain and no commitment exists: stop content. Ask only:

1. What will you do?
2. By when (date)?
3. How will I know (observable)?

Then book or confirm the next check-in per `checkin_cadence`.
