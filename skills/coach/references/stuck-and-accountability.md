# Stuck clients and accountability

## Decode rule

What the client **does between sessions** names the cause. What they **say in session** is usually the acceptable theory about it.

## Symptom → first move

| Symptom | Likely cause | First move |
|---------|--------------|------------|
| Great session, nothing after | Commitment was yours, not theirs | Have them restate it in their words at close |
| "Yes, but" on every option | Ambivalence (both sides are theirs) | Stop proposing; ask for the full case *for* not changing |
| Endless planning / tooling | Planning is the avoidance | Start time in next 24h, not a better plan |
| Same commitment missed 3+ | Sizing, not motivation | Halve, then halve again; only then ownership |
| Goal reset every quarter | Outcome goal with no process goal | Split controllable process vs outcome |
| Only talks about others | Locus of control left the room | "What part of this is yours?" — coach only that |
| Energy drops on a topic | Unsaid material | Name the drop; do not interpret |
| Wants sessions, never books | Wrong container | Change cadence/length before judging desire |
| Progress then reversal near success | Unnamed cost of success | "What gets harder if this works?" |
| Fluent insight, no behavior change | Insight consumed as the product | Commitments-only closes for a month |

## Commitment fields (mandatory)

Every commitment needs:

1. **Action** — concrete behavior
2. **Deadline** — a date (not "soon")
3. **Observable** — how anyone would know it happened

"Exercise more" has none. "20-minute walk before first meeting, Mon/Wed/Fri, logged in the tracker" has all three. Missing the third field → record as intention, not commitment; do not count in streaks.

## Size classes

| Class | Shape | Cadence | On a miss |
|-------|-------|---------|-----------|
| Minimum viable action | <20 min, once | Before next session | Still too big, or deadline was vague |
| Repeating behavior | Same action, fixed days | Weekly for first 30 days, then `checkin_cadence` | Cut frequency before cutting the action |
| Decision with deadline | A choice made, not researched | One session | Cost of wrong choice was the blocker |
| Avoided conversation | Named person, date, opening line | One session | Rehearse first sentence out loud in-session |
| Experiment | Time-boxed trial + review date | 1–4 weeks | Experiments are reported, not "missed" |

## Miss protocol (Rule 5)

1. Two consecutive misses of the same ask → `new_size = old_size ÷ 2`, re-run 20-minute test.
2. Two consecutive hits → ratchet scope ~25%.
3. Only after two halvings that still miss: examine ownership, capacity, or a hidden competing commitment.
4. Probing motivation first reads as blame and costs the relationship.

## Implementation intentions

Attach action to a cue and place: "after I close the laptop, I walk for 20 minutes." Implementation intentions show a medium-to-large effect in meta-analysis; treat cue+place as default formatting, not garnish. See `sources.md`.

## Stakes and streaks

- Social stakes (tell one named person by a named date) beat financial penalties the client controls.
- Streaks are tools, not scoreboards. Rule after a break: **never miss twice** — the second miss re-forms the old behavior.
