## Evidence Sources (Gate 6)

Use these authoritative references when stating calorie, macro, or protocol guidance. Prefer loading this file only when source verification is needed.

### Energy expenditure and macros
- **Mifflin–St Jeor equation** — BMR estimation basis commonly used before applying activity multipliers via https://en.wikipedia.org/wiki/Basal_metabolic_rate
- **Dietary Reference Intakes / macronutrients** — protein, carbohydrate, and fat Acceptable Macronutrient Distribution Ranges framing via https://ods.od.nih.gov/HealthInformation/Dietary_Reference_Intakes.aspx
- **International Society of Sports Nutrition position stand: protein and exercise** — protein dosing ranges for athletes/hypertrophy via https://jissn.biomedcentral.com/articles/10.1186/s12970-017-0177-8

### Diet patterns
- **Ketogenic diet overview** — typical very-low-carbohydrate framing via https://en.wikipedia.org/wiki/Ketogenic_diet
- **Mediterranean diet** — whole-food pattern associated with cardiometabolic health via https://en.wikipedia.org/wiki/Mediterranean_diet
- **Healthy diet** — WHO/public-health framing for balanced intake patterns via https://en.wikipedia.org/wiki/Healthy_diet

### Tracking caveats
- Food-label accuracy tolerances and cooked-vs-raw weight pitfalls remain practical coaching notes; escalate clinical conditions to licensed professionals.
