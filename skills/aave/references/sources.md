# Research Sources — Aave V3 Protocol

Primary technical documentation, contract repositories, and live verification endpoints for Aave V3.

## Technical Documentation & Risk Framework

- **Aave V3 Technical Documentation** — https://aave.com/docs/developers/smart-contracts/pool
  - Core Pool contracts, lending/borrowing methods, E-Mode categories, and Flash Loan interfaces.
- **Aave Liquidations Guide** — https://aave.com/help/borrowing/liquidations
  - Health Factor calculation, liquidation threshold, close-factor, and bonus incentives.
- **Aave Markets Data API** — https://aave.com/docs/aave-v3/markets/data
  - Querying reserve data, collateral asset caps, and user account data.

## Official Repositories & Addresses

- **Aave Address Book** — https://github.com/aave-dao/aave-address-book
  - Deployed contract addresses across all supported L1 and L2 chains.
- **Aave V3 Core Contracts** — https://github.com/aave-dao/aave-v3-origin
  - Smart contract source code, `GenericLogic.sol`, and `LiquidationLogic.sol`.
- **GHO & Umbrella Documentation** — https://aave.com/docs/ecosystem/gho
  - GHO stablecoin facilitator model and Umbrella protocol-risk staking.
