## Common Traps

- Fetch `/models` and use the live ID instead of hardcoding a remembered model ID.
- Split coding, reasoning, JSON, and migration work instead of treating Kimi as one generic route.
- Redact first and preview what leaves the machine before sending internal logs to the API.
- Use a second deterministic pass instead of combining creative reasoning with strict JSON output.
- Verify auth, base URL, retries, and parser behavior before blaming the model for failures.
