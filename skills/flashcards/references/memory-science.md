# Memory Science for Flashcards

## Core Principles

- **Minimum Information Principle**: Simpler cards result in better retention. If a card feels complex, split it. Each card should test exactly one thing.
- **Active Recall**: The act of retrieving information from memory strengthens the memory trace. Questions must force retrieval, not just recognition.
- **Spacing Effect**: Reviewing information at increasing intervals is more effective than massed practice (cramming). Spaced repetition algorithms manage these intervals.
- **Personal Connection**: Adding context from your own experience strengthens encoding.
- **Concrete over Abstract**: Concrete facts (e.g., "Paris is capital of France") are easier to remember than abstract concepts.
- **Imagery**: Visual descriptions and images enhance memory encoding.

## Formulating Effective Questions

- **Best retention**: Why/How questions that require understanding.
- **Good retention**: Fill-in-the-blank, definition recall, process steps.
- **Weak retention**: Yes/No questions, multiple choice (use sparingly as they test recognition more than recall).
- **Avoid**: Questions answerable by pattern matching or elimination.
