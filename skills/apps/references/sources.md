# App recommendation source map

Use these sources when a recommendation depends on a mutable privacy disclosure or on current store-policy context. This map does not prove that an individual app currently offers a feature, price, or subscription tier; check the app's current official listing and documentation before making that claim.

## Privacy disclosures

- **Apple — App privacy details**: <https://developer.apple.com/app-store/app-privacy-details/>. Use the App Store privacy-label categories as one input when comparing an iOS app's data practices; distinguish an App Store disclosure from an independent security audit.
- **Apple Platform Security — App Privacy Report**: <https://support.apple.com/guide/security/app-privacy-report-sec7d82ea64/web>. Use when explaining the iOS feature that exposes an app's network and sensor-access activity to the device owner.
- **Google Play Console Help — Data safety form**: <https://support.google.com/googleplay/android-developer/answer/10787469>. Use Google Play's Data safety disclosure as one input when comparing Android apps.
- **Google Play Console Help — User Data policy**: <https://support.google.com/googleplay/android-developer/answer/10144311>. Use when a comparison needs the policy framing behind data collection, sharing, and disclosure requirements.

## Verification routine

1. Identify the user's platform, region, app version, and decision criterion.
2. Check the app's official store listing and vendor documentation for current pricing, availability, compatibility, and policy terms.
3. Read the relevant platform disclosure above when privacy is material.
4. State the date and source for mutable claims; if a source cannot be checked, retain the durable comparison framework and mark the detail unverified.
