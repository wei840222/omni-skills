# Authoritative language resources

Use these sources when a request needs a normative spelling, a lexical choice, a grammatical form, or a distinction between standard and user-supplied varieties. They are reference material, not a substitute for preserving the user’s requested voice.

- **Real Academia Galega, Dicionario** — https://academia.gal/dicionario
  - Use for current dictionary entries and usage notes in standard Galician.
- **RAG entry: `vostede`** — https://academia.gal/dicionario/-/termo/vostede
  - Identifies `vostede` as the courtesy personal pronoun used when the addressee is not addressed as `ti`.
- **RAG entry: `rapaz`** — https://academia.gal/dicionario/-/termo/rapaz
  - Records the feminine form `rapaza` for the relevant sense.
- **RAG entry: `grazas`** — https://academia.gal/dicionario/-/termo/grazas
  - Provides the standard dictionary treatment of `grazas`.

If a requested regional, reintegrationist, or colloquial form is not established by the source text or a consulted authority, retain the user’s supplied form or ask a focused question instead of inventing a dialectal marker.
