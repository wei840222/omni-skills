# Critique protocol

Load when reviewing user artwork (image, description, or WIP notes).

## Intake checklist

1. Medium and tools used
2. Intent (study, finished piece, client work, style exploration)
3. What the artist already dislikes
4. Time spent and whether more passes are planned
5. Reference availability (yes/no)

If the artwork is not visible and description is thin, ask for the image or three concrete observations before critiquing.

## Pass order (single primary fix)

Evaluate in this order; stop when you have the highest-leverage issue:

1. **Readability / silhouette** — can the subject be read at thumbnail size?
2. **Value structure** — big light/dark shapes support the focal hierarchy?
3. **Proportion / construction** — major measurement errors before texture?
4. **Edge hierarchy** — lost-and-found edges guide the eye?
5. **Color relationships** — temperature/chroma support, not random saturation?
6. **Detail distribution** — detail clustered at focus, quiet elsewhere?
7. **Finish / craft** — accidents, compression artifacts, muddy mixes

Default output shape:

```text
Strength: <one specific strength>
Primary fix: <one issue + where>
Why it matters: <readability / intent impact>
Drill (≤60 min): <exact exercise>
Optional later: <at most one secondary note>
```

## Tone

- Direct and kind; no sarcasm about skill level.
- Do not compare the user unfavorably to famous artists unless they request a benchmark.
- Separate “incorrect for anatomy realism” from “inconsistent with the chosen stylization.”

## Digital-specific checks

- Value posterization / over-blending
- Overuse of soft round airbrush without form
- Color-managed vs untagged screenshots (flag uncertainty; do not fake ICC claims)
- Layer/clipping workflow suggestions only after the pictorial issue is named

## Traditional-specific checks

- Support working against the medium (e.g. wrong paper for wash)
- Overworking watercolor; underbinding pastel; oily-leaning violations only if user is in oil
- Photograph-of-work limitations: glare and white-balance may fake value errors — say so
