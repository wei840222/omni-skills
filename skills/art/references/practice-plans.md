# Practice plans

Load when the user wants a learning path, weekly plan, or skill breakdown.

## Decomposition patterns

| Goal | Component skills (practice separately) |
|---|---|
| Believable face | head construction → feature placement → value planes → edges |
| Hands | box/wedge masses → finger grouping → foreshortening drills |
| Environment | horizon/VP → value masses → edge hierarchy → sparse detail pass |
| Digital painting | opaque block-in → value lock → color commit → edge pass → focal render |
| Watercolor control | wet-on-wet washes → hard edges → lifting → limited-palette studies |

## Starter plans (adjust intensity)

### A. Absolute beginner drawing (4 weeks, ~25–40 min/day)

| Week | Focus | Daily core |
|---|---|---|
| 1 | Line + boxes | 10 min straight/curve control; 15 min boxes in perspective |
| 2 | Gesture | 15×1–2 min figures or animal gestures from photo/ref |
| 3 | Values | 3×10 min 3–5 value posters of simple still life |
| 4 | Finish | 2 small finished studies; one master-copy value study |

Success = finished imperfect pages, not perfect lines.

### B. Digital portrait block-in (2 weeks)

1. 10 head constructions (Loomis-like or preferred method) — no rendering.
2. 10 value-only portraits, 20–30 min, three values max.
3. 5 limited-palette color commits from the best value locks.
4. One longer piece (90–120 min) applying the same pipeline.

### C. Critique-driven improvement (ongoing)

After each critique:

1. Write the single target skill in one sentence.
2. Design a 5-day micro-cycle of drills aimed only at that sentence.
3. Re-critique the **same type** of subject; compare only that axis.

## Time honesty

- Habit formation for observational skill often needs **weeks to months** of short reps.
- “Draw every day for 10 minutes” beats rare 4-hour hero sessions for beginners.
- Plateaus are normal after early gains; change drill design, not only willpower speeches.

## Reference hygiene

- Prefer photographic or life reference with clear lighting for value training.
- Master copies: match value structure first; color second.
- For stylized goals, schedule deliberate style studies **and** structure studies — not only finished fan art.
