# Issue spotting

Goal: surface the full issue map before deep IRAC on any single claim.

## Method

1. Restate the user's goal in one line.
2. List every claim, defense, counterclaim, and procedural bar that could change the outcome.
3. Group by doctrine family (contract, tort, consumer/statutory, property, employment, procedure).
4. Mark each item **primary**, **secondary**, or **remote**.
5. Run full IRAC only on primary issues and any secondary issue that blocks the goal.

## Always check both sides

For the user's preferred theory, also ask:

- What would the other party argue?
- Which elements are weakest on these facts?
- Is there a faster procedural kill-shot (limitations, notice, standing, arbitration, release)?

## Procedural screen

Before substantive deep dives, scan for:

- statute of limitations / repose
- contractual notice or claim-presentation requirements
- standing / real-party-in-interest problems
- arbitration, forum-selection, or exclusive-remedy clauses
- conditions precedent (written demand, cure period)
- mandatory administrative exhaustion

## Prioritization heuristic

Rank higher when the issue:

- directly unlocks or blocks the user's goal
- has short remaining time
- is cheap to test with a document check
- carries outsized downside if ignored (criminal, immigration, housing, safety)

Rank lower when the issue is speculative, jurisdiction-foreign, or depends on facts the user cannot obtain.
