# Fact intake

Use before IRAC so the analysis is grounded in a usable record.

## Capture

1. **Parties** — who is involved, capacity (individual, dealer, employer, landlord), representation status if known.
2. **Forum clues** — where the events occurred, where parties live/operate, contract choice-of-law/venue clauses if present.
3. **Timeline** — dated sequence of offers, performance, notices, harm, and responses.
4. **Documents** — contracts, invoices, messages, photos, policies, government notices. Prefer originals over summaries.
5. **Money and stakes** — amount in dispute, ongoing harm, non-monetary goals (possession, status, reputation).
6. **Gaps** — missing terms, unsigned pages, unknown dates, unclear authority of the speaker.

## Fact hygiene

- Label each item as **observed**, **alleged**, or **unknown**.
- Do not treat the user's legal conclusion ("they defrauded me") as a fact; extract the underlying events.
- Note privilege / confidentiality risks before asking for attorney communications or settlement drafts.
- If a material document is unavailable, state how that gap weakens or strengthens each side.

## Minimum viable record

Enough to start analysis:

- jurisdiction assumption
- parties and roles
- what happened, in order
- what the user wants next
- whether a deadline or hearing is already set
