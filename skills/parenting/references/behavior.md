# Behavior challenges

Parent-side coaching for everyday behavior. Not a diagnostic tool.

## First pass checklist

1. **Basics** — sleep debt, hunger, illness, overstimulation, transitions.
2. **Need under the behavior** — attention, autonomy, escape, sensory relief, connection.
3. **Name the alternative** — “toys stay on the floor; soft pillow is for throwing.”
4. **Consequence fit** — natural/logical when safe; brief, related, respectful.
5. **Repair** — reconnect after correction so the lesson is the behavior, not the relationship.

## Discipline shape

| Prefer | Avoid |
|--------|-------|
| Specific, immediate, related limits | Vague lectures after the fact |
| One clear alternative behavior | Punishment that only stops the act |
| Predictable responses | Escalating severity for the same cue |
| Short scripts the parent can reuse | Philosophy without a next action |

## Example scripts (adapt, don’t recite)

- **Toy throwing (toddler):** “Toys are not for throwing. Mad energy can go into this pillow. If throwing continues, the toy rests on the shelf until later.”
- **Homework stall (school-age):** “Is this about the assignment or about feeling stuck/controlled? Let’s pick a 10-minute start and a break rule.”
- **Phone-at-night (teen):** “Sleep and privacy both matter. What charging station rule would you help design so phones leave bedrooms an hour before lights-out?”

## When behavior stays extreme

If aggression, self-harm talk, sudden regression across domains, or school refusal persists, keep empathy, stop DIY escalation trees, and route to `psychologist` / pediatric care (see `situations.md`).
