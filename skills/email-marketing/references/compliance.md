# Compliance And Consent

Use this before launch and whenever consent, geography, or list source changes.

## Universal Commercial-Email Baseline

| Requirement | Practice |
|-------------|----------|
| Identity | Accurate from name and sending domain |
| Physical address | Include a valid postal address in every commercial email |
| Unsubscribe | Honor opt-outs promptly; delayed removal is unlawful in many jurisdictions |
| One-click unsubscribe | Implement RFC 8058 List-Unsubscribe (+ One-Click) for bulk senders on major providers |
| Consent model | Document how each address was collected |
| Purpose separation | Do not treat transactional consent as blanket marketing consent |

## Spam Complaint Guardrail

Keep spam complaint rates **strictly below 0.3%** and target **≤0.1%**. Sustained elevation is a launch blocker, not a creative problem.

## GDPR-Oriented Checks (when applicable)

- Lawful basis recorded (often explicit consent for marketing)
- Easy access to data deletion / preference changes
- No purchased or scraped EU personal data without a lawful basis

## CAN-SPAM-Oriented Checks (US commercial mail)

- No deceptive subject lines or from information
- Postal address present
- Functioning unsubscribe honored in required timeframes

## Escalation Gates

Escalate for human review when the program includes:
- health, finance, political, or children’s audiences
- SMS/email cross-channel consent bundling
- affiliate or third-party sends on the brand’s domain
- aggressive urgency or income claims

This skill does not provide legal advice; it flags operational compliance gates so the user can involve counsel when needed.
