## Common Mistakes

- Select exactly the weights used (typically 2–3) instead of loading a broad "safe" range.
- Restrict display faces (for example Lobster, Pacifico, Abril Fatface) to headings only.
- Avoid near-duplicate pairings such as Roboto + Open Sans; pick one text face.
- Ensure every CSS `font-weight` value has a matching loaded weight or variable axis coverage.
- Always include a robust fallback stack, for example `font-family: 'Inter', system-ui, sans-serif`.
