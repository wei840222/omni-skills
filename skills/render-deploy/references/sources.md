# Official Sources & Platform Specifications

This document records the official documentation and technical specifications for Render cloud hosting and Blueprints.

## Official Platform Documentation

- **Render Documentation Home**: [https://render.com/docs](https://render.com/docs)
  - Core platform architecture, service types (Web Services, Private Services, Background Workers, Cron Jobs, Static Sites), and environment variable groups.
- **Render Blueprint (`render.yaml`) Specification**: [https://render.com/docs/blueprint-spec](https://render.com/docs/blueprint-spec)
  - Infrastructure as code schema for automated provisioning of services, databases, disks, and environment sync.
- **Render Public REST API Reference**: [https://api-docs.render.com/reference/introduction](https://api-docs.render.com/reference/introduction)
  - Programmatic service creation, deployment triggering, log inspection, and webhook integration.
