# Sale and rental staging

Use this reference for a property listing, viewing, or guest-ready plan. Base commercial claims on local comparable data, platform rules, and current costs; present projected outcomes as scenarios rather than guarantees.

## Define the objective

Record the property type, audience, listing platform, target date, budget, occupancy status, local restrictions, and the primary decision the staging should support: sale viewing, rental photography, guest experience, or long-term use.

## Prioritize work

1. Address safety, cleaning, repairs, and access first.
2. Select the rooms and features that best communicate the property’s value.
3. Remove clutter, private items, and visual distractions while retaining enough context to show room function and scale.
4. Add only items that fit the budget, local availability, maintenance capacity, and listing rules.
5. Coordinate the finished plan with `references/photography.md` before the shoot or viewing.

## Rental competitive analysis

Compare current local listings with matching location, capacity, amenities, condition, and season. Record the date and source for every comparison. Distinguish observed features from assumptions about price, occupancy, or reviews.

## Review-to-fix mapping

Translate recurring verified feedback into a concrete hypothesis, cost, owner, and validation method. For example, a repeated comfort complaint may justify comparing sleep, lighting, or amenity improvements, but a change should remain optional until the user confirms scope and cost.

## Financial framing

Use a transparent planning calculation:

```text
estimated payback period = total change cost ÷ estimated monthly incremental net revenue
```

Label incremental revenue as a scenario, document its local comparable-data source, and account for fees, vacancy, maintenance, taxes, financing, and seasonality where applicable.

## Common staging traps

| Trap | Why it fails | Positive alternative |
|---|---|---|
| Over-staging | Clutter obscures the room | Keep items that communicate function, scale, and the intended audience |
| Wrong scale | Furniture misstates usable space | Verify dimensions and circulation before placing items |
| Ignoring exterior | Arrival shapes the first impression | Include exterior condition and access in the walkthrough |
| Inconsistent lighting | Mixed sources distort the room | Test the lighting plan with the photographer or a sample image |
| Style mismatch | Staging conflicts with the property | Start with the architecture and confirmed target audience |
| Odor masking | Fragrance can create an additional issue | Identify and resolve the underlying odor source when possible |
