# Style direction

Use this reference when a user asks to identify, select, or combine interior styles.

## Start with a brief

Ask about:

1. Pieces that must remain.
2. Styles, colors, materials, and experiences the user explicitly likes or dislikes.
3. Architectural context and fixed finishes.
4. Occupants, daily use, maintenance capacity, budget, timeline, and region.
5. Whether the plan is intended to be reversible, long-lived, staged, or rental-focused.

## Style vocabulary

| Direction | Typical signals | Useful questions |
|---|---|---|
| Scandinavian | Light woods, restrained palette, functional forms | Does the user want warmth, minimalism, or both? |
| Mid-century | Organic forms, tapered legs, wood contrast | Which original or reproduction pieces define the room? |
| Contemporary | Current forms, clean lines, mixed materials | Which elements should stay timeless rather than trend-led? |
| Mediterranean | Warm earth tones, texture, arches, natural materials | Does the architecture and local climate support this direction? |
| Industrial | Exposed structure, metal, raw finishes | Which hard surfaces need acoustic or thermal softening? |
| Traditional | Symmetry, layered detail, formal materials | Which details belong to the building rather than decoration? |

## Build a coherent mix

Choose one primary direction, then introduce a limited number of supporting influences that share a material, color, proportion, or historical relationship. Present a small palette, a hierarchy of investments, and a reversible trial step before committing to permanent finishes.

## Budget and sourcing

Match materials, construction quality, and maintenance expectations to the user’s actual budget tier. For a named product or retailer, follow the regional availability process in `references/rules.md`; catalog imagery and brand familiarity are not availability evidence.

## Validate before commitment

Use samples, dimensions, lighting checks, and a simple room plan to test the direction. Explain the trade-off when a style choice conflicts with maintenance, access, budget, architecture, or long-term flexibility.
