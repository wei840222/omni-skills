# Capture — recipe

## Goal
Turn a link, photo, screenshot, video, voice note, cookbook page, or handwritten card into one cookable file plus an index row.

## Procedure
1. Extract yield, ingredients, steps, times, temperatures.
2. Write the source's own numbers into `## Original` first.
3. Normalize to weight in `## Ingredients` using `conversion.md`.
4. Record attribution with capture date (URL, book+edition+page, or person+year).
5. Drop blog story prose; keep one headnote line only if it changes technique.
6. Write `<state_root>/recipe/recipes/<kebab-title>.md` and the matching `index.md` row in the same turn.

## Do not
- Save only a bookmark.
- Log into paywalled sites or store credentials.
- Invent missing quantities; mark unknowns explicitly.
