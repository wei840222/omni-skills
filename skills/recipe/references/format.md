# Format — recipe

## File skeleton

```markdown
# Title

- Yield: …
- Source: … (captured YYYY-MM-DD)
- Tags: …

## Original
…verbatim source measures…

## Ingredients
…normalized weights / countable yield…

## Steps
…

## Notes
- Variations:
- Equipment:
- Untested:
```

## Grammar
- Ingredient lines: quantity + unit + item (+ preparation).
- Steps: imperative, one action family per step when practical.
- Yield must be countable (`12 muffins`, `4 servings × ~350 g`).
- Keep Original and Ingredients as separate truths; do not overwrite Original with the cooked variant.
