# Equipment — recipe

Rewrite a saved recipe for a different device only with explicit time/liquid/temperature mapping.

## Transfer notes
- **Pressure cooker:** liquid minimum is a hard floor; time is not “oven ÷ N”.
- **Air fryer:** usually hotter/faster air; reduce temp slightly and check early.
- **Slow cooker:** low evaporative loss — reduce free liquid; browning is separate.
- **Sous vide:** set target temp/time from doneness, then finish for crust if needed.
- **Fan oven:** apply fan offset from `conversion.md`.

If a technique cannot transfer (deep dry crust in a sealed wet cooker, etc.), say so and offer the closest safe path.
