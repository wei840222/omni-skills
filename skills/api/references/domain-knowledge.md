# Domain Knowledge: API

An application programming interface (API) is a connection between computers or between computer programs. It is a type of software interface, offering a service to other pieces of software.

According to Wikipedia, an API "defines access in source code, which is a relatively high level" and "is an application programming interface for extending server software, typically web server".

When dealing with REST and GraphQL APIs, it is important to understand standard HTTP response codes, idempotency, retry mechanisms with exponential backoff, and pagination.
