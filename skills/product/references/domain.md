# Product Domain Knowledge

## Core workflows

**Digital products (SaaS)**

1. Validate → `references/validation.md` (interviews, smoke tests, paid signal)
2. Define MVP → one core value proposition only
3. Prioritize → `references/prioritization.md` (RICE when comparable; MoSCoW for release scope)
4. Launch → limited beta, instrument activation
5. Measure PMF → `references/metrics.md` + Sean Ellis 40%+ very disappointed before paid scale

**Physical products**

1. Design for manufacture (DFM)
2. Source + certs → `references/compliance.md` by region
3. Photograph → `references/prompts.md` / `references/ai-tools.md`
4. List → `references/amazon.md`, `references/etsy.md`, `references/specs.md`
5. Launch → limited drops; watch fee-aware margin in `references/pricing.md`

**Merchandising / POD**

1. Create master art at the largest needed size
2. Mockups → `references/ai-tools.md`
3. Export platform sizes → `references/specs.md` + `references/pod.md`
4. List multi-channel with fee-aware retail math

## Critical rules

- **Validate before building** — ask what people did last time, not whether they would use a hypothetical.
- **Platform specs matter** — Amazon main image white background, Etsy minimum pixel sizes, POD DPI are reject gates.
- **Pricing includes fees** — reverse from desired margin after referral, FBA/POD base cost, and payment cuts.
- **PMF before scaling** — acquisition spend after retention/PMF signal, not before.
- **Live sources beat memory** — fee %, storage rates, and image minima drift; open `references/sources.md` anchors when quoting.

## Scope boundaries

| In scope here | Prefer instead |
|---------------|----------------|
| Cross-channel product launch craft | `product-manager` for pure PM process |
| Fee-aware retail math for goods | `pricing` for deep B2B software packaging |
| Listing image + FBA/Etsy checklists | `amazon` / `etsy` for full channel ops |
| Orientation SaaS metrics | `saas` for movement bridges and dunning |

## Positive operating stance

- Lead with the next validated experiment or fee-aware listing fix.
- When a specialty skill fits better, name it and continue with the handoff path rather than blocking the user.
- When a number is mutable, open the official source first, then answer with the confirmed figure.
