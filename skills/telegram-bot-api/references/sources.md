# Official Sources & Technical Specifications

This document records the official documentation and technical specifications for the Telegram Bot API.

## Official Telegram Bot Documentation

- **Telegram Bot API Reference**: [https://core.telegram.org/bots/api](https://core.telegram.org/bots/api)
  - HTTP method specifications (`sendMessage`, `setWebhook`, `getUpdates`), update types, inline keyboards, reply markups, Mini Apps integration, business bots, and forum topics.
- **Telegram Mini Apps (Web Apps)**: [https://core.telegram.org/bots/webapps](https://core.telegram.org/bots/webapps)
  - Client-side Web App integration, viewport parameters, theme event handling, and secure data transfer via `initData`.
- **Telegram Bot Developer FAQ & Rate Limits**: [https://core.telegram.org/bots/faq](https://core.telegram.org/bots/faq)
  - BotFather commands, rate limits (avoiding more than 1 message/second within a single chat; broadcasting around 30 messages/second overall, with paid broadcast scaling), and file size upload limits.
