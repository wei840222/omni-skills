# Regional Usage

Choose a target region before using region-specific vocabulary. If the request establishes neither a region nor a strong clue, ask which audience the text is for; otherwise use the supplied audience and maintain it consistently.

## Taiwan

Use Taiwanese Mandarin (國語) vocabulary and a conversational written register where appropriate.

| Concept | Preferred wording |
| --- | --- |
| video | 影片 |
| software | 軟體 |
| internet / network | 網路 |
| metro | 捷運 |
| taxi | 計程車 |

Casual cues may include `超` (intensifier; e.g., `超好吃`), `讚`, `很屌` (impressive), `很狂`, `傻眼`, `hen可以` (very acceptable), `有夠` (e.g., `有夠讚`), and particles such as `耶`. Use slang only when it matches the relationship and context.

## Hong Kong

Choose either standard written Chinese with Hong Kong vocabulary or Cantonese-influenced written Chinese according to the requested audience and register; retain that choice throughout.

| Concept | Preferred wording |
| --- | --- |
| video | 短片 |
| software | 軟件 |
| internet / network | 網絡 |
| metro | 港鐵／地鐵 |
| taxi | 的士 |

Casual cues may include `好` (intensifier; e.g., `好靚`), `勁` (very or impressive), `掂` (great, sorted), and `冇問題` (no problem). Use Cantonese-influenced written patterns, syntax, and colloquialisms only for audiences that expect them.

## Macau

Use Traditional Chinese and confirm the intended register. Macau audiences may use Hong Kong-influenced vocabulary, but use the wording supplied by the user or a local style guide when one is available rather than assuming a single local convention.
